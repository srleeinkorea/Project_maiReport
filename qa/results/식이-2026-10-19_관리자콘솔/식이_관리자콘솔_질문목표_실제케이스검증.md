# 식이 질문·목표 — 관리자 콘솔 실제 케이스 검증

서버 데이터 1.1.1 · 규칙 1.0.0. 서버 코드·데이터는 고치지 않음.

## 판정

**서버는 규칙대로 동작함. 1.1.1 문구도 그대로 나옴. 다만 문구 목록 뒤쪽은 계약 규칙 때문에 사용자에게 영영 안 나옴 (기획 판단 필요).**

| 항목 | 결과 |
|---|---|
| 가상 사용자 | 32명 (#1128~#1159) |
| 돌린 날짜 | 1,371일 (목표 1,368개) |
| 기대값과 같음 | 1,364일 |

기대값은 서버 「규칙 보기」 문서와 1.1.1 데이터로 따로 계산함. 날마다 끼니·회전 질문 축·축 상태·목표 문구·단계·긴 문장을 하나씩 대조함.

## 1. 기본 케이스 — 저장소 식이 QA를 서버로 옮겨 확인

저장소 QA 계획(`qa/plans/식이.qa-plan.json`)의 케이스를 서버 규칙에 맞게 바꿔서 돌림.

| 새벽 3시 접속은 전날 세션, 「어제 저녁」을 물음 | 10-19 03시 → 세션 10-19, 어제 저녁 | 통과 |
| 04~10시도 「어제 저녁」, 같은 끼니 답은 다시 안 물음 | 03시에 답한 고정 질문을 04시에 「답함」으로 재사용 | 통과 |
| 10시부터 「오늘 아침」, 12시부터 「오늘 점심」, 17시부터 「오늘 저녁」 | 시각 10개 경계 모두 | 통과 |
| 고정 질문에 「못 먹거나 거름」이면 회전 질문 없이 회복 목표 | 13시 결식 → 「단백질 한 입 먹기」 | 통과 |

| 축 상태 「개선 필요」면 기본까지만 | 채소를 늘 「먹지 않음」 → 19일에도 기본 | 통과 |

서버에 없는 기능이라 이번에 못 본 것:

- 식사 시각 질문 단계(저장소 QA 21~27번) — 1.1.1은 연구소 전달본이라 이 단계가 빠져 있음.
- 검진 유효기간(13~16번) — 검증 화면에 검진 입력이 없음.
- 필드 이름 바꿔 넘기기(3번) — 서버 내부 함수라 화면으로 확인 불가.

|---|---|

**화면에서는 바뀐 문구 54개가 1.1.1 글자 그대로 나옴. 옛 1.1.0 문구는 한 번도 안 나옴.**

| 이유 | 채소를 곁들이면 외식에서도 채소를 챙겨요. |

1.1.1에서 단계가 바뀐 문구도 바뀐 단계에서 나옴. 예: 「국 대신 나물 반찬」은 입문에서 기본으로 옮겨져, 채소 기본 단계 16일째에 나옴.

## 3. 발견한 것

### 발견 1 — 문구 목록 뒤쪽은 사용자에게 영영 안 나옴 [기획 판단 필요]

목표 문구 393개(저부담 묶음 10개 제외) 중 **139개는 어떤 사용 패턴에서도 안 나옴.**

원인은 문구 반복 방지 규칙. 계약 검증규칙 V-45는 「최근 30일에 안 나온 문구를 문구 번호 순으로 먼저」 고름. 30일이 지난 문구는 처음 쓰는 문구와 같은 줄에 서고, 번호가 앞이라 다시 뽑힘. 서버는 이 규칙을 그대로 지킴. 서버 결함이 아님.

예: 일반 사용자 13시 접속, 단 음료 입문 문구는 11개 있음. 실제로 도는 것은 4개뿐.

| 날 | 나온 문구 |
|---|---|
| 5일 | 한 잔은 물로 바꾸기 |
| 15일 | 시럽 · 크림 빼기 |
| 25일 | 더운 날 물부터 마시기 |
| 35일 | 식후 커피는 무가당으로 |
| 45일 | 한 잔은 물로 바꾸기 (30일 지나서 처음으로 돌아감) |

한 축이 30일에 몇 번 나오느냐로 쓸 수 있는 문구 수가 정해짐. 일반 사용자는 축마다 약 7일에 한 번이라 4~5개, 질환 사용자의 연결 축은 3일에 한 번이라 10개 안팎.

축·단계별로 안 나오는 문구:

| 축 · 단계 | 안 나옴 / 전체 | 이유 |
|---|---|---|
| 끼니 규칙 (전 단계) | 41 / 41 | 회전 질문이 없는 축. 다른 축 문구가 늘 있어서 차례가 안 옴 |
| 식사 시각 기본 · 도전 | 11 / 11 | 점수 질문이 없어 늘 관찰 중 → 입문에서 안 오름 |
| 식사 시각 입문 | 10 / 17 | 목록 뒤쪽 |
| 채소 입문 | 27 / 53 | 목록 뒤쪽 |
| 단백질 입문 | 24 / 41 | 목록 뒤쪽 |
| 기름진 음식 입문 · 기본 | 13 / 45 | 목록 뒤쪽 |
| 짠맛 · 국물 입문 · 기본 | 10 / 43 | 목록 뒤쪽 |
| 단 음료 · 식사 속도 입문 | 3 / 36 | 목록 뒤쪽 |

1.1.1에서 바꾼 문구 중 안 나오는 15개:

| 축 · 단계 | 문구 |
|---|---|
| 끼니 규칙 | 세 끼 제때 먹기 · 대충 때우지 않고 차려 먹기 · 바쁜 날엔 간단한 한 끼 · 아침엔 따뜻한 한 그릇 |
| 식사 시각 | 저녁은 제때 먹기 · 저녁은 매일 같은 시간에 |
| 기름진 음식 기본 | 볶은 반찬 대신 나물무침 · 튀긴 고기 대신 생선구이 · 튀긴 닭 대신 삶은 닭 · 해물 튀김 대신 숙회 · 닭은 튀김 대신 구이로 |
| 짠맛 · 국물 | 찌개 대신 맑은 국 · 양념은 절반만 넣기 |
| 단백질 입문 | 끓일 때 달걀 하나 넣기 |
| 단 음료 입문 | 커피 설탕은 반만 |

정할 것: 반복 방지를 「가장 오래전에 나온 문구 먼저(한 번도 안 나온 문구가 맨 앞)」로 바꿀지. 바꾸면 목록 전체가 차례로 돎. 계약 V-45 · 설정 CFG-065 · 서버 코드가 같이 바뀜.

### 발견 2 — 서버 규칙 문서의 반복 방지 설명이 실제와 다르게 읽힘 [낮음]

「규칙 보기」 8.3은 「최근 30일 안 쓴 문구 → 오래전에 쓴 문구 → 데이터 순서」라고 적음. 「안 쓴 문구가 오래전에 쓴 문구보다 먼저」로 읽힘. 실제로는 30일 지난 문구와 처음 쓰는 문구를 같이 놓고 데이터 순서로 고름. 정확히 30일 전에 쓴 문구도 「최근」으로 봄.

### 발견 3 — 규칙 문서 예시가 1.0.4 기준 [낮음]

「규칙 보기」 예시는 1.0.4 데이터 기준. 1.1.1과 다른 곳:

- 「국 대신 나물 반찬」이 채소 입문 두 번째 문구라고 적었지만, 1.1.1에서는 기본 단계 문구.
- 새벽에는 끼니 규칙 「아침거리 꺼내 두기」와 식사 시각 「저녁 후 부엌 정리」뿐이라고 적었지만, 1.1.1에서는 새벽 3시에 채소 「내일 채소 꺼내 두기」가 나옴.

### 발견 4 — 영어 사용자는 긴 문장 · 이유 · 축 이름이 비어 있음 [참고]

1.1.1 데이터에 영문 긴 문장과 영문 이유가 0개. 영어 사용자 화면의 목표 카드에는 짧은 문구만 나옴. 회전 질문의 축 이름도 영어 응답에서 비어 있음. 규칙 문서 11.2에 「영문 없음」으로 적힌 알려진 한계.
