1배경과 목표

왜 이 화면이 필요한가

사람들은 건강검진을 받고 나서 결과지를 한 번 훑어보고 서랍에 넣습니다. 수치는 남아 있는데 그게 좋은 건지 나쁜 건지, 작년보다 나아진 건지 판단이 안 되기 때문입니다. 병원이나 공단 사이트에 다시 들어가는 일도 번거롭습니다.

목표는 단순합니다. 검진 결과를 앱 안으로 끌고 들어와, 사용자가 "내 몸 상태는 지금 이렇구나"를 한 번에 이해하고, 필요하면 다음 행동(위험도 분석, 항목별 상세, 올해 검진 예약)으로 이어지게 만드는 것입니다.

4화면 구성

세 가지 상태와 가져온 뒤의 카드 순서
①가져오기 전무엇을 볼 수 있는지 안내하고 가져오기를 권한다
②가져오는 중진행 상태와 예상 시간을 보여준다
③가져온 뒤건강 나이 → 위험도 분석 → 주요 소견 → 검진 안내
④이어지는 화면위험도 분석 · 전체 항목 · 항목 상세 · 검진 안내

4.1 카드 순서를 이렇게 잡은 이유

  • 건강 나이를 맨 위에 — 숫자 하나로 전체 인상을 먼저 준다. 실제 나이와의 차이를 같이 보여줘서 좋고 나쁨의 기준을 즉시 알 수 있게 한다.
  • 위험도 분석을 두 번째에 — 전체 인상을 본 직후가 "그래서 나는 뭐가 위험한가"가 가장 궁금한 순간이다.
  • 주요 소견을 세 번째에 — 근거가 되는 실제 수치. 왜 그런 건강 나이가 나왔는지 여기서 확인한다.
  • 검진 안내를 맨 아래에 — 결과를 다 본 뒤에 나오는 다음 행동. 위에 있으면 결과 읽기를 방해한다.

4.2 주요 소견에 넣는 항목

혈압 · 혈당 · 콜레스테롤 · 간 수치 · 신장 수치. 검진 항목 중 만성질환과 가장 직접 연결되고, 사용자가 이름만 들어도 무엇인지 아는 다섯 가지입니다. 나머지 항목은 전체 항목 보기로 넘깁니다.

항목마다 값 옆에 상태를 한 단어로 붙입니다. 사용자가 숫자를 해석할 필요 없이 "괜찮다 / 지켜봐야 한다 / 챙겨야 한다"를 바로 알 수 있게 하는 것이 이 카드의 핵심입니다.

5이어지는 화면

이 화면에서 나갈 수 있는 곳
진입점가는 곳거기서 하는 일
위험도 분석 배너셀비 체크업검진 결과를 근거로 10대 질환 위험도를 분석한 리포트를 본다. 외부 유료 서비스
소견 항목항목 상세해당 항목의 의미, 기준 범위, 지난 결과와 비교
전체 검진 항목 보기전체 항목 목록가져온 모든 항목을 본다
검진 안내 확인하기검진대상조회올해 받을 수 있는 일반검진·암검진 항목과 수검 여부를 본다

위험도 분석은 외부 서비스인 셀비 체크업이 담당한다. 검진 결과와 생활 습관 입력을 받아 유료 리포트를 주며, 검진요약은 진입까지만 책임진다. 검진대상조회는 공단 조회 결과를 그대로 보여주는 화면으로, 앱에서 대상 여부를 판단하지 않는다.

앱이 계산하는 값(건강 나이, 항목별 상태)은 무엇을 근거로 했는지 화면에서 확인할 수 있어야 합니다. 사용자가 납득하지 못하면 숫자 자체가 의미를 잃습니다.

7원칙

이 화면을 만들 때 지키는 것
  • 진단하지 않는다. 상태를 알려주되 병명을 붙이거나 치료를 권하지 않는다.
  • 겁주지 않는다. 좋지 않은 결과도 다음에 할 수 있는 일과 함께 전달한다.
  • 숫자를 숨기지 않는다. 쉬운 말로 요약하되 실제 수치를 항상 같이 보여준다.
  • 빈 상태도 화면이다. 데이터가 없을 때도 무엇을 얻을 수 있는지 먼저 보여준다.
  • 먼저 보여줄 것을 고른다. 모든 항목을 같은 무게로 늘어놓지 않는다.

10확인 필요

결정이 남아 있는 것
  • 가져온 검진 결과를 앱에서 얼마 동안 보관하고, 언제 다시 받아오도록 권할지
  • 공단에 검진 기록이 아예 없는 사용자에게 무엇을 보여줄지
  • 주요 소견 다섯 항목을 고정으로 둘지, 사용자 상태에 따라 바꿀지
  • 건강 나이를 계산할 수 없을 만큼 항목이 부족할 때 카드를 어떻게 처리할지
  • 검진 대상 안내를 대상이 아닐 때도 다른 문구로 보여줄지, 아예 감출지
