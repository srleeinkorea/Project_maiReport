식이 질문 QA 체크리스트

오늘의 질문 중 식이 질문이 기획대로 나오는지 확인하는 표예요. 케이스마다 조건대로 접속해 보고, 예상 결과와 다르면 실제 결과를 적은 뒤 근거 칸을 그대로 개발에 전달하면 돼요.

기준 문서식이 질문·목표 상세기획 v1.0.0, 식이 최종결정사항 v1.0.0, 식이 프로토타입 v1.0.0
끼니 기준 시각10시 · 12시 · 17시. 10시 전은 어제 저녁, 10~12시 오늘 아침, 12~17시 오늘 점심, 17시 이후 오늘 저녁
질문 수식이는 하루 최대 2개. 보통은 ① 고정 질문(끼니 양) + ② 회전 질문(행동 하나)
질환별 회전 질문고혈압 → 채소·국물, 당뇨병 → 채소·단 음료·간식·식사 속도·양, 이상지질혈증 → 식사 속도·양·기름진 음식, 만성 신장질환 → 없음. 같은 조건이면 질문 번호 순(채소 → 단 음료·간식 → 국물 → 야식 → 식사 속도·양 → 단백질 → 기름진 음식). 질환 축을 한 바퀴 돌면 다음 날은 일반 축 하나
노란 표시(확인 필요)가 붙은 케이스
  • 기획 문서끼리 또는 문서와 프로토타입이 서로 다르거나, 규칙이 정해지지 않은 부분이에요. 결과가 예상과 달라도 바로 버그로 넘기지 말고 기획에서 먼저 정해야 해요.
  • 목표 문구와 금지 성격은 데이터계약 엑셀의 목표문구·질환금지성격 시트가 기준이에요. 식이 프로토타입의 목표 문구는 아직 이 시트와 다르니(회복 문구, 금지 성격 표시 등) 목표 QA는 실제 앱으로 해 주세요.
  • 질문 문장과 답 버튼은 상세기획의 「축별 질문 8종과 선택지」 표를 정답으로 봐요. 식이 프로토타입은 채소·국물·기름진 음식·야식 문장이 이 표와 달라요(예: 프로토타입 「국물은 어느 정도」, 상세기획 「국물은 얼마나」). 프로토타입 문장이 실제 화면에 나오면 실패로 적어 주세요.
입력한 실제 결과와 판정은 이 브라우저에만 저장돼요. 다른 사람과 공유되지 않아요.
