개발 전달 모음

F · E · TBD로 판정된 케이스가 모여요. 그대로 복사해 개발에 전달하세요.

아직 기획과 다른 케이스가 없어요.
  • 질환별 연결 축 (질환연결축 시트): 고혈압 = 국물 → 채소 · 당뇨병 = 채소 → 단 음료·간식 → 식사 속도·양 · 이상지질혈증 = 기름진 음식 → 식사 속도·양 · 만성 신장질환 = 없음(금지만). 질문은 질문 번호 순서로 고르고, 목표는 그날 질문 축을 따라가요. 만성 신장질환은 연결 축이 없어요.
  • 질문 번호 순서 (질문 시트): 채소 → 단 음료·간식 → 국물 → 야식 → 식사 속도·양 → 단백질 → 기름진 음식. 야식은 오전 4~10시에만 물어요.
  • 금지 성격 (질환금지성격 시트): 당뇨병 = 공복·감량 · 만성 신장질환 = 증량·감량·수분. 회복 문구 7개는 모두 증량 성격이에요.
  • 노란 표시가 붙은 케이스는 기획 결정이 남은 항목이라, 예상과 달라도 자동 판정이 TBD예요.
  • 고른 결과는 이 브라우저에만 저장돼요. 다른 사람과 공유되지 않아요.
