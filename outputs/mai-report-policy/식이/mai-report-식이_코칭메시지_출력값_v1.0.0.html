식이 — 질문 전에 가진 값과 질문으로 얻는 값

식이는 두 종류의 값을 가집니다. 질문 전에 이미 들고 있는 값(시각·질환·검진·과거 기록)과, 질문해서 얻는 값(답 27개)입니다. 앞의 값으로 무엇을 물을지가 정해지고, 뒤의 값이 실제 지표가 됩니다.

질문 전에 이미 가지고 있는 값

사용자가 아무것도 누르기 전에 식이가 들고 시작하는 값들입니다. 무엇을 물을지, 어느 끼니를 물을지, 어떤 말을 막을지가 여기서 정해집니다. 크게 ① 지금 시각 ② 질환 ③ 검진 ④ 어제까지 쌓인 것 네 묶음입니다.
