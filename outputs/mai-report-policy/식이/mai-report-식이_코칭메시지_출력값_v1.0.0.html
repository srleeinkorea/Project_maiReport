식이 데이터 안내

다른 기능에서 식이의 값을 가져다 쓸 때 보는 문서입니다. 전체 구조로 어떤 값이 어디서 나오는지 보고, 표 1에서 데이터 목록을, 표 2에서 값마다의 뜻을, 표 3에서 질환 목록을 확인합니다. 용어는 데이터 계약서에 쓰인 그대로이고 설명만 풀어 적었습니다.

전체 구조

식이는 질문 전에 가지고 있는 값으로 무엇을 물을지 정하고, 사용자의 답을 받아 다른 기능이 가져다 쓸 값을 만듭니다. 세 단계입니다.

점선은 축적을 뜻합니다. 응답이 쌓여 축 상태가 되고, 목표 완료가 쌓여 목표 단계가 올라갑니다. 이 둘은 서로 섞이지 않습니다 — 축 상태는 질문에 답한 것으로만, 목표 단계는 목표를 완료한 것으로만 정해집니다.

단계무엇을 하나 무엇을 보고 정하나여기서 꼭 알아야 할 것
① 대상 끼니질문과 목표가 다룰 끼니를 정함 진입 시각 하나 새벽 진입이면 끼니 날짜가 어제입니다
② 질문 축그날 물을 행동 축 하나를 고름 질환 연결 축 · 검진 연결 축 · 응답 이력 질문 칸은 하루에 둘뿐이라, 질환 확인이 뜨면 평소 질문 하나가 밀립니다
③ 금지위험한 성격의 문구를 후보에서 제외 질환 정보 사용자 확인 전에도 이미 적용됩니다
④ 목표남은 문구에서 하루 한 개를 고름 질문 축 · 목표 단계 · 시간대 남은 문구가 없으면 목표 없이 안내만 나갑니다
