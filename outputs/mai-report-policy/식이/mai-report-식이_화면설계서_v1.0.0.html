재진입이미 답한 질문은 다시 노출하지 않음문항 상태의 effective_answer_id 사용
시간대 변경미응답 질문만 새 끼니 라벨로 갱신이미 답한 질문의 meal_date/type은 바꾸지 않음

오프라인답변을 확정 완료처럼 보이지 않게 하고 재전송 안내서버 저장 확인 후 목표 계산
접근성: 선택지는 최소 높이 48px, 선택 상태는 색상 외 테두리·라디오 표시로 함께 구분합니다. 진행 정보는 텍스트 1 / 2를 제공하고, 버튼과 선택지에 명확한 접근성 이름을 지정합니다.
