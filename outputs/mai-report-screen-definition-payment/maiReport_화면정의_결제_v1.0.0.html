03 · Screen Detail

ACC-004 · 이용권 관리

ACC-004

이용권 관리

계정 서브 화면
목적
보유 이용권 수를 확인하고, 구매하고, 이용권 내역(상태·시각)과 환불 경로를 제공한다.
진입
계정 메인 → ‘이용권 관리’.
범위
현 단계 Selvy Checkup 1종만 노출. ANRISK 제외.

구성요소

이용권 카드(tk-card)

아이콘 · ‘Selvy Checkup’ · 잔여 수(ticketCount() = status=AVAILABLE 개수) · [구매하기] → ACC-005.

가상 결제(디버그)

[가상 결제 (디버그 전용)] — 개발 빌드 한정. 릴리스 빌드 비노출.

이용권 내역(tk-hist)

이용권별 행: 상품명 · 상태 배지 · 시각 라인(상태에 따라 발급/예약/사용/취소 시각) · memo. 최신순.

환불 링크

status=AVAILABLE 인 이용권에만 [스토어에서 환불 신청] 노출. 탭 시 스토어 환불 화면 안내(ACC-005 계열 모달).

빈 상태

이용권 없음: “이용권 내역이 없습니다.”

상태 배지

상태배지시각 라인환불 링크
AVAILABLE사용 가능발급 {issued_at} (+ 만료 예정 {expires_at})노출
RESERVED사용 예약예약 {reserved_at}미노출(사용 개시 간주)
USED사용 완료사용 {used_at}미노출
CANCELED취소됨취소 {canceled_at} · memo미노출
EXPIRED기간 만료만료 {expires_at}미노출

데이터 바인딩 / 예외

입력
analysis_ticket(user 전체) · ticket.status/issued_at/reserved_at/used_at/canceled_at/expires_at/memo
파생
잔여 수 = status=AVAILABLE 개수(만료 제외)
조회 실패

이용권 목록 로드 실패: 잔여 수 ‘—’, 재시도. 구매하기는 유지.

만료 임박

expires_at 30일 이내 AVAILABLE 이용권: “{n}일 후 만료” 표기(정책 D1).

04 · Screen Detail

ACC-005 · 이용권 구매 확인

ACC-005

이용권 구매 확인

모달
목적
스토어 결제 시트 호출 전, 상품·가격을 확인시키는 사전 확인 모달.
진입
ACC-004 또는 SELVY-002의 [구매하기].

구성요소

제목

“Selvy Checkup 이용권 구매”

본문

“Selvy Checkup 분석 이용권 1회 · {스토어 표시가} 결제를 진행하시겠습니까?” + “구매 후 서버 검증이 끝나면 이용권 1장이 발급됩니다.”

[결제하기]

스토어 인앱결제 시트 호출 → 결제 완료 시 서버 영수증 검증 → 이용권 지급.

[취소]

모달 닫힘. 상태 변화 없음.

디버그 변형

가상 결제: “디버그 전용 가상 결제로 이용권 1장을 즉시 발급합니다. 실제 스토어 결제는 진행되지 않아요.” purchase.is_debug=true.

결제 결과 상태

결과purchase.status화면
결제 성공 + 검증 성공VERIFIED → GRANTED모달 닫힘, ACC-004 잔여 수 +1, 내역에 AVAILABLE 추가
결제 성공 + 검증 지연PENDING“결제 확인 중” 안내, 구매 복원 유도
결제 취소(사용자)—모달 유지 또는 닫힘, 변화 없음
결제 실패FAILED오류 안내 + 재시도. 이용권 미지급
중복 결제VERIFIED ×2지급 후 정책 8·9장 안내(중복분 환불)
표현

가격은 스토어 표시가를 그대로 노출(플랫폼 간 상이 가능, 보전 없음 — 정책 D9). 프로토타입의 ₩100은 테스트 가격이며 실제 가격은 스토어 상품 설정값.

05 · Screen Detail

SELVY-001 · 셀비 체크업 소개

SELVY-001

셀비 체크업 소개

서브 화면
목적
검진정보 기반 주요질환 위험도 분석 서비스를 안내하고 신청(SELVY-002)으로 연결한다.
진입
병원 → 진료요약 → ‘질환 위험 분석’ 카드.

구성요소

서비스 설명(svBody)

분석 대상 질환, 필요한 검진정보, 결과 형태(10년 단위 추이 등) 안내.

CTA

[주요질환 위험도 분석하기] → SELVY-002.

참고 정보 고지

“결과는 이해를 돕는 참고 정보이며 의학적 진단·의료진 판단을 대체하지 않습니다.” 상시 노출.

경계

셀비 체크업은 ‘질환 위험 예측’ 성격이 있어 maiReport 본체의 상태 서사·코칭과 분리해 별도 서비스로만 노출합니다(MRS 9장 경계 사례). 본체 카피에 위험 예측 표현을 쓰지 않습니다.

06 · Screen Detail

SELVY-002 · 분석 신청 · 결제

SELVY-002

분석 신청 · 결제

결제/신청 화면
목적
분석에 쓸 검진정보를 선택하고, 이용권을 확인·구매한 뒤 분석을 신청한다.
진입
SELVY-001 CTA.

구성요소

검진정보 선택

등록된 검진정보 목록에서 분석 대상 1건 선택. 없으면 등록 안내.

이용권 확인

잔여 이용권 ≥ 1: [분석 신청하기] 활성. 0: [구매하기] → ACC-005(결제 payGo 초기 disabled).

분석 신청

이용권 1장 RESERVED(예약=사용 개시 간주) → analysis_run REQUESTED 생성.

진행/완료

분석 진행 표시 → 완료 시 SELVY-003. 실패 시 이용권 AVAILABLE 복원 + 재시도.

상태

상태조건화면
신청 가능검진정보 선택됨 & 잔여 이용권 ≥ 1[분석 신청하기] 활성
이용권 필요잔여 0[구매하기] 노출 → ACC-005
검진정보 없음등록 검진정보 0검진 리포트 등록 안내
분석 실패analysis_run FAILED이용권 복원 + 재시도, 반복 실패 시 장애 환불 안내(정책 6장)

데이터 바인딩

입력
등록 검진정보 목록 · analysis_ticket(AVAILABLE 수) · analysis_run
쓰기
신청 시 ticket.status=RESERVED, analysis_run 생성. 완료 시 ticket.status=USED + result_ref

SELVY-003 · 셀비 체크업 결과

SELVY-003

셀비 체크업 결과

서브 화면
목적
선택 검진정보 기반 10대 질환 위험도 결과와 해석 안내를 제공한다.
진입
SELVY-002 분석 완료 · 분석 목록에서 과거 결과.

구성요소

결과 목록(rsBody)

질환별 위험도 지표·추이(10년 단위 등). 표현은 참고 정보 톤.
