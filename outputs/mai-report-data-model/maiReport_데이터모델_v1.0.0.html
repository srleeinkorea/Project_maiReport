01 · Scope & Notation

범위와 표기

포함

  • 지표 산출: 원천 건강 데이터, 개인 기준선, 지표 상태, 자가보고
  • 결제: 인앱결제 상품, 구매, 분석 이용권, 분석 실행, 환불 이벤트

  • 사용자·프로필·동의·권한 (user, profile)
  • 코칭·행동 로그, AI 인사이트, 검진·진료 원문
  • 스토어 결제 대금·영수증(스토어 사업자 소관)

02 · Domain Map

도메인 맵

metric_key지표명lowmidhighobservingdirection 비교 기준

low/mid/high는 순서 있는 등급이지만 지표 간 비교·합산 대상이 아닙니다(P5). 지표 2의 최종 명칭은 2026-09-11 ‘자기돌봄’으로 확정했습니다(C-1 종결). enum 값(self_care)과 표시명은 분리해 두었으므로 표시명이 바뀌어도 모델은 영향받지 않습니다.

표시 라벨은 저장하지 않습니다 — C-3 확정

어휘는 2026-09-11 문장형으로 확정했습니다(위 표). 기획서 7장의 명사형 표기는 이 결정에 맞춰 갱신 대상입니다.

어휘가 확정된 뒤에도 metric_state에는 state_key(low/mid/high/observing)만 저장하고 표시 문자열은 저장하지 않습니다. 라벨은 클라이언트·문구 템플릿이 state_key에서 렌더하므로, 문구가 나중에 다듬어져도 데이터 마이그레이션이 필요 없고 과거 스냅샷의 의미도 바뀌지 않습니다.

06 · Integrity Rules

무결성·정책 규칙

ID규칙근거
R1analysis_ticket.analysis_type = 연결 purchase.product.analysis_type. 타입 간 전환·차감 대체 불가결제 정책 3장
R2USED · CANCELED 는 종료 상태. USED→CANCELED 자동 전이 금지(악용 조항으로 별도 처리)결제 정책 5·6장
R3스토어 환불 알림 수신 시 해당 purchase_id의 AVAILABLE(및 RESERVED, 정책 v1.0) 이용권만 CANCELED결제 정책 5장
R4ticketCount(잔여) = status=AVAILABLE 개수프로토타입 ticketCount()
R5expires_at 경과 이용권은 USED 불가. 만료 30일 전 1회 고지(정책 v1.0)결제 정책 4장
R6metric_state 유니크 (user, metric_key, period_type, period_start, ruleset_version). 과거 스냅샷은 규칙 변경 시 재계산 안 함지표 기획서 8장
R7metric_state.resolution=none 이면 state_key=observing, direction·internal_value=null지표 기획서 8장
R8metric_baseline 미충족 입력은 상태 산출에서 제외. 지표별 필수 입력이 빠지면 지표 자체가 observing지표 기획서 3·8장
R9health_sample.quality ∈ {outlier,duplicate}는 집계 제외(원본 보존). 생리적 범위 밖 값은 윈저라이즈 후 사용·로그 기록지표 기획서 8장
R10건보공단·의료이력 데이터는 metric_state 산출 입력이 될 수 없음(맥락·안전장치로만)지표 기획서 3장
R11metric_key=self_care는 기준점 신호(식사 시각 또는 긴 비활동 종료·일정 전후) 와 활동 시간대 분포가 둘 다 있어야 산출. 걸음 총량만으로는 observing지표 기획서 3·5장
R12metric_key=life_steadying은 period_type=week 행만 생성. 일 단위 행 생성·일 단위 direction 금지지표 기획서 6·7장
R13value_scale=low_res는 life_margin에만 허용. high_res 행과 internal_value를 비교·차감·동일 시계열로 잇지 않음지표 기획서 2·8장
R14daily_checkin(자가보고)과 식사 기록은 state_key를 상향시키는 입력이 될 수 없음 — inputs_used의 role=aux로만 기록지표 기획서 1장 P1·P3
R15세 지표를 합산·평균한 종합 점수/종합 등급 엔터티를 두지 않음지표 기획서 1장 P5
