더보기는 건강 데이터를 해석하는 화면이 아니라 "내 계정과 앱 설정을 확인하고 바꾸는 화면"이다. 사용자 본인 → 데이터와 권한 → 서비스 안내와 환경 순으로 성격이 다른 묶음을 나누고, 계정을 벗어나는 동작(로그아웃 · 회원탈퇴)은 목록 밖에 따로 둔다. 이 문서는 더보기 목록과 내정보 화면의 구성 · 표시값 · 이동 · 예외를 정의한다.

1화면 개요

더보기의 역할과 묶음 순서

1.1 화면의 역할

더보기는 하루에 여러 번 여는 화면이 아니다. 필요할 때 들어와 "확인하고 · 바꾸고 · 나간다"는 세 가지만 한다. 건강 데이터 값, 지표 해석, 코칭은 두지 않는다. 목록 항목은 한 줄에 하나씩, 누르면 그 항목만 다루는 화면으로 넘어가는 구조를 지킨다.

1.2 묶음 순서

① 프로필이름 · 내정보 관리
② 데이터건강데이터 연동 · 검진 · 진료정보 연동 · 동의 관리
③ 서비스알림 관리 · 이용권 관리 · 언어
④ 안내공지사항 · 문의하기 · 약관 및 정책
⑤ 목록 밖로그아웃 · 앱 버전

위에서 아래로 "나 → 내 데이터 → 앱 사용 설정 → 안내" 순으로 간다. 동의 관리는 약관 옆이 아니라 연동 옆에 둔다. 사용자가 동의를 찾는 순간은 약관을 읽고 싶을 때가 아니라 "내 데이터가 어디로 가지?" 할 때이기 때문이다. 로그아웃은 설정 변경이 아니라 앱을 벗어나는 동작이므로 목록 카드에 넣지 않고 아래에 따로 둔다.

1.3 두 화면의 관계

더보기탭 바에서 진입. 목록만 보여준다
→ 내정보프로필 카드를 누르면 진입. 가입 정보 조회
→ 회원탈퇴내정보 안에서만 진입. 더보기 목록에는 두지 않는다

이 문서는 시안을 기준으로 쓰였다. 예시 화면(프로토타입)과 다른 지점은 아래와 같다.

4.3 언어

현재 적용 중인 언어 이름을 그 언어로 쓴다(한국어 · English). 지원 언어가 하나뿐인 동안에도 항목을 숨기지 않고 "한국어"를 그대로 보여준다.

4.3 값을 붙이지 않는 항목

동의 관리 · 알림 관리 · 공지사항 · 약관 및 정책에는 상태값을 붙이지 않는다. 동의와 알림은 항목이 여러 개라 한 줄로 요약하면 오해를 만들고, 공지 · 약관은 상태가 없기 때문이다.

6.2 값이 없을 때

값이 없는 행도 숨기지 않고 자리를 지키며 "등록 안 됨"으로 쓴다. 어떤 정보가 비어 있는지 사용자가 알 수 있어야 하기 때문이다. 이름이 없으면 "님"만 남기지 않고 화면 제목과 같은 자리를 비운 채 카드부터 보여준다.

6.3 수정

이 화면은 조회 전용이다. 행을 눌러도 아무 일도 일어나지 않고, 수정 버튼도 두지 않는다. 생년월일 · 연락처는 본인 확인을 거친 가입 정보라 앱 안에서 바로 바꾸지 않는다.

변경이 필요한 사용자가 돌아갈 곳이 없다. 문의 경로 안내를 이 화면에 둘지, 연락처 · 이메일만 재인증 후 변경할 수 있게 열지 결정이 필요하다(§10-1).

② 확인"로그아웃할까요? / 다시 로그인하면 지금까지의 기록을 그대로 볼 수 있어요" · [로그아웃] [취소]
③ 로그인 화면기기에 저장된 로그인 정보만 지운다

로그아웃은 서버에 쌓인 기록 · 리포트 · 연동 설정을 지우지 않는다. 다시 로그인하면 이전 상태로 돌아온다. 건강 데이터 연동은 기기 권한이므로 로그아웃으로 해제하지 않는다.

7.2 회원탈퇴

① 내정보에서 탭"회원탈퇴 ›". 더보기 목록에는 진입점을 두지 않는다
② 안내 화면사라지는 것과 남는 것을 나눠서 보여준다
③ 확인되돌릴 수 없음을 한 번 더 확인
④ 완료로그인 화면으로. 완료 안내 한 줄
구분내용
사라지는 것계정과 가입 정보, 질문 답변 · 목표 기록 · 지표 · 검진 · 진료 기록. 다시 가입해도 복구되지 않는다
멈추는 것건강 데이터 수집과 모든 알림. 마케팅 수신 동의도 함께 철회된다
남는 것법령에 따라 보관 기간이 정해진 기록. 보관 항목과 기간은 개인정보 처리방침을 따른다

탈퇴 안내 화면과 확인 문구의 최종 문안은 처리방침 확정본과 함께 맞춘다(§10-5).

8예외 상태

값을 못 읽거나 이동할 수 없을 때
상황처리
네트워크 없음 · 조회 실패목록 구조는 그대로 두고 상태값 자리만 비운다. 항목을 누르면 이동한 화면에서 각자 오류를 안내한다. 더보기 전체를 오류 화면으로 덮지 않는다
내정보 조회 실패이름과 카드 자리를 비운 채 다시 시도할 수 있게 한다. 이전에 받아 둔 값을 그대로 보여주지 않는다
건강 데이터 미연동상태값 "연동 안 함". 더보기에서는 연동을 권유하지 않는다(권유는 홈 · 생활 탭의 안내 카드가 맡는다)
공지 없음항목은 그대로 두고, 이동한 목록 화면에서 빈 상태를 안내한다
지원 언어 1개항목을 숨기지 않는다. 선택 화면에 현재 언어 한 줄만 보여준다
로그인 만료더보기 진입 시 로그인 화면으로 보낸다. 빈 값으로 목록을 보여주지 않는다

9화면 이동 규칙

들어오고 나가는 경로 정리
트리거결과
하단 탭 "더보기"더보기 진입. 하위 화면에 있다가 다시 누르면 더보기 목록으로 돌아온다
프로필 카드 탭내정보로 이동
내정보 뒤로가기더보기 목록으로. 스크롤 위치 유지
연동 상태 변경 후 복귀더보기의 연동 상태값을 새로 읽어 갱신한다
언어 선택 후 복귀선택한 언어로 전체 화면 문구를 바꾸고 더보기로 돌아온다
알림 · 공지 링크 진입공지사항 상세로 바로 이동. 뒤로가기는 공지사항 목록을 거쳐 더보기로 돌아온다
동의 철회 후 복귀더보기 목록은 그대로. 처리 결과는 알림(필수 안내)으로 따로 알린다
로그아웃 · 탈퇴 완료로그인 화면. 뒤로가기로 더보기에 돌아올 수 없다
