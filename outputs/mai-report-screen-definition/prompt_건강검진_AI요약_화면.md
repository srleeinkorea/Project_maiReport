# 프롬프트 — 건강검진 결과 AI 요약 화면 프로토타입

아래 내용을 그대로 복사해 AI에게 전달하면 현재 프로토타입의 "건강검진 결과 AI 요약" 화면과 같은 결과물을 만들 수 있다.
기존 앱 파일에 이식하는 경우와 단독 HTML로 만드는 경우 모두 쓸 수 있도록 작성했다.

---

## 역할과 목표

당신은 모바일 헬스케어 앱의 프로덕트 디자이너 겸 프론트엔드 개발자입니다.
건강검진 결과를 사용자 언어로 정리해 주는 **"건강검진 결과 AI 요약" 화면**을 단일 HTML 파일(HTML + CSS + JavaScript, 외부 라이브러리 없음)로 만들어 주세요.
모바일 UI 기준이며 최대 폭은 430px입니다. 파일을 열면 이 화면이 바로 보여야 합니다.

## 지켜야 할 원칙

1. **판정은 검진기관의 것입니다.** 정상·관리 필요·확인 필요 같은 상태는 검진 데이터의 판정과 기준 범위에서 규칙으로 정합니다. AI 문장이 새로운 판정을 만들지 않습니다.
2. **숫자는 코드가 그립니다.** 모든 수치·단위·기준 범위는 구조화된 데이터에서 렌더링하고, 자유 서술 문장에는 수치를 넣지 않습니다.
3. **진단하지 않습니다.** "고혈압입니다", "당뇨가 의심됩니다", "위험", "심각", "걱정 없어요" 같은 표현을 쓰지 않습니다. 행동 안내는 "의료진과 상의", "다음 검진에서 확인"까지만 합니다.
4. **불필요한 요소를 넣지 않습니다.** 빈 목록, "0개" 카드, 접기/펼치기 토글, 원본 보기 버튼, 안내 문구 박스, 카드 번호 라벨은 두지 않습니다. 설명이 필요하면 카드 안에 바로 보이게 합니다.
5. 문체는 짧고 차분한 존댓말("~이에요", "~해 주세요")입니다.

## 화면 구성 (위에서 아래로, 단일 스크롤)

### 0. 헤더
뒤로가기 버튼, 제목 "건강검진 결과 AI 요약".

### 1. 메타 + 예시 전환
- 검진일, 검진기관 두 칸을 같은 폭으로 나란히.
- "정상 예시 / 확인 필요 예시" 세그먼트 토글. 처음 열릴 때는 검진 데이터의 판정에 따라 자동 선택되고, 토글로 바꿔 볼 수 있습니다.

### 2. 종합 요약
- 섹션 제목: 작은 라벨 "이번 검진 한눈에 보기" + "종합 요약".
- 히어로 카드: 라벨 "AI 건강검진 요약", 두 줄 제목(고정 문장), AI 문장 정확히 두 개(첫 문장 = 무엇이 눈에 띄는지, 둘째 = 어떻게 받아들이면 되는지, 수치 없음), 아래 3칸 숫자 **정상 / 관리 필요 / 확인 필요**. 항목별 해석의 수치 검사 13개 + 그 밖의 검사 결과 5개 = 18개를 상태별로 세어 채웁니다(세 수의 합 = 18). 숫자 칸 아래 설명 문장은 두지 않습니다. 확인 필요 예시는 10 / 4 / 4, 정상 예시는 18 / 0 / 0. **별도의 "AI 한줄 정리" 카드는 만들지 않습니다.** 확인 필요 예시는 연한 분홍, 정상 예시는 연한 초록 배경.
- 확인 필요 예시: "우선 확인 항목" 카드에 순위 1·2·3으로 흉부 X선(검진기관 소견 "경화 소견 · 폐렴 의심", 태그 "재검 권고"), 혈압(134/86 → 140/90 → 148/94 mmHg, 높아짐), 공복혈당(112 → 119 → 128 mg/dL, 높아짐). 이 값은 4-1의 최근 5회 값 중 마지막 3개와 같아야 합니다. 판정형 검사의 재검 권고가 항상 1순위입니다.
- 정상 예시: "현재 상태" 카드에 혈압 118/76, 공복혈당 92, 총콜레스테롤 188, BMI 22.4를 2×2 격자로, 모두 정상.

### 3. 신체계측 (또래 비교)
- 섹션 헤더: 사람 아이콘, "신체계측", 부제 "내 또래와 비교한 내 신체 상태를 한눈에 확인해보세요." 안내 문구 "동일한 성별·연령대 100명을 기준으로 내 결과가 어느 위치에 있는지 보여드려요."는 헤더가 아니라 **카드 4장 아래**에 작게 둡니다.
- 키, 체중, BMI, 허리둘레 **각각 카드 하나**. 항목마다 고유 색: 키 파랑(#3B7BFF), 체중 초록(#22B08E), BMI 보라(#8B5CF6), 허리둘레 주황(#FF7A21).
- 카드 왼쪽(약 108px): 번호 원형 배지 + 항목명, 큰 수치와 단위, "내 또래 100명 중" 소제목 아래 **등수를 항목 색으로 크게**(예: 70등), 상태 배지("조금 큰 편이에요" / "무거운 편이에요" / "조금 높은 편이에요"). 배지는 평균 근처면 초록, 관리 필요면 주황.
- 카드 오른쪽: **사람 실루엣 5개**를 SVG로 직접 그립니다(이미지 파일 사용 금지). 5구간은 1~20등 / 21~40등 / 41~60등 / 61~80등 / 81~100등이고, 각 사람 아래에는 그 등수 구간 한 줄만(10px, 줄바꿈 없음) 씁니다. 구간 이름(작은 편·조금 작은 편·평균적인 편·조금 큰 편·큰 편)은 그림 아래에 쓰지 않고 왼쪽 상태 배지에서만 보여 줍니다. 내 구간의 사람만 진한 색이고 위에 "나" 말풍선이 붙으며, 그 아래 등수 구간 글자도 항목 색으로 굵게 표시합니다. 나머지는 같은 색의 연한 톤입니다.
- 사람 그림은 항목 특성이 바로 보여야 합니다.
  - 키: 사람 전체 크기가 작은 것부터 큰 것까지(0.55배 → 1배).
  - 체중: 몸 전체(몸통·팔·다리)가 홀쭉한 것부터 넓은 것까지.
  - BMI: 어깨는 비슷하고 몸통이 둥글게 차오르는 정도.
  - 허리둘레: 옆모습으로 배가 앞으로 나오는 정도.
- 검사의 의미나 건강상태 설명은 이 섹션에 넣지 않습니다.
- 응원 카드나 격려 문구는 두지 않습니다. 카드 4개로 섹션이 끝나고, 행동 안내는 5번 섹션에서만 합니다.
- 등수는 경계값표(국민건강영양조사 2022~2024 p1~p99, 성별×5세 구간)로 계산합니다: k = 값 이하 경계 개수 → P = k + 보간 → rank = round(P) 1~99 → band = ceil(rank÷20). health는 BMI <18.5 또는 ≥25, 허리둘레 여 ≥85/남 ≥90이면 warn. 예시 사용자 여자 42세(여자 40-44세 집단). 계산 결과: 정상 예시 = 키 164.2cm 70등, 체중 57.8kg 47등, BMI 21.4 40등, 허리둘레 71.0cm 29등. 확인 필요 예시 = 키 164.2 70등, 체중 69.3kg 81등, BMI 25.7 78등(warn), 허리둘레 86.0cm 80등(warn). 안내 문구 끝에 "출처: 국민건강영양조사 2022~2024".

### 4. 항목별 해석
- 섹션 제목 "항목별 해석", 부제 "검사마다 내 수치가 기준 범위 어디에 있는지 막대로 보여드려요." 그 아래 색 범례 한 줄(정상 / 관리 필요 / 확인 필요).
- **검사군 하나 = 카드 하나**, 검사군 안의 개별 검사는 **행**으로 나열합니다. 행마다 왼쪽에 검사명과 값+단위, 오른쪽에 그 검사만의 **기준 범위 막대**를 둡니다.
- 기준 범위 막대: 정상(연초록) / 관리 필요(연노랑) / 확인 필요(연분홍) 구간을 폭 비율대로 칠하고, 구간이 바뀌는 수치를 막대 아래 눈금으로 표시하며, 내 값 위치에 세로 마커를 찍습니다. 마커 색은 값이 놓인 구간의 색입니다.
- 행의 상태는 값이 놓인 구간에서 자동으로 정해지고, 카드 상단 배지(정상 / 관리 필요 / 확인 필요)는 행 중 가장 나쁜 상태를 따릅니다. 확인 필요·관리 필요 카드는 테두리 색으로도 구분합니다.
- 검사군과 행, 기준 범위(예시값):
  - 혈압: 수축기(정상 <120, 관리 필요 120~139, 확인 필요 ≥140, 축 90~180), 이완기(<80, 80~89, ≥90, 축 50~120)
  - 혈당: 공복혈당(<100, 100~125, ≥126, 축 60~200)
  - 콜레스테롤: 총콜레스테롤(<200, 200~239, ≥240, 축 120~300), LDL(<130, 130~159, ≥160, 축 50~220), HDL(**높을수록 좋음**: <40 확인 필요, 40~59 관리 필요, ≥60 정상, 축 20~100), 중성지방(<150, 150~199, ≥200, 축 50~300)
  - 간 기능: AST(≤40, 41~50, ≥51, 축 0~100), ALT(≤35, 36~45, ≥46, 축 0~100), γ-GTP(예시 사용자는 여성이므로 여 기준 ≤35, 36~45, ≥46, 축 0~90 / 남은 ≤63, 64~77, ≥78, 축 0~140)
  - 신장 기능: eGFR(**높을수록 좋음**, 2구간: <60 확인 필요, ≥60 정상, 축 30~120), 크레아티닌(2구간: ≤1.5 정상, >1.5 확인 필요, 축 0.4~2.5)
  - 빈혈: 혈색소(**양쪽이 나쁨**, 5구간, 여성 기준: <10 확인 필요, 10~11.9 관리 필요, 12~15.5 정상, 15.6~16.5 관리 필요, >16.5 확인 필요, 축 8~20 / 남성은 <12, 12~12.9, 13~16.5, 16.6~17.5, >17.5)
- 기준 범위는 국민건강보험공단 일반건강검진 판정기준(정상A / 정상B / 질환의심)을 그대로 따르고, 화면 이름은 정상 / 관리 필요 / 확인 필요로 씁니다. "경계"·"주의"라는 말은 쓰지 않습니다. 2구간 검사는 막대에 관리 필요 구간이 없습니다.
- 예시 값: 확인 필요 예시 = 혈압 148/94, 공복혈당 128, 총콜레스테롤 232, LDL 151, HDL 49, 중성지방 115, AST 28, ALT 31, γ-GTP 18, eGFR 88, 크레아티닌 1.0, 혈색소 11.6. 정상 예시 = 118/76, 92, 188, 108, 62, 97, 22, 19, 18, 96, 0.9, 13.2.
- 각 카드 하단: 해석 한 문장. 사용자 말투로 자연스럽게("혈압이 기준 범위를 넘었고, 최근 몇 년 사이 계속 오르고 있어요"처럼, "확인 필요 기준을 넘었고" 같은 딱딱한 표현은 피함. 수치 없이, 배지 판정과 어긋나지 않게 — 배지가 정상이면 "정상에 못 미친다"고 쓰지 않음, 확인 필요·관리 필요는 글자색으로 구분) + 검사 의미 한 문단을 연한 회색 박스로 **항상 표시**합니다. 토글 없음.
- 신체계측은 위 섹션에서 다뤘으므로 여기서 반복하지 않습니다.

### 4-1. 검사 행의 최근 5회 변화 (별도 섹션 없음)
- 항목별 해석의 **각 검사 행 오른쪽 끝에 화살표 버튼(›)**을 둡니다. 누르면 그 행 아래에 최근 5회 검진 값의 인라인 SVG 꺾은선이 펼쳐지고, 위에 "이전보다 높음 / 낮음 / 비슷함" 표시, 아래에 5개 값과 검진일(21.05 · 22.06 · 23.06 · 24.05 · 25.06)이 붙습니다. 마지막 점을 강조하고 선 색은 마지막 값이 놓인 구간 색을 따릅니다.
- 이전 검진이 없는 검사는 화살표를 두지 않습니다. 장기 변화를 별도 섹션으로 만들지 않습니다.
- 예시 값(확인 필요): 수축기 126→130→134→140→148, 이완기 80→82→86→90→94, 공복혈당 98→103→112→119→128, 총콜레스테롤 198→205→212→218→232, LDL 121→128→134→142→151, HDL 56→54→52→50→49, 중성지방 96→102→108→110→115, AST 24→25→26→27→28, ALT 22→24→27→29→31, γ-GTP 17→17→18→18→18, eGFR 95→93→91→90→88, 크레아티닌 0.9→0.9→1.0→1.0→1.0, 혈색소 12.8→12.5→12.2→11.9→11.6. 정상 예시는 안정적인 값(수축기 122→118, 공복혈당 94→92 등).

### 4-2. 그 밖의 검사 결과
- 항목별 해석 바로 아래 섹션. 작은 라벨 없이 제목 "그 밖의 검사 결과"만, 부제 "흉부 X선처럼 숫자 범위가 없는 검사는 검진기관의 판정과 소견을 그대로 보여드려요."
- 카드 하나, 카드 제목·아이콘 없이 행 목록만. 행: 검사명 · 소견 한 줄 · 상태 배지. 막대·그래프 없음. 확인 필요 행이 위로.
- 예시(확인 필요): 흉부 X선 "경화 소견 · 폐렴 의심 · 재검 권고" 확인 필요 / 요검사(요단백) "음성" 정상 / B형간염 "표면항체 있음 · 면역 상태" 정상 / 시력 "좌 0.8 / 우 1.0" 정상 / 청력 "좌·우 정상" 정상. 정상 예시는 다섯 개 모두 정상("특이 소견 없음", "음성", …).
- 카드 아래 해석 한 문장: "흉부 X선에 재검 소견이 있어요. 검진기관 권고에 따라 다시 확인해 주세요." / 정상이면 "모두 특이 소견이 없어요."
- 이 검사들은 종합 요약 숫자 칸과 우선 확인 항목, 행동에 수치 검사와 똑같이 포함됩니다.

### 5. 내가 해야 할 행동
- 섹션 제목 "내가 해야 할 행동", 부제 "검진기관 권고부터 순서대로 챙겨 보세요." (정상이면 "앞으로도 이렇게 챙겨 주세요.")
- 흰 카드 하나에 번호 목록 1~3개. 각 항목: 제목 한 줄, 설명 한 문장. 근거 태그는 화면에 표시하지 않고, 정렬만 검진기관 권고 → 일반 건강관리 안내 → 앱 안내 순으로 합니다.
- 확인 필요 예시: ① 흉부 X선 재검을 받으세요(검진기관 권고) ② 혈압을 다시 재 보세요(검진기관 권고) ③ 공복혈당은 진료로 확인하세요(검진기관 권고). 총콜레스테롤은 관리 필요(정상B)라 검진기관 권고로 쓰지 않습니다. 상한 3개라 일반 안내(체중·허리둘레)는 밀려납니다. 검진기관 권고는 절대 빼지 않습니다.
- 정상 예시: ① 지금 습관을 이어가세요(일반 안내) ② 다음 검진 일정을 확인하세요(앱 안내) ③ 이번 결과를 보관하세요(앱 안내).
- 재검 날짜나 진료 기한을 지어내지 않습니다.

### 6. 면책
한 문장: "AI 요약은 검진 결과를 이해하기 쉽게 정리한 참고 정보이며, 의학적 진단을 대신하지 않아요. 걱정되는 항목은 의료진과 상담해 주세요."

## 디자인

- 세부 시각 디자인(크기·색·간격·서체)은 지정하지 않습니다. 기존 앱의 톤앤매너를 따르되 디자이너 재량으로 정합니다.
- 지켜야 할 것은 세 가지뿐입니다. ① 정상 / 관리 필요 / 확인 필요 세 상태가 배지·막대·마커·글자색에서 같은 톤으로 일관되게 구분될 것. ② 신체계측 항목마다 고유 색 하나로 번호·등수·사람 그림·말풍선이 묶일 것. ③ 한글은 어절 단위로 줄바꿈할 것.

## 진입 흐름 (기존 앱에 이식할 때)

- 검진 상세 화면의 CTA "ChatGPT로 결과 요약하기"를 누르면 **전송 동의 바텀시트**가 열립니다. 최초 1회는 보내는 것(검사 수치·판정·기관 소견) / 안 보내는 것(이름·생년월일·연락처) / 처리(외부 AI, 결과만 저장) 세 줄과 "자세히 보기", 버튼 "취소 / 동의하고 요약하기". 두 번째부터는 제목과 "요약하기" 버튼만.
- 동의 후 전체 화면을 막지 않고 CTA 자리에서 3단계(검사 정보 확인 → 검사 결과를 쉽게 정리하고 있어요 → 수치·판정 검증)가 진행되고, 끝나면 결과 화면이 자동으로 열립니다. 검진 상세에는 한 줄 결론과 "요약 보기 ›" 버튼이 남습니다.
- 검진 1건에 요약 1개만 만들고, 이미 있으면 확인 없이 바로 엽니다.
