2 내정보 (MORE-010)

카카오 계정에서 연동한 사용자 정보를 조회하는 화면. 조회 전용이며 수정 기능은 제공하지 않음. 하단에 관리 중인 질환 입력 및 회원탈퇴 진입 경로를 둠.

화면 동작

구분내용
제공 기능가입 정보 조회, 관리 중인 질환 입력 화면 이동, 회원탈퇴 화면 이동
수정 불가이름 · 생년월일 · 연락처 · 이메일 주소는 카카오 계정 정보에서 연동해 오는 값이므로 수정 불가. 별도 안내 문구 없음
항목 순서생년월일 → 연락처 → 이메일 주소 (고정)
관리 중인 질환‘건강 정보’ 영역에 표시. 미입력 또는 모두 해제 시 ‘없음’, 3개 이상은 ‘고혈압, 당뇨병 외 1’ 형식
회원탈퇴다른 메뉴와 분리 배치하여 오선택 방지
이메일 미등록카카오 가입 시 이메일 제공 미동의 → ‘등록 안 됨’ 표시
조회 실패‘정보를 불러오지 못했어요’ 문구 및 재시도 버튼 표시

표시 정보

3 관리 중인 질환 입력 (MORE-011)

현재 치료 중이거나 정기적으로 확인 중인 질환을 사용자가 직접 선택하는 화면. 고정된 4개 항목(고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환) 중 복수 선택 가능하며, 1개 이상 선택 시 저장 가능함.

화면 동작

구분내용
화면 제목‘현재 치료·관리 중인 질환을 모두 선택해 주세요.’ (‘만성질환’ 용어 미사용, 완치된 과거 질환 제외)
선택 항목고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환 4개로 고정, 복수 선택 가능. ‘해당하는 질환이 없어요’ 버튼 없음
저장선택이 없으면 비활성, 1개 이상 선택 시 활성화. 저장 후에는 변경 시에만 활성화. 모두 해제 후 저장 가능(‘없음’). 완료 시 ‘저장했어요’ 안내
이전 화면저장하지 않은 선택은 폐기 후 내정보로 이동
활용 범위사용자 입력값이며 의료진 진단이 아님. 목표 추천 · 주의 문구에만 활용
저장 실패‘저장하지 못했어요. 잠시 후 다시 시도해 주세요’ 안내, 선택 내용 유지

표시 정보

항목출처표시 기준
선택 질환사용자 직접 선택복수 선택 가능
최종 저장일저장 시점 기록1회 이상 저장한 경우에만 표시

4 동의 관리 (MORE-040)

필수 동의 3종의 동의일을 확인하고, 선택 동의 2종을 켜고 끄는 화면.

화면 동작

구분내용
필수 동의서비스 이용약관 · 개인정보 수집 · 이용 · 민감정보 처리. 동의일만 표시, 변경 불가. 철회는 회원탈퇴로만 가능
선택 동의마케팅 정보 수신 · 서비스 품질 향상을 위한 데이터 활용. 스위치로 즉시 변경, 켜짐 시에만 동의일 표시
확인 필요민감정보 처리 항목의 수집 항목 설명을 화면에서 제외함 → 법무 검토 시 재확인

표시 정보

항목출처표시 기준
필수 동의 3종가입 시 동의동의일만 표시
마케팅 정보 수신선택 동의켜짐 시 동의일 표시
데이터 활용선택 동의켜짐 시 동의일 표시

5 알림 관리 (MORE-050)

알림을 필수와 선택으로 나눠 보여주는 화면. 필수 알림(공지사항)은 항상 켜져 있어 끌 수 없고, 선택 알림(오늘의 목표 알림)만 켜고 끌 수 있음.

화면 동작

구분내용
공지사항 (필수)항상 켜짐, 스위치 비활성으로 끌 수 없음을 표시
오늘의 목표 알림 (선택)스위치로 즉시 변경, ‘매일 저녁’
광고성 알림이 화면에 두지 않음. 동의 관리의 ‘마케팅 정보 수신’에서만 변경
알림 목록공지 알림을 눌러도 공지사항 화면으로 이동하지 않고 목록에서 내용만 표시

표시 정보

항목출처표시 기준
공지사항필수 알림항상 켜짐 · 스위치 비활성
오늘의 목표 알림선택 알림스위치 · ‘매일 저녁’

7 회원탈퇴 (MORE-020)

탈퇴 여부를 한 번 확인하는 화면. 진입 즉시 ‘정말 탈퇴하시겠어요?’와 삭제 · 복구 불가 안내를 보여주고, 탈퇴하기 선택 시 바로 탈퇴 처리함.

화면 동작

구분내용
확인 문구‘정말 탈퇴하시겠어요?’ / ‘회원탈퇴 시 모든 개인정보가 삭제되며 복구할 수 없어요.’ (확인 체크 · 사유 설문 없음)
탈퇴하기바로 탈퇴 처리 → 데이터 연동 · 알림 · 마케팅 수신 동의 일괄 해지 → 탈퇴 완료 화면
취소내정보로 이동
탈퇴 실패안내 후 현재 화면 유지
확인 필요법령상 보관 기록 · 미사용 이용권 소멸 안내 제외 → 처리방침 · 약관 고지로 충분한지 법무 검토
