1 더보기 · 프로필 카드 (MORE-001)

더보기 탭 최상단에 위치한 카드. 사용자 이름과 ‘내정보 관리’ 안내 문구를 표시하며, 카드 선택 시 내정보 화면으로 이동함.

화면 동작

구분내용
진입 경로하단 더보기 탭 → 최상단 프로필 카드
선택 시내정보 화면으로 이동

표시 정보

항목출처표시 기준
이름가입 정보항상 표시

검토 사항

구분내용
신규더보기는 프로필 카드 아래 ‘연동’ · ‘서비스’ · ‘법적 정보 및 기타’ 3개 묶음으로 구성함.
사용성연동: 건강데이터 · 검진 · 진료정보. 연동된 대상 이름을, 미연동 시 ‘미연동’을 표시함.
사용성서비스: 동의 관리 · 알림 관리 · 이용권 관리(보유 장수) · 언어(한국어).
사용성법적 정보 및 기타: 서비스 이용 약관 · 개인정보 처리방침 · 개인정보 수집 및 이용동의를 각각 별도 항목으로 둠.
신규공지사항 · 문의하기 메뉴는 두지 않음.
사용성카드에는 이름만 표시함. 연락처 · 이메일은 내정보 화면에서만 표시함.

2 내정보 (MORE-010)

카카오 계정에서 연동한 사용자 정보를 조회하는 화면. 조회 전용이며 수정 기능은 제공하지 않음. 하단에 관리 중인 질환 입력 및 회원탈퇴 진입 경로를 둠.

화면 동작

구분내용
제공 기능가입 정보 조회, 관리 중인 질환 입력 화면 이동, 회원탈퇴 화면 이동
미제공 기능이름 · 생년월일 · 연락처 · 이메일 주소 수정 (카카오 계정 정보에서 연동)
관리 중인 질환 표시미입력 또는 모두 해제: ‘없음’ / 선택 시: 질환명 (3개 이상은 ‘외 N’)

예외 상황

상황처리
이메일 미등록카카오 가입 시 이메일 제공 미동의 → ‘등록 안 됨’ 표시
정보 조회 실패‘정보를 불러오지 못했어요’ 문구 및 재시도 버튼 표시

표시 정보

항목출처표시 기준
이름카카오 계정 정보항상 표시
생년월일카카오 계정 정보값이 없으면 ‘등록 안 됨’
연락처카카오 계정 정보값이 없으면 ‘등록 안 됨’
이메일 주소카카오 계정 정보 (제공 동의 시)값이 없으면 ‘등록 안 됨’
관리 중인 질환사용자 직접 입력미입력 시 ‘없음’

검토 사항

구분내용
사용성이름 · 생년월일 · 연락처 · 이메일 주소는 카카오 계정 정보에서 연동해 오는 값이므로 앱에서 수정 불가. 화면에 별도 안내 문구는 두지 않음.
사용성항목 순서는 생년월일 → 연락처 → 이메일 주소로 고정함.
신규‘건강 정보’ 영역에 관리 중인 질환 항목을 신규 추가함. 선택 질환이 3개 이상인 경우 ‘고혈압, 당뇨병 외 1’ 형식으로 축약 표시함.
사용성회원탈퇴는 다른 메뉴와 분리 배치하여 오선택을 방지함.

3 관리 중인 질환 입력 (MORE-011)

현재 치료 중이거나 정기적으로 확인 중인 질환을 사용자가 직접 선택하는 화면. 고정된 4개 항목(고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환) 중 복수 선택 가능하며, 1개 이상 선택 시 저장 가능함.

화면 동작

구분내용
선택 항목고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환 4개로 고정
선택복수 선택 가능
저장저장하기 버튼은 비활성 상태로 시작하며, 1개 이상 선택 시 활성화. 이후 변경 사항이 있을 때만 활성화. 저장 완료 시 ‘저장했어요’ 안내
이전 화면미저장 선택 내용 폐기 후 내정보로 이동

예외 상황

상황처리
저장 실패‘저장하지 못했어요. 잠시 후 다시 시도해 주세요’ 안내, 선택 내용 유지

표시 정보

항목출처표시 기준
선택 질환사용자 직접 선택복수 선택 가능
최종 저장일저장 시점 기록1회 이상 저장한 경우에만 표시
진료정보 연동 여부검진 · 진료정보 연동 상태연동 시에만 재확인 안내 표시

검토 사항

구분내용
사용성화면 제목: ‘현재 의료진에게 진단받아 치료받거나 정기적으로 확인 중인 질환을 모두 선택해 주세요’. ‘만성질환’이라는 용어를 쓰지 않고, 선택 기준(현재 · 의료진 진단 · 치료 또는 정기 확인)을 문장으로 안내함. 완치된 과거 질환은 제외됨.
사용성화면 문구는 제목 · 선택 방법 안내 한 줄 · 저장 버튼으로 최소화함.
사용성진료정보 미연동 시 별도 안내 문구를 표시하지 않음. 연동 시에만 ‘진료 기록과 다르면 한 번 더 여쭤볼게요’를 표시함.
신규선택 항목은 4개(고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환)로 고정함. 그 외 질환은 직접 선택 대상에서 제외함.
신규‘해당하는 질환이 없어요’ 버튼은 두지 않음.
사용성저장하기 버튼은 선택이 없으면 비활성, 1개 이상 선택하면 활성화함. 이미 저장한 질환을 모두 해제하는 경우에도 저장 가능하며 ‘없음’으로 표시함. 저장 없이 이전 화면으로 이동 시 선택 내용은 폐기함.
주의본 정보는 의료진 진단이 아닌 사용자 입력값임. 목표 추천 및 주의 문구에만 활용하며 건강 판단의 근거로 사용하지 않음.
신규진료정보 연동 시 진료 기록의 진단명과 비교하고, 불일치할 경우 ‘오늘의 질문’으로 재확인함.

4 동의 관리 (MORE-040)

필수 동의 3종의 동의일을 확인하고, 선택 동의 2종을 켜고 끄는 화면.

화면 동작

구분내용
선택 동의스위치로 즉시 변경
필수 동의변경 불가, 철회는 회원탈퇴로만 가능

표시 정보

항목출처표시 기준
필수 동의 3종가입 시 동의동의일만 표시
마케팅 정보 수신선택 동의켜짐 시 동의일 표시
데이터 활용선택 동의켜짐 시 동의일 표시

검토 사항

구분내용
사용성필수 동의에는 ‘필수’ 표시를 따로 두지 않음 (묶음 제목으로 구분).
사용성선택 동의는 스위치로 상태를 표시하므로 ‘미동의’ 문구를 두지 않음.
주의민감정보 처리 항목의 수집 항목 설명을 화면에서 제외함. 법무 검토 시 재확인 필요.

5 알림 관리 (MORE-050)

알림을 필수와 선택으로 나눠 보여주는 화면. 필수 알림(공지사항)은 항상 켜져 있어 끌 수 없고, 선택 알림(오늘의 목표 알림)만 켜고 끌 수 있음.

화면 동작

구분내용
공지사항끌 수 없음 (스위치 비활성)
오늘의 목표 알림스위치로 즉시 변경

표시 정보

항목출처표시 기준
공지사항필수 알림항상 켜짐 · 스위치 비활성
오늘의 목표 알림선택 알림스위치 · ‘매일 저녁’

검토 사항

구분내용
사용성필수 알림도 목록에 보여주되 스위치를 비활성으로 두어, 끌 수 없는 알림임을 알 수 있게 함.
사용성광고성 알림은 이 화면에 두지 않고 동의 관리의 ‘마케팅 정보 수신’에서만 변경함.
신규알림에서 공지 알림을 눌러도 공지사항 화면으로 이동하지 않고 목록에서 내용만 보여줌.

6 이용권 관리 (MORE-060)

보유 이용권 수와 이용권 내역을 확인하는 화면. 무료 이용권 1장이 자동으로 지급되어 있음.

화면 동작

구분내용
무료 이용권1장 자동 지급, 구매 버튼 없음
환불 신청사용 가능한 이용권에만 표시, 스토어 환불 화면으로 이동

표시 정보

항목출처표시 기준
보유 이용권이용권 내역N장
이용권 내역구매 · 사용 · 취소 기록상태와 날짜 (시각 제외)
정가상품 정보25,000원

검토 사항

구분내용
신규무료 이용권 1장을 자동 지급함 (내역에 ‘무료 지급’으로 표시, 환불 신청 없음). 구매 버튼과 별도 안내 문구는 표시하지 않음.
사용성사용 가능한 이용권에만 ‘환불 신청’을 표시하며, 선택 시 스토어 환불 화면으로 이동함.

7 회원탈퇴 (MORE-020)

탈퇴 여부를 한 번 확인하는 화면. 진입 즉시 ‘정말 탈퇴하시겠어요?’와 삭제 · 복구 불가 안내를 보여주고, 탈퇴하기 선택 시 바로 탈퇴 처리함.

화면 동작

구분내용
탈퇴하기바로 탈퇴 처리 → 탈퇴 완료 화면으로 이동
취소내정보로 이동

예외 상황

상황처리
탈퇴 처리 실패안내 후 현재 화면 유지

검토 사항

구분내용
사용성안내는 ‘회원탈퇴 시 모든 개인정보가 삭제되며 복구할 수 없어요.’ 한 문장으로 최소화함. 확인 체크 단계는 두지 않음.
신규탈퇴 시 데이터 연동, 알림, 마케팅 수신 동의를 일괄 해지함.
주의법령상 보관 의무 기록 · 미사용 이용권 소멸 안내는 화면에서 제외함. 개인정보 처리방침 · 이용약관 고지로 충분한지 법무 검토 필요.
사용성탈퇴 사유 설문은 두지 않음.

8 탈퇴 완료 (MORE-021)

탈퇴 처리 완료를 안내하는 최종 화면. 버튼 선택 시 초기(로그인) 화면으로 이동함.

화면 동작

구분내용
처음 화면으로로그인 화면으로 이동

검토 사항

구분내용
사용성본 화면에서 뒤로 가기를 통한 앱 내부 복귀는 불가함.
