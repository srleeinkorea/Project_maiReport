Functional Specification

목표 이어가기
기능 정의

생활 › 목표 분석의 주간 달성률을 대체하는 기능군입니다. 목표 실행 기록, 연속일수 산출, 코멘트 선택, 데이터 네 영역으로 나눠 트리거 · 입력 · 처리 · 출력 · 예외를 정의합니다. 모든 기능은 목표 분석 화면에 속하며, 완료 처리 · 완료 취소 · 문구 잠금 · 연속일수 계산 · 목표 기록 저장 · 홈 카드와 계산 공유는 홈 목표 카드에도 그대로 적용됩니다.

01

목표 실행 기록

사용자가 그날의 목표를 완료로 남기고, 그 기록이 집계의 입력이 되는 구간입니다.

GOAL-001오늘의 목표 완료 처리검토
선택 날짜의 카테고리별 목표를 완료로 기록하고 관련 집계를 갱신한다.
트리거
미완료 상태의 목표 영역 터치 — 별도 완료 버튼을 두지 않고 카드 전체가 터치 영역
입력
사용자, 카테고리(식이 · 활동 · 수면), 기준일, 그날 제시된 목표 문구
처리
완료 여부 저장 → 목표 문구 잠금(문구 잠금) → 완료 카운터 갱신 → 완료 날짜를 기준으로 연속일수 재계산 요청(연속일수 계산) → 코멘트 재평가 요청(상황 평가)
출력
체크 표시가 채워지고 본문이 흐려진 완료 상태 카드, 갱신된 이어가기 블록과 코멘트
예외
과거 날짜는 허용하고 미래 날짜만 불가 — 날짜 스트립으로 이동한 날에 그대로 기록한다 · 연타 시 마지막 상태만 반영 · 저장 실패 시 카드 상태를 이전으로 복구하고 재시도 안내 · 터치 영역 안의 링크나 보조 동작을 두지 않아 오터치를 막는다
GOAL-002완료 취소확정
완료 상태의 목표를 같은 영역 재터치로 되돌리고 관련 집계를 재계산한다.
트리거
완료 상태의 목표 영역 재터치 — 완료와 같은 영역을 쓰는 토글
입력
사용자, 카테고리, 취소 대상 날짜
처리
완료 해제 → 목표 문구 잠금 해제(문구 잠금) → 완료 카운터 감소 → 취소 날짜를 기준으로 연속일수와 최장 기록 재계산 → 코멘트 재평가
출력
미완료 상태로 돌아간 카드, 갱신된 집계와 코멘트
예외
과거 날짜도 취소 허용 — 날짜 스트립으로 볼 수 있는 날은 모두 되돌릴 수 있다 · 재계산 실패 시 취소 전 상태로 원복 · 별도 확인 대화상자를 두지 않는다(되돌리기가 같은 동작이므로)
GOAL-003목표 문구 잠금확정
완료 처리한 목표의 문구와 상태를 그날 동안 고정한다.
트리거
완료 처리 성공
입력
기준일, 카테고리, 그날 제시된 문구
처리
제시 문구 보존 → 개인화 교체 대상에서 제외 → 잠금 상태 유지
출력
문구가 고정된 완료 카드
예외
완료 취소 시 잠금 해제 · 날짜가 바뀌면 잠금 종료 · 사용자가 실제로 한 행동과 화면 문구가 어긋나지 않도록 교체하지 않는다
02

연속일수 산출

완료 이력에서 이어가는 일수를 계산하고 타일 표시 상태를 정하는 구간입니다. 주 경계와 무관하게 동작합니다.

STREAK-001연속일수 계산검토
카테고리별로 완료가 이어진 날 수를 산출한다.
트리거
화면 진입, 완료·취소 처리, 기준일 변경
입력
사용자, 카테고리, 기준일, 완료 이력
처리
기준일 완료 시 그날부터 · 미완료이고 전날 완료 시 전날부터 · 둘 다 미완료면 0 → 과거로 역산하되 완료면 일수 +1, 완료 기록이 없으면 종료 (목표가 생성되지 않은 날도 완료 기록이 없으므로 동일하게 종료)
출력
카테고리별 현재 연속일수, 연속 시작일
예외
주·월 경계에서 리셋하지 않음 · 기준일이 끝나기 전에는 끊김 처리하지 않음 · 건너뛰기 규칙 없음(2026-09-16 확정 — 목표 없는 날을 따로 저장하지 않는다) · 이 숫자는 실천이 아니라 기록이 이어진 날을 센다
STREAK-002최장 기록 산출 및 보존검토
완료 이력 전체에서 최장 연속일수를 계산하고 연속이 끊겨도 보존한다.
트리거
완료·취소 처리
입력
카테고리별 완료 이력 전체, 현재 연속 구간
처리
현재 진행 중인 연속 구간을 제외한 과거 최장 연속 구간 산출(이전 최장 기록) → 현재 연속일수와 비교 → 연속일수가 이전 최장 기록보다 크면 경신
출력
카테고리별 최장 기록, 이전 최장 기록, 경신 여부
예외
비교 대상은 현재 연속을 뺀 과거 최장이다 — 현재 연속을 포함해 계산하면 둘이 항상 같아져 경신이 영원히 성립하지 않는다(상황 평가 상황 4가 동률을 제외하기 때문) · 과거 기록이 없으면 이전 최장 기록을 0이 아니라 “해당 없음”으로 두어 1일째에 “지금까지 가장 길게”가 나오지 않게 한다 · 연속이 끊겨도 최장 기록은 삭제하지 않음 · 완료 취소 시 취소 날짜 기준으로 재계산 · 성능을 위해 증분 갱신 여부 결정 필요
STREAK-003기준일 이동 재계산확정
날짜 스트립으로 기준일을 바꾸면 그 시점 기준으로 다시 계산한다.
트리거
날짜 스트립에서 날짜 선택, 주 이동
입력
선택일, 완료 이력
처리
기준일 설정 → 오늘의 목표를 그날 기록으로 교체 → 세 카테고리 연속일수 재계산 → 코멘트 재평가
출력
선택일 기준으로 구성된 두 블록
예외
미래 날짜 선택 비활성 · 세 타일이 반드시 같은 기준일을 사용해야 값이 어긋나지 않음 · 날짜를 옮기면 일수가 달라지는 것이 정상(그 시점 기준) · 대신 보조 문구를 O월O일까지로 바꿔 현재진행형과 구분한다 — 타일 상태 판정
STREAK-004타일 상태 판정검토
연속일수와 이력 유무로 타일의 주요 표시와 보조 문구를 정한다.
트리거
연속일수 산출 완료
입력
연속일수, 완료 이력 유무, 연속 시작일, 기준 주, 기준일이 오늘인지 과거인지
처리
이력 0건 → 시작 전 · 연속 0 → 다시 시작 · 기준일이 과거 → N일째 / O월O일까지 · 시작일이 기준 주 이전 → N일째 / 시작일(O월O일)로부터 · 그 외 → N일째 / 이어가는 중
출력
타일 주요 표시, 보조 문구, 보조 문구 색
예외
0일째를 표시하지 않음 · 과거 기준일에 이어가는 중을 쓰지 않는다 — 그 뒤로 끊겼을 수 있어 현재진행형이 거짓이 된다 · 시작일 표기 조건을 “지난주”에서 “기준 주 이전”으로 확대 필요 · 연속과 일째 어휘 통일 필요
03

코멘트 선택

상태를 평가해 상황 0~9 중 하나를 고르고 문구와 카테고리 구분 표시를 확정하는 구간입니다.

CMT-001상황 평가 및 우선순위 선택검토
상황 0~9 중 충족하는 최상위 하나를 고른다. 기준일이 오늘일 때만 적용한다.
트리거
이어가기 블록 렌더링, 완료·취소 처리, 기준일 변경
입력
기준일, 목표 생성 여부, 완료 이력 유무, 최근 방문일, 카테고리별 연속일수, 최장 기록, 마디 목록
처리
기준일이 과거면 이 목록을 건너뛰고 기준일 이동 재계산의 과거 모드 문구를 쓴다. 오늘이면 0 목표 없음 → 1 첫 기록 전 → 2 오랜만의 방문 → 3 마디 도달 → 4 최장 기록 경신 → 5 마디 하루 전 → 6 세 카테고리 동률 → 7 두 카테고리 동률 → 8 가장 긴 기록 하나 → 9 현재 연속 없음 순으로 평가하여 최초 충족 항목 확정 (번호는 화면정의서 예시 화면 00~09와 같다)
출력
선택된 상황 코드, 대상 카테고리 목록
예외
동시 충족 시 상위 1개만 노출 · 동률은 하나를 임의로 고르지 않고 묶어서 처리 · 상황 0은 세 카테고리 목표가 모두 없을 때만 성립(일부만 없으면 해당 타일만 비활성) · 상황 2은 방문 기록 수집(방문 기록 수집)이 전제이고 방문일 기준이라 과거 모드에서는 평가하지 않는다 · 상황 4는 연속일수가 이전 최장 기록보다 클 때만 성립한다 — 초과만, 동률은 제외(동률이면 상황 8가 뜬다) · 이전 최장 기록은 지금 이어가는 중인 연속을 뺀 과거 최장 일수이며(최장 기록 산출) 과거 기록이 없으면 상황 4 자체가 해당 없음 · 마디는 7 · 14 · 30 · 50 · 100 · 150 · 200 · 250 · 300 · 365이고 그 뒤로는 365의 배수 · 상황 3는 오늘 완료 상태에서 연속일수가 마디 값과 정확히 같을 때만 성립(15일째에 14를 다시 띄우지 않음) · 같은 날 둘 이상이 마디에 닿으면 마디 값이 큰 쪽 하나만, 값이 같으면 묶어서 말한다 · 상황 4의 동시 경신도 같은 규칙
CMT-002코멘트 문구 생성검토
선택된 상황의 제목과 본문을 실제 값으로 채워 만든다.
트리거
상황 코드 확정
입력
상황 코드, 대상 카테고리, 연속일수, 마지막 완료일, 도달 마디 값, 기준일 완료 여부
처리
상황별 템플릿 선택 → 날짜·일수 치환 → 기준일이 오늘이고 아직 미완료면 “오늘도 하면 N+1일째예요” 한 문장을 덧붙임 → 금지 어휘와 부정형 검사
출력
코멘트 제목과 본문 1~2줄
예외
금지 어휘(달성률 · 실천 점수 · 순응도 · 의지력 · 꾸준히 · 완주) 포함 시 배포 차단 · 부정형 금지 · 건강 효과 주장과 감탄사 금지 · 끊긴 것은 문장에 올리지 않되 상황 9만 예외 · 기준일이 과거면 미래형 문장(“내일도” · “오늘 하면” · “오랜만이에요”)을 쓰지 않는다 · 같은 권유를 여러 상황에 반복하지 않는다
CMT-003코멘트 카테고리 구분 표시확정
코멘트가 언급하는 카테고리 수로 카드 배경을 정한다.
트리거
문구 생성 완료
입력
언급 카테고리 목록
처리
1개면 해당 카테고리로 구분 표시 · 2개 이상이거나 없으면 중립 처리 (시각 표현은 디자인에서 정한다)
출력
코멘트 카드의 구분 표시 대상 카테고리
예외
카테고리 구분 표시는 그 자체로 “이 종목 이야기”라는 신호이므로 임의로 붙이지 않는다
04

데이터

위 세 그룹이 딛고 서는 저장소와 공통 계산입니다. 세 기능 모두 정의가 없어 선행 작업입니다.

DATA-G01목표 기록 저장미정
카테고리 × 일자 단위로 완료 여부와 제시 문구를 보관한다.
트리거
완료·취소 처리
입력
사용자, 카테고리, 날짜, 완료 여부, 완료 시각, 그날 제시된 문구
처리
목표 기록 저장 → 동일 키(사용자 · 카테고리 · 날짜) 존재 시 갱신
출력
영속화된 목표 기록
예외
스키마 미정 — 논리 데이터 모델이 행동 로그를 범위에서 제외해 두어 정의가 없음 · 기록이 카드가 아니라 카테고리에 귀속되어야 문구가 바뀌어도 일수가 승계됨 · 제시 문구를 함께 남겨야 잠금 규칙의 근거가 됨 · 과거 날짜 기록이 가능하므로 날짜는 입력값으로 받는다
DATA-G02방문 기록 수집미정
목표 화면을 본 날을 남겨 오랜만의 방문을 판정한다.
트리거
목표 분석 화면 진입 또는 홈 목표 카드 노출
입력
사용자, 방문일
처리
방문 기록 저장 → 최근 방문일 조회
출력
