maiReport 기능정의서

최신 HTML 프로토타입의 실제 화면·모달·탭과 플랫폼별 권한 분기를 기준으로 시스템 처리 요구사항을 기능 ID 단위로 정의합니다. 각 기능에서 화면 ID, 화면명 및 실제·계획 DOM ID를 함께 추적할 수 있습니다.

PRODUCT INPUT / OUTPUT

maiReport 최종 I/O 정의

사용자·기기·의료기관에서 확보한 데이터를 품질과 출처를 보존해 통합하고, 사용자가 이해할 수 있는 현재 상태·근거·생활 행동·변화 추이로 제공합니다.

INPUT · 서비스 입력
I-01 · 사용자·권한 컨텍스트

카카오 인증, 활성 프로필, 약관·민감정보 동의, HealthKit·Health Connect 접근 권한

I-02 · 생활·생리 데이터

Apple Health 및 Samsung Health 등에서 연계된 걸음·수면·심박·활동·신체·건강측정 데이터

I-03 · 의료정보

건강검진 결과·문진표, 진료·처방·방문이력과 출처·최종 갱신 시각

I-04 · 리포트 데이터

AI REPORT QR, 일반 검진 결과 이미지·PDF, OCR 추출값과 사용자 검수값

I-05 · 사용자 입력·행동 이력

오늘의 질문 응답, 목표 선택·완료·쉬기, 진료 메모와 이용 시점

PROCESSING데이터를 설명과 행동으로 변환
인증·동의·접근권한 검증
출처·최신성·결측·중복 판정
단위 표준화 및 개인 기준선 비교
상태·인사이트·행동 규칙 적용
의료 표현 안전 검수 및 감사 기록
OUTPUT · 사용자 제공 결과
O-01 · 오늘의 상태

오늘의 컨디션, 회복여유·생활부담·리듬안정성과 평소 대비 변화

O-02 · 개인화 코칭·행동

상태 근거가 포함된 코칭과 식이·활동·수면 행동 제안 및 실천 이력

O-03 · 통합 건강 데이터

생활·생리·검진·진료·AI REPORT의 출처별 요약, 최신성 및 원문 상세 연결

O-04 · 주간 분석·AI 인사이트

목표·지표·생활 변화 분석, 종합 인사이트, 상세 근거와 변화 추이

O-05 · 의료정보 활용 결과

검진·진료 통합 이력, AI 검진 요약, Selvy Checkup 질환 위험도 결과

FINAL OUTPUT · “내 건강정보가 무엇을 의미하는지 이해하고, 오늘 필요한 행동을 선택할 수 있는 상태”질병 진단·치료 결정이 아닌 건강정보 이해와 일상생활 관리를 위한 참고 결과
SCREEN TRACEABILITY

최신 HTML 화면 연계표

화면 ID는 IA 추적 키입니다. DOM ID는 최신 HTML에 구현된 실제 컨테이너를 우선 표시하며, Android 신규 화면처럼 미구현 항목은 계획 DOM으로 구분합니다.

검색 조건에 일치하는 기능이 없습니다.
구현 전 공통 확인사항외부 API 인증·인가, 중복 요청에 대한 멱등성, 비동기 처리 상태, 네트워크 오류 재시도, 민감정보 마스킹, 사용자 동의 및 철회, 데이터 보유·파기 정책은 상세 설계 단계에서 확정해야 합니다.
