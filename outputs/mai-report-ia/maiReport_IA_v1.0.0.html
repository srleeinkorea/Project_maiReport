확인이 필요한 사항
  1. 병원 탭의 연동 관리 동선 — 검진요약 · 진료요약 하단의 「마지막 업데이트 · 연동 관리」 링크를 뺐어요(2026-09-23). 연동 갱신 · 해제는 더보기 › 검진 · 진료정보 연동에서만 할 수 있어요.
  2. 진료정보의 진단명 제공 범위 — 심평원 API에서 주상병명 · 코드가 2026-04-28 이후 통신사 인증 경로로만 와요. 진단명이 없을 때 진료상세 화면을 어떻게 보여줄지 정해야 해요.
  3. 진료 이용현황 진입 — 화면과 연도 필터는 구현돼 있지만(openAllVisits) 어디에서도 호출하지 않아 들어갈 수 없어요.
  4. 검진 · 진료정보 연동 해제는 즉시 삭제 — 유예 기간이 없어요. 회원 탈퇴 안내의 「법정 보관 정보」 문구와 어긋나지 않는지 확인이 필요해요.
