maiReport · Service Overview

내 건강의 신호를,
오늘의 작은 변화로.

maiReport는 의료기관에서 생성된 AI 리포트를 사용자가 직접 확인할 수 있도록 전달하고, 리포트·검진·진료 기록과 스마트기기·문진 데이터를 활용해 현재 상태를 이해하고 가벼운 생활 행동을 선택하도록 돕는 웰니스 코칭 서비스입니다.

AI 리포트 전달의료·생활 데이터 결합상태 기반 라이트 코칭가용 데이터 적응형글로벌 웰니스 확장
ENTRY POINT병원에서 제공받은 AI 리포트의 QR 등록·확인

현재는 사용자가 QR을 촬영해 리포트를 수신하며, 향후 서버 직접 전달 방식으로 확장할 수 있습니다.

PRIMARY MOMENT이상 소견이나 건강 우려로 관심과 행동 의지가 높아진 시점

리포트 확인 직후를 상태 이해와 생활 코칭으로 연결하는 핵심 접점으로 봅니다.

SERVICE BOUNDARY질병 진단·치료가 아닌 일상생활 중심의 웰니스 지원

의료진의 판단을 대체하지 않고, 사용 가능한 정보 범위에서 생활 행동을 제안합니다.

01 · SERVICE ORIGIN

리포트 전달 앱에서
건강 행동 지원 서비스로

maiReport의 출발점은 의료기관의 AI 분석 리포트를 사용자가 직접 수신하고 보관할 수 있게 하는 것이었습니다. 이후 검진·진료·처방 정보를 함께 조회하는 개인 건강정보 관리 기능이 더해졌고, 현재는 축적된 의료정보와 일상 데이터를 활용해 사용자가 오늘 할 수 있는 행동을 제안하는 코칭 경험으로 확장하고 있습니다.

PHASE 01 · ORIGIN

AI 리포트 전달

의료기관에서 제공받은 리포트의 QR을 촬영해 사용자 앱으로 전달하고, 결과를 직접 확인·보관하는 핵심 기능에서 시작했습니다.

PHASE 02 · EXPANSION

개인 건강정보 관리

건강검진, 진료·처방 이력 등 확보 가능한 데이터를 연계해 사용자의 건강정보를 한곳에서 조회하는 아카이브 역할로 확장했습니다.

PHASE 03 · CURRENT DIRECTION

컨텍스트 기반 웰니스 코칭

AI 리포트와 생활 데이터를 함께 해석해 현재 상태를 설명하고, 사용자가 부담 없이 선택할 수 있는 한 가지 생활 행동을 제안합니다.

02 · PLANNING INTENT

건강에 대한 관심이
가장 높아지는 순간을 연결

건강한 일상에서 지속적인 관심을 만들어내는 것보다, 리포트에서 이상 소견을 확인하거나 몸이 좋지 않아 스스로의 상태에 관심이 높아지는 시점이 행동 변화 가능성이 큽니다. maiReport는 이 순간을 놓치지 않고 리포트 확인 → 상태 이해 → 생활 코칭으로 자연스럽게 이어지는 경험을 설계합니다.

01

리포트 이후의 단절

사용자는 결과를 확인한 뒤 다음에 무엇을 해야 하는지 알기 어렵고, 의료기관에서 일상생활 관리로 이어지는 후속 경험도 부족합니다.

02

의료정보와 생활정보의 분리

진료·검진 기록을 다루는 서비스와 웨어러블 기반 웰니스 서비스가 분리되어 있어 두 맥락을 함께 반영한 코칭이 드뭅니다.

03

정보 나열만으로는 부족

수집된 데이터를 단순 조회하는 것만으로는 반복 방문의 이유가 약하며, 상태 설명과 행동 제안으로 이어져야 사용자 가치가 생깁니다.

CORE KEY MESSAGE
결과를 확인한 오늘,
건강한 변화가 시작됩니다.

maiReport가 흩어진 건강 신호를 함께 읽고, 지금 나에게 필요한 한 가지 생활 행동을 제안합니다.

TURN 01현재 상태 요약

AI가 오늘의 전반적인 상태를 한 문장으로 설명합니다.

TURN 02근거 지표 확인

상태 요약의 근거가 된 지표와 수집 데이터를 보여줍니다.

TURN 03평소 대비 변화

오늘의 생활 패턴이 개인 기준선과 어떻게 다른지 설명합니다.

TURN 04한 가지 행동 선택

여러 제안 중 사용자가 부담 없이 실천할 행동 하나를 선택합니다.

03 · CORE FEATURES

주요 기능

핵심 기능은 AI 리포트 수신을 출발점으로 현재 보유한 데이터를 조합해 상태를 설명하고, 부족한 정보는 짧은 질문으로 보완한 뒤 사용자가 한 가지 생활 행동을 선택하도록 구성합니다.

01

AI 리포트 등록·확인

의료기관에서 받은 AI 리포트를 사용자 앱으로 전달하는 핵심 진입 기능입니다.

  • 현재 QR 촬영 기반 리포트 수신
  • 대상자 정보 매칭 및 리포트 보관
  • 향후 서버 직접 전달 방식 확장
02

가용 데이터 통합

특정 데이터 보유를 전제하지 않고 현재 확보된 정보의 조합으로 사용자 맥락을 구성합니다.

  • AI 리포트·검진·진료·처방 정보
  • 걸음·수면·심박 등 기기 데이터
  • 일일 문진과 사용자 자기보고 데이터
03

동적 문진·데이터 보완

자동 수집되지 않은 항목을 짧은 선택형 질문으로 보완해 코칭에 활용합니다.

  • 수면 등 누락 데이터 기반 질문 노출
  • 사용자별 질문 구성 차등화
  • 최소 입력으로 활용 가능한 값 변환
04

개인 건강정보 조회

확보 가능한 건강정보를 유형과 시간 흐름에 따라 확인할 수 있도록 제공합니다.

  • 건강검진 결과와 문진표
  • 진료·처방 및 병원 방문 이력
  • 리포트와 생활 데이터 통합 조회
05

상태 요약·근거 지표

AI가 현재 상태를 요약하고 그 근거가 되는 데이터와 개인 기준선 대비 변화를 보여줍니다.

  • 오늘의 상태 요약 메시지
  • 상태 근거 지표와 관련 데이터
  • 평소 대비 변화와 생활 패턴
06

라이트 웰니스 코칭

사용자에게 여러 행동을 강제하지 않고 오늘 할 수 있는 한 가지를 선택하도록 제안합니다.

  • 수면·활동·식이 중심 생활 제안
  • 부담이 적은 선택형 인터랙션
  • 선택 이력과 변화 확인으로 확장
04 · PHYSIOLOGICAL SIGNALS

생리학적 신호를
이해 가능한 상태지표로

코칭의 설득력은 단순한 생활 권고가 아니라 실제 생리·생활 데이터에서 출발해야 합니다. maiReport는 개별 원천값을 그대로 나열하기보다 데이터 품질과 개인 기준선을 확인한 뒤 복합 상태지표로 재구성하고, 사용자가 이해할 수 있는 설명과 행동 제안으로 연결합니다.

ACTIVITY LOAD

활동·부하 신호

하루의 신체활동량과 최근 활동 부하가 평소 수준에서 어떻게 달라졌는지 확인합니다.

  • 걸음 수
  • 활동 시간
  • 활동 에너지
  • 운동 시간
기본 코칭은 걸음 수만으로도 시작할 수 있도록 설계
RECOVERY & SLEEP

회복·수면 신호

수면량과 규칙성, 안정 상태의 심박 변화를 함께 살펴 회복 상태를 추정합니다.

  • 수면 시간
  • 수면 규칙성
  • 안정시 심박수
  • 심박변이도
기기·권한·데이터 품질에 따라 사용 항목이 달라짐
CARDIORESPIRATORY

심폐 관련 신호

심박과 호흡 관련 지표의 절대값보다 개인의 최근 범위와 변화 방향을 중심으로 관찰합니다.

  • 심박수
  • 호흡수
  • 산소포화도
  • 활동시 심박
수집 가능한 경우에만 보조 신호로 활용
BODY & MEASUREMENT

신체·건강측정 신호

기기 연계 또는 사용자 입력으로 확보되는 측정값은 장기 추이와 의료정보의 보조 맥락으로 사용합니다.

  • 체중·BMI
  • 혈압
  • 혈당
  • 체온
실제 지원 항목은 OS 제공 범위와 서비스 정책에 따라 확정
01 · SIGNAL원천 데이터 수집

기기, 의료정보와 사용자 입력에서 신호를 확보합니다.

02 · QUALITY품질·결측 확인

측정 시각, 최신성, 연속성과 누락 여부를 검증합니다.

03 · BASELINE개인 기준선 비교

최근 7~14일의 개인 범위와 변화 방향을 우선합니다.

04 · INDEX복합 상태지표 구성

여러 신호를 회복·부담·리듬 관점으로 재구성합니다.

05 · ACTION설명·행동으로 전환

변화 근거를 설명하고 부담이 낮은 행동을 제안합니다.

가설 지표 · 정의 필요

회복여유

수면량·규칙성, 안정시 심박수와 심박변이도, 전일 활동 부하 등을 조합해 오늘의 회복 가능 여유를 설명하는 지표입니다.

가설 지표 · 정의 필요

생활부담

최근 활동량, 높은 심박 구간, 휴식 부족과 사용자가 보고한 피로도를 종합해 일상에서 체감하는 부담 수준을 설명합니다.

가설 지표 · 정의 필요

리듬안정성

수면·기상 시각과 활동 시간대의 일관성을 바탕으로 생활 리듬이 개인의 평소 패턴에서 얼마나 안정적인지 설명합니다.

INTERPRETATION RULE

생리학적 지표는 단일 측정값이나 일반 기준치만으로 상태를 단정하지 않습니다. 개인 기준선 대비 변화, 데이터 충분도와 사용자 문진을 함께 고려하며, 의료적 이상 판정이나 질병 위험 예측이 필요한 경우에는 의료기관 상담으로 연결합니다.

05 · DIFFERENTIATION

차별화 포인트

의료정보를 보관하는 환자 포털과 일상 데이터만 활용하는 웰니스 코칭 사이의 공백을 공략합니다. AI 리포트라는 명확한 진입점과 의료·생활 데이터의 결합, 낮은 행동 부담이 maiReport의 차별화 축입니다.

01AI 리포트 기반의 명확한 진입점

새로운 앱을 습관적으로 사용하게 만드는 대신, 사용자가 건강정보에 가장 관심을 갖는 리포트 수신·확인 시점을 서비스 유입과 코칭의 출발점으로 활용합니다.

02의료정보와 생활 데이터의 동시 활용

AI 리포트·검진·진료 정보와 스마트기기·자기보고 데이터를 함께 사용해, 의료기록 조회와 일반 웰니스 코칭이 분리된 기존 시장의 공백을 보완합니다.

03보유 데이터에 따라 정교해지는 구조

걸음 수만 있어도 기본 코칭이 가능하도록 설계하고, 수면·심박·의료정보가 추가될수록 규칙과 메시지가 더 구체화되는 가용 데이터 적응형 방식을 지향합니다.

04가볍고 비강제적인 행동 선택

과도한 목표와 엄격한 이행 추적 대신 ‘30분 일찍 자기’처럼 부담이 낮은 제안을 제공하고, 사용자가 원하는 행동 한 가지를 스스로 선택하도록 합니다.

05글로벌 확장을 고려한 웰니스 경계

국가별 의료정보 접근성과 규제 차이를 고려해 질병 진단·치료보다 일상생활 지원에 집중하고, 의료정보가 없는 환경에서도 기기 데이터만으로 동작할 수 있게 설계합니다.

06 · USER VALUE

대상 사용자와
제공 가치

우선 대상은 AI 검사나 건강검진 결과를 확인한 직후, 자신의 상태에 관심은 높아졌지만 생활에서 무엇을 해야 할지 알기 어려운 사용자입니다. 지속 사용을 강제하기보다 필요한 순간에 명확하고 부담이 적은 도움을 제공하는 데 집중합니다.

PRIMARY USERAI 리포트 또는 검진 결과를 받고
다음 행동이 필요한 사용자

이상 소견이나 건강 우려로 자신의 상태에 대한 관심과 행동 의지가 높아진 시점을 우선합니다.

UNDERSTAND현재 상태를 쉽게 이해

요약 메시지와 근거 데이터를 순서대로 제시해 단편적인 정보 나열을 줄입니다.

ACT오늘 할 수 있는 한 가지

실행 부담이 낮은 생활 행동을 제안하고 선택권은 사용자에게 둡니다.

LOW FRICTION최소 데이터로도 시작

걸음 수와 짧은 문진만으로 시작하고 데이터가 추가될수록 경험을 정교화합니다.

관심이 생긴 순간에 개입

리포트 확인 직후처럼 사용자가 설명과 조언을 필요로 하는 타이밍을 우선합니다.

데이터에 비례한 설명

보유한 정보 이상을 추론하지 않고 근거가 있는 범위에서만 상태를 설명합니다.

사용자 선택권

행동을 강제하거나 미이행을 압박하지 않고 제안과 선택 중심으로 설계합니다.

웰니스 안전 경계

질병 진단·치료 판단은 의료진에게 연결하고 일상생활 지원 범위를 유지합니다.

SERVICE BOUNDARY
