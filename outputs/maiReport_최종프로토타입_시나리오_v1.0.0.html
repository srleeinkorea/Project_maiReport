최종 프로토타입 시나리오 · 일반인 / 폐렴 회복기

최종 프로토타입(prototype.html)의 실제 로직을 그대로 실행해, 화면에 실제로 나올 수 있는 질문·답 조합마다 오늘의 코칭, 지식DB 코칭, 오늘의 목표가 무엇으로 나오는지 모았습니다. 진입 시각에 따라 묻는 끼니와 질문 후보가 달라져 시각별로 나눴습니다.

질문이 정해지는 규칙

  • 일반인 — 1번 고정 질문 「{지난 끼니}은 평소만큼 드셨나요?」 + 2번 회전 질문(채소·단 음료·국물·포만감·단백질·기름진 음식, 아침 4~10시에는 야식 포함) 중 하루 1개. 「거의 못 먹음」이면 2번을 묻지 않습니다.
  • 폐렴 회복기 — AI REPORT에 폐렴 소견이 있을 때. 1번 「최근 폐렴을 진단받고 치료, 회복 중이신가요?」 → 「네」면 2번 단백질 질문, 「아니요 · 잘 모르겠어요」면 2번 끼니 고정 질문 → 3번 「오늘은 가볍게 걸어볼 수 있을 것 같나요?」(활동 목표와 회복기 활동 코칭의 '활동 가능 확인').
  • 활동 · 수면 목표 — 일반인은 질문 없이 연동 데이터로 정합니다. 하루 걸음 7,000보 미만이면 「짧은 산책 한 번 더하기」(지식DB fact 190), 최근 7밤 중 과반이 7시간 미만이면 「오늘은 평소보다 일찍 눕기」(fact 40), 아니면 기본 목표. 폐렴 회복기 활동은 3번 걷기 답으로, 수면은 「상체 높여 눕기」 고정입니다.
  • 지식DB 코칭 — 수면(최근 7밤 중 과반 7시간 미만), 폐렴 회복기(「네」일 때만), 당뇨(내정보 직접 선택 시) 규칙. 일반인은 연동 데이터 두 가지(평소 · 걸음과 수면이 부족한 날)로 나눠 보여 줍니다.
