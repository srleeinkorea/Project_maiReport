# maiReport HTML → Figma (틀 유지) · Figma 플러그인

HTML 화면(화면설계서 · 프로토타입 · 문서)을 **보이는 모양 그대로** Figma 레이어로 옮기는 플러그인입니다.
html.to.design과 같은 방식이에요. 브라우저가 그린 결과에서 상자 · 글자 · 이미지의 위치 · 크기 · 색 · 테두리 · 그림자 · 글꼴을 읽어 같은 자리에 Figma 레이어를 만듭니다.

- **틀 유지** — 모든 레이어를 원래 위치에 놓습니다(오토 레이아웃으로 바꾸지 않음).
- **Figma에서 수정 가능** — 글자는 텍스트 레이어(부분 굵기 · 색 · 밑줄 유지), 상자는 프레임, 아이콘은 벡터, 이미지는 이미지 채우기로 들어갑니다.
- **누르면 바뀌는 화면도 가능** — 플러그인 창 안에서 문서를 직접 눌러 원하는 화면을 띄운 뒤 가져옵니다. 가져올 때마다 Figma에 프레임이 하나씩 오른쪽으로 쌓입니다.

> 기존 `figma-doc-plugin`(문서 보드 생성기)은 우리 문서 양식(카드 · 표)을 **오토 레이아웃으로 새로 그리는** 도구입니다. 이 플러그인은 **원래 모양을 그대로 옮기는** 도구라 용도가 다릅니다.

## 설치 (한 번만)
1. Figma **데스크톱 앱**을 엽니다(브라우저 버전은 개발 플러그인을 불러올 수 없습니다).
2. 메뉴 → Plugins → Development → **Import plugin from manifest…**
3. 이 폴더의 `manifest.json`을 선택합니다.

## 사용
1. 옮길 Figma 파일을 열고 Plugins → Development → **maiReport HTML → Figma (틀 유지)** 실행
2. 문서 불러오기 — 둘 중 하나
   - **주소**: 위 칸에 문서 주소를 넣고 **불러오기**
     예) `https://srleeinkorea.github.io/maireport-rsna-demo-k7x9m2q8v4n6/wip-clinic-codef.html`
     (사이트 첫 화면 주소가 아니라 **문서 파일 주소**를 넣으세요. 첫 화면은 문서를 안쪽 창(iframe)으로 띄워서 내용을 읽을 수 없습니다.)
   - **파일**: HTML 파일을 창에 끌어다 놓거나 **파일 선택**
3. 창 안의 화면을 직접 눌러 원하는 상태로 만듭니다(예: 화면 버튼 ② 본인인증, 데이터 상황 '주민번호 오류').
4. 필요하면 옵션을 고르고 **현재 화면 Figma로 가져오기**
5. `[HTML] 이름` 프레임이 생기고 선택된 상태로 화면에 맞춰집니다. 다음 화면을 띄우고 다시 가져오면 오른쪽에 이어서 놓입니다.

### 모든 화면 한 번에 가져오기
화면설계서처럼 위쪽에 **화면 버튼**이 있는 문서는 **모든 화면 가져오기**를 누르면 플러그인이 버튼을 차례로 눌러 가며 화면마다 한 장씩 가져옵니다. 프레임 이름은 `문서 제목 · 버튼 이름`(예: `진료정보 연동 · ② 본인인증`)입니다.
- 옆 칸의 `#jump button`은 화면 버튼을 찾는 선택자입니다. 우리 화면설계서(진료정보 연동 · 내정보 관리)는 그대로 두면 됩니다. 다른 문서는 그 문서의 버튼 선택자로 바꾸세요.
- **데이터 상황 포함**을 켜면 화면마다 '데이터 상황' 버튼(`#scen button`, 예: 주민번호 오류 · 진단명 없음)도 하나씩 눌러 추가로 가져오고, 끝나면 '기본'으로 되돌립니다. 진료정보 연동은 꺼면 8장, 켜면 14장입니다.
- 중간에 **멈추기**를 누르면 지금 화면까지만 가져오고 멈춥니다.
- 데이터 상황 중 버튼을 눌러야 나타나는 상태(예: '주민번호 오류'는 [카카오로 본인인증]을 눌러야 오류 문구가 보임)는 버튼만 바뀐 화면으로 들어갑니다. 그런 화면은 창 안에서 직접 눌러 띄운 뒤 **현재 화면**으로 가져오세요.

### 창 크기
처음에는 820×600으로 열립니다. **오른쪽 아래 모서리(빗금)** 를 끌면 창 크기가 바뀌고(최소 560×420), 바꾼 크기는 다음에 열 때도 그대로입니다. 창이 작아도 미리보기는 정한 화면 폭(기본 1280) 그대로 그린 뒤 줄여서 보여주므로, 가져오는 결과는 창 크기와 상관없습니다.

### 옵션
| 옵션 | 하는 일 |
|---|---|
| 화면 폭 | 문서를 그릴 창 폭(1280 · 1440 · 1024 · 390 휴대폰). 반응형 문서는 폭에 따라 모양이 달라집니다. |
| 범위 | **전체 페이지** · **폰 화면만(`.phone`)** · **선택자 직접 입력**. 화면설계서에서 폰 화면만 모으고 싶을 때 `폰 화면만`을 고르세요. |
| 줄바꿈 위치 그대로 | 브라우저에서 줄이 바뀐 자리를 Figma에서도 똑같이 바꿉니다(기본 켬). 끄면 Figma가 줄바꿈을 다시 계산해서, 글꼴이 다르면 줄 수가 달라질 수 있습니다. |
| 스크롤 영역 펼치기 | 폰 화면처럼 안쪽 스크롤에 가려진 내용까지 끝까지 펼쳐서 가져옵니다(기본 끔). 끄면 보이는 만큼만 보이고 나머지는 잘린 상태로 들어갑니다(프레임 크기를 늘리면 보임). |
| 이름 | 만들 프레임 이름. 비우면 `문서 제목 · 번호`. |

## 가져오는 것
| HTML | Figma |
|---|---|
| 배경색 · 선형 그라디언트 · 배경 이미지 | 프레임 채우기(단색 · 선형 그라디언트 · 이미지) |
| 테두리(변마다 두께 다름 · 점선) · 외곽선 | 선(Inside / Outside, 변별 두께, 대시) |
| 둥근 모서리(모서리마다 다름, %) | 모서리 반경 |
| box-shadow(여러 개 · inset) | 드롭 섀도 · 이너 섀도 |
| overflow hidden · auto · scroll | 프레임 내용 자르기 |
| 글자(굵게 · 색 · 밑줄 · 자간 · 행간 · 정렬 · 말줄임) | 텍스트 레이어(구간별 스타일) |
| ::before · ::after (점 · 선 · 체크 · 라벨) | 일반 레이어 |
| 목록 점 · 번호 | 텍스트 |
| `<img>` · `<canvas>` | 이미지 채우기 사각형 |
| `<svg>` | 벡터 |
| 입력칸 · 체크박스 · 라디오 · 선택 상자 | 상자 + 값(비밀번호는 점), 체크 표시 |
| 투명도 · z-index 겹침 순서 | 레이어 투명도 · 순서 |

## 글꼴
문서가 쓴 글꼴을 Figma에서 찾고, 없으면 **Pretendard → Noto Sans KR → Inter** 순으로 바꿉니다. 한글이 있는 글자에는 한글 글꼴만 씁니다. 가져온 뒤 창 아래에 **사용한 글꼴**이 표시됩니다.
우리 문서는 Pretendard를 쓰므로, 컴퓨터에 [Pretendard](https://github.com/orioncactus/pretendard)를 설치해 두면 가장 똑같이 나옵니다(설치 후 Figma 재시작).

## 한계
- **회전 · 기울임(transform)** 은 반영하지 않습니다(예: 살짝 기울인 메모 스티커가 반듯하게 들어감).
- **안쪽 창(iframe) · 동영상** 내용은 가져오지 않고 회색 상자로 둡니다.
- **오토 레이아웃이 아닙니다.** 틀을 그대로 지키려고 절대 위치로 놓습니다. 글을 많이 늘리면 아래 요소가 자동으로 밀려 내려가지 않습니다.
- **주소로 불러오기는 허용한 사이트만** 됩니다(`manifest.json`의 `allowedDomains`: 공유 사이트 · jsdelivr · cdnjs · unpkg · Google Fonts). 다른 사이트는 브라우저에서 **다른 이름으로 저장 → HTML**로 저장한 뒤 파일로 끌어다 놓거나, `allowedDomains`에 주소를 추가하세요.
- 파일로 불러오면 **상대 경로 이미지**(같은 폴더의 png 등)는 보이지 않습니다. 이미지를 문서 안에 넣었거나(data URI) 주소로 불러오면 보입니다.
- 웹 글꼴과 Figma 글꼴의 글자 폭이 조금 달라 한 줄 글자가 1~2px 어긋날 수 있습니다.

## 파일
| 파일 | 내용 |
|---|---|
| `manifest.json` | 플러그인 정보 · 허용 도메인 |
| `code.js` | Figma 쪽: 설계도(JSON)를 받아 레이어를 만든다 |
| `ui_v1.0.0.html` | 플러그인 창: 문서를 그리고, 화면을 읽어 설계도(JSON)로 바꾼다 |
