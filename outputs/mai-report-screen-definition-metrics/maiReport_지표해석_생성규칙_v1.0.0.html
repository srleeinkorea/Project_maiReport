지표별 분석 · 이번 주 해석 생성 규칙

생활 탭 지표별 분석 카드의 ‘이번 주 해석’ 문장을 개발에서 동일하게 만들 수 있도록 입력값, 흐름 유형 판정, 이유 선택, 문장 조합, 예외 처리 조건을 정의함.

대상 지표: 생활여유 · 자기돌봄 · 일상안정 · 구간 판정은 지표 엔진 결과를 그대로 사용

1표시 조건

언제, 어떤 기준으로 문장을 보여주는지
항목조건
표시 위치지표 카드의 주간 그래프 아래 ‘이번 주 해석’ 영역
기준 기간이번 주 월요일 ~ 오늘(오늘 포함). 지난 주는 월 ~ 일 전체
날짜 선택과의 관계상단 날짜 띠에서 다른 날을 골라도 문장은 바꾸지 않음(주 단위 고정). 배지 · 점선 · 핵심 데이터만 선택한 날 기준으로 바뀜
생성 시점하루 첫 동기화가 끝나 지표 엔진이 오늘 구간을 내려준 뒤 1회 생성. 같은 날 추가 동기화로 오늘 구간이 바뀌면 다시 생성
지난 주주가 끝난 뒤(일요일 자정 이후) 마지막으로 생성한 문장을 ‘돌아보는 말투’로 바꿔 고정 저장. 이후 다시 생성하지 않음
문장 수지표 1개당 1~2문장(규칙은 8장)

2입력값

문장을 만들 때 쓰는 값. 구간은 앱이 계산하지 않고 지표 엔진 값을 그대로 받음
입력출처설명
요일별 구간지표 엔진이번 주 각 날짜의 구간: good(좋음) · mid(보통) · low(주의) · none(관찰 중 · 값 없음)
유효 일수요일별 구간에서 계산이번 주에서 구간이 none이 아닌 날 수
핵심 데이터 값건강 데이터 연동지표별 핵심 데이터 항목의 날짜별 값(항목은 4장 표)
평소 범위지표 엔진(평소 기준)핵심 데이터 항목별 사용자 평소 값 범위. 생활여유 · 자기돌봄은 내 평소 범위, 일상안정은 평소 21일 기준
변화 시작 요일요일별 구간에서 계산이번 주 안에서 구간이 처음 바뀐 날(3장 판정에 사용)
구간 경계(참고): 생활여유 70 / 40, 자기돌봄 · 일상안정 66 / 33 (0~100 내부 점수). 앱은 이 값으로 다시 판정하지 않음.

3흐름 유형 판정

위에서부터 차례로 확인해 처음 맞는 유형 하나를 선택함. 구간 순서: 주의(low) < 보통(mid) < 좋음(good)
순서유형조건설명
1기록 부족유효 일수 2일 이하흐름을 말하지 않음(9장)
2회복오늘(마지막 유효일) 구간이 이번 주 가장 낮았던 구간보다 높고, 첫 유효일 구간보다 같거나 높음낮아졌다가 다시 올라옴
3하락오늘 구간이 이번 주 첫 유효일보다 낮고, 오늘이 주의(low) 또는 보통(mid)주 초반보다 내려감
4주의 지속유효일의 절반 이상이 주의(low)이고 오늘도 주의낮은 상태가 이어짐
5들쭉날쭉구간이 오르내린 횟수(바로 전날과 다른 방향으로 바뀐 횟수)가 2회 이상방향이 자주 바뀜
6좋음 유지유효일이 모두 좋음(good)좋은 상태가 이어짐
7보통 유지위 어느 것에도 해당하지 않음대체로 비슷함

변화 시작 요일: ‘회복’은 이번 주 가장 낮은 구간 다음으로 구간이 올라간 날, ‘하락’은 처음 구간이 내려간 날. 문장에 ‘{요일}부터’로 사용.

4이유 선택

문장 앞부분에 쓸 ‘이유’를 핵심 데이터에서 고르는 조건
지표이유 후보(핵심 데이터 항목)
생활여유수면 · 활동 시간(하루 중 분포 포함)
자기돌봄식후 활동 · 활동 시간
일상안정기상 · 취침 시각의 일정함 · 걸음 수 · 수면 · 활동 시간

선택 순서

  • ① 흐름 방향과 같은 방향으로 평소 범위에서 가장 많이 벗어난(또는 평소 범위로 돌아온) 항목을 1순위로 선택
  • ② 같은 방향의 항목이 하나 더 있으면 2순위로 추가(최대 2개)
  • ③ 흐름 방향: 회복 · 좋음 유지 → 좋아진 항목, 하락 · 주의 지속 → 나빠진 항목, 들쭉날쭉 → 요일별 변동이 가장 큰 항목, 보통 유지 → 평소 범위 안 항목
  • ④ 조건에 맞는 항목이 없으면 이유 없이 결과 문구만 사용(7장 조합 C)
  • ⑤ 이유에는 핵심 데이터 표에 보이는 항목만 사용(표에 없는 심박 · 칼로리 등은 쓰지 않음). 단 일상안정의 ‘기상 · 취침 시각’은 리듬 설명에 한해 허용

항목좋아짐 · 평소로 돌아옴나빠짐 · 평소를 벗어남흔들림

두 항목 연결 시 앞 문구의 ‘~면서’를 ‘~고’로 바꿈. 예: ‘수면이 짧아지고 활동 시간이 줄면서’.

{N}: 변화 시작 요일부터 오늘까지 일수. 3일 미만이면 ‘{N}일째’ 대신 ‘줄고 있어요’로 표기.

이유 · 결과 · 변화 시작 요일을 조합하는 형식
조합사용 조건형식
A하락 · 주의 지속 · 회복(변화 시작 요일이 이번 주 화요일 이후){요일}부터 {이유}, {결과}

조합 예: 회복 · 이유 2개(활동 시간, 수면) · 생활여유 →
늦은 시간에 몰려 있던 활동이 하루 중간으로 나뉘고 수면이 채워지면서, 여유가 다시 앞선 하루가 됐어요.

8작성 규칙 · 금지 표현

항목규칙
길이1~2문장, 합계 60자 안팎(최대 80자). 넘으면 이유를 1개로 줄여 다시 조합
강조부분 굵게 없이 문장 전체를 본문 강조 톤으로 표시
날짜요일로만 표기(‘화요일부터’). 날짜 숫자 · ‘이번 주는’ 같은 달력 주어는 쓰지 않음
숫자점수 · 퍼센트 · 핵심 데이터 수치를 문장에 쓰지 않음(수치는 아래 핵심 데이터 표에서 보여줌). 예외: 결과 문구의 {N}일째
금지 표현진단 · 질병 · 몸 상태 단정(‘아픈 동안’, ‘회복 중’, ‘병’), 행동 지시(‘~하세요’, ‘~해야 해요’), 비교 평가(‘다른 사람보다’)
말투‘~어요’ 체. 이번 주는 현재형 · 현재진행형, 지난 주는 과거형

9예외 처리

상황처리
기록 부족(유효 2일 이하)‘아직 흐름을 말하기엔 기록이 적어요.’ 한 문장
오늘 구간이 관찰 중(none)카드 전체가 관찰 중 상태로 바뀌며 해석 영역을 표시하지 않음
건강 데이터 미연동지표 카드 대신 연동 안내 카드만 표시(해석 없음)
지난 주저장된 문장을 과거형 · ‘이 주는’ 주어로 변환해 표시. 예: ‘…흔들림이 줄었어요.’ → ‘이 주는 …흔들림이 줄었어요.’ 상세 기록이 없는 주는 해석 대신 기록 없음 안내
생성 실패해석 영역 제목과 문장을 숨기고 나머지 카드는 그대로 표시

10적용 예시

현재 프로토타입 문장이 어떤 조건에서 나오는지
지표요일별 구간(월~목)유형 · 조합문장
생활여유보통 · 주의 · 보통 · 좋음회복 · B늦은 시간에 몰려 있던 활동이 하루 중간으로 나뉘고 수면이 채워지면서, 여유가 다시 앞선 하루가 됐어요.
자기돌봄보통 · 주의 · 보통 · 보통회복 · B + 보충식사 뒤와 오래 앉아 있던 뒤에 짧은 걷기가 이어진 날이 늘었어요. 아직 절반쯤이에요.
일상안정보통 · 보통 · 좋음 · 좋음회복 · B자고 움직이는 시각이 다시 일정해지면서, 평소 범위 안에서 흔들림이 줄었어요.
생활여유좋음 · 보통 · 주의 · 주의하락 · A화요일부터 수면이 짧아지고 활동 시간이 줄면서, 여유가 사흘째 줄고 있어요.
자기돌봄좋음 · 보통 · 주의 · 주의하락 · A화요일부터 식사 뒤나 오래 누워 있던 뒤에 이어지는 움직임이 거의 없었어요.
일상안정좋음 · 보통 · 주의 · 주의하락 · A화요일부터 걸음 수와 수면이 평소 범위를 벗어나면서, 생활 리듬이 흔들리고 있어요.
자기돌봄 회복 예시는 이유 문구가 문장 끝까지 이어지는 형태(‘~늘었어요’)라 조합 B의 ‘{이유}, {결과}’ 대신 이유 문구를 문장으로 끝맺은 경우임. 이유 문구만으로 결과가 드러나면 결과 문구를 생략할 수 있음(자기돌봄 식후 활동 한정).
