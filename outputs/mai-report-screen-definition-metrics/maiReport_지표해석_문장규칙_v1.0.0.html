1한눈에 보기

① 구간 비교

선택한 날 vs 전날

구간: 좋음 · 보통 · 주의 (엔진 결과 그대로)
② 구간이 바뀜

이유 + 변화

가장 크게 달라진 데이터 1개
③ 구간이 같음

며칠째인지 + 상태

주의 3일 이상이면 이유 추가

2문장 형식

상황형식
전날 기록 없음{상태}.
구간이 올라감 · 내려감{이유} {변화}.
같은 구간 2일 이상{N}일 연속 {상태}.
주의 3일 이상{이어진 이유 · N일 연속 이어지면서} {상태}.

함께 지키는 규칙

  • 바뀐 날 = 구간이 전날과 달라진 날 (점수만 바뀌면 같은 날)
  • N = 같은 구간이 이어진 날 수 (지난 주까지 거슬러 셈)
  • 오늘이 아닌 날: ‘어제’ → ‘전날’
  • 일상안정 ‘균형’ = 지난주보다 걸음 · 활동 · 운동이 유지·증가(안정) 또는 감소(불안정)한 정도 (매일 일정한지를 뜻하지 않음)

이유 고르는 규칙

  • 세 지표 모두 점수에 준 영향이 가장 큰 항목 1개만
  • 영향이 2점 미만이면 이유 생략
  • 주의가 이어진 날: 그 기간 매일 낮았던 항목만

영향 점수 계산 방법

  • 재료별 영향(점) = 비중 × (오늘 재료 점수 − 어제 재료 점수) × 100
  • 재료 점수 = 산식이 각 재료를 0~1로 바꾼 값 (흐름도 산식 그대로)
  • 내려간 날은 가장 크게 마이너스, 올라간 날은 가장 크게 플러스인 재료 1개
  • 개발: 엔진이 계산 중 가진 재료 점수를 어제 값과 빼기만 하면 됨
지표재료0~1 재료 점수

6지표별 예시

생활여유

올라감수면 시간이 늘어나면서 몸의 여유가 어제보다 나아졌어요.

올라감움직임이 하루에 고르게 나뉘면서 몸의 여유가 어제보다 나아졌어요.

내려감활동이 한때에 몰리면서 몸의 여유가 어제보다 감소했어요.

내려감활동이 많아 부담이 커지면서 몸의 여유가 어제보다 감소했어요.

같음2일 연속 남아 있는 몸의 여유가 보통이에요.

주의 지속수면이 짧은 날이 3일 연속 이어지면서 남아 있는 몸의 여유가 부족한 편이에요.

자기돌봄

올라감식후 활동이 이어지면서 나를 챙기는 정도가 어제보다 나아졌어요.

올라감걸음 수가 늘어나면서 나를 챙기는 정도가 어제보다 나아졌어요.

내려감걸음 수가 줄어들면서 나를 챙기는 정도가 어제보다 감소했어요.

같음2일 연속 나를 챙기는 정도가 좋은 편이에요.

주의 지속식후 활동이 적은 날이 3일 연속 이어지면서 나를 챙기는 정도가 부족한 편이에요.

일상안정

올라감걸음 수가 늘어나면서 일상의 균형이 나아졌어요.

내려감걸음 수가 줄어들면서 일상의 균형이 흐트러졌어요.

같음2일 연속 일상의 균형이 보통이에요.

읽는 법

  • 회복 주 수요일: 활동 분산 2칸 → 5칸 → ‘움직임이 하루에 고르게 나뉘면서’
  • 저하 주 수요일: 취침 00:40으로 늦어짐 → ‘잠드는 시간이 불규칙해지면서’
  • 저하 주 화요일 자기돌봄: 식후 활동도 줄었지만 걸음 수 감소의 점수 영향이 더 커서 걸음 수가 이유
  • 주의가 이틀뿐이라 ‘3일 연속’ 문장은 이 샘플에 나오지 않음

8표시 · 말투

항목규칙
제목‘지표 해석’ 고정 (지난 주 화면도 같음)
기준일날짜 띠에서 고른 날 (지난 주 화면은 그 주 일요일)
갱신저장하지 않음 · 동기화로 값이 바뀌면 다시 만듦
숨김관찰 중 · 건강 데이터 미연동 · 계산 실패

말투 원칙

  • 부드러운 존댓말 + 데이터 용어(수면 시간 · 활동량 · 걸음 수)로 근거 표시
  • 이유는 ‘~하면서’로 연결
  • 한 문장에 비교 표현(어제 · 지난주)은 하나만
  • 점수 · 수치 표기
  • 진단 · 몸 상태 단정
  • ‘~하세요’ 같은 행동 지시

9개발 구현 명세

9-1 생성 위치

  • 문장은 서버(지표 엔진 계층)에서 만들고 앱은 받은 문자열을 그대로 표시 (권장)
  • 앱에서 만들 경우에도 아래 입력 · 처리 순서를 그대로 따름
  • 저장하지 않음 · 구간이나 재료 점수가 바뀌면 다시 생성

9-2 입력 데이터 (지표 · 날짜별)

필드형식설명
metricmargin / selfcare / steady생활여유 / 자기돌봄 / 일상안정
dateYYYY-MM-DD하루 경계는 04:00 (사용자 현지 시간)
bandgood / mid / low / none엔진 판정 구간 · none = 관찰 중 · 미연동 · 계산 실패
parts{재료키: 숫자}생활여유 · 자기돌봄: 0~1 재료 점수
일상안정: 재료별 변화값 −1~1 (최근 7일 vs 직전 7일)
excluded[재료키]관측 부족 · 기회 0 등으로 계산에서 빠진 재료
지표재료키 (비중)
marginactive 0.20 · spread 0.30 · load 0.25 · sleep 0.25
selfcaresteps 0.55 · meal 0.20 (공백 후 움직임 · 활동 분산은 이유 후보 아님)
steadysteps 0.30 · active 0.15 · exercise 0.15 · action 0.15 · walkdays 0.10 · sleepreg 0.15

9-3 처리 순서

1. cur = 선택일 band
   cur == none → 문장 없음(숨김)
2. prev = 선택일 −1일 band
   prev 없음 또는 none → "{상태}."
3. cur != prev (구간 바뀜)
   up = 순서(low < mid < good)로 cur 이 더 높음
   재료별 영향 = 비중 × (오늘 parts − 전날 parts) × 100
     · steady 는 × 50 (표시점수 = 50 + 50 × Z)
   후보 = excluded 제외 재료 중
     up 이면 영향 > 0, 아니면 영향 < 0
     margin 의 load 는 내려간 날만 후보
   best = |영향| 최대 (동점이면 비중 큰 순 → 표의 순서)
   |best 영향| < 2 → 이유 없음
   → "{이유 문구} {변화 문구}."
4. cur == prev (구간 같음)
   N = 선택일부터 거꾸로 같은 band 가 이어진 날 수
       (none · 기록 없는 날에서 끊음, 지난 주까지 셈)
   N ≥ 2 → "{N}일 연속 {상태}."
   cur == low 이고 N ≥ 3 →
     그 N일 동안 매일 '낮음'인 재료가 있으면
     "{재료} … N일 연속 이어지면서 {상태}." (앞의 'N일 연속'은 생략)
5. 선택일 ≠ 오늘 → 문장의 "어제" 를 "전날" 로 치환
