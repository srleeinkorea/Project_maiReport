v0.2 변경 요지

구 지표(회복여유·생활부담·리듬안정성, 각 0~100·좋은 방향 고정)를 지표 기획서 v0.3의 생활여유·자기돌봄·일상안정으로 교체했습니다. 이름만이 아니라 표시 모델이 바뀝니다 — ① 점수/100 비노출, 상태 표현만 ② 종합 점수·종합 문장 금지(P5) ③ 일상안정은 주 단위로만 방향 갱신(일 단위 화살표 없음) ④ 자기돌봄은 ‘기준점—행동 연결’ 구조라 활동 총량으로 대체 불가.

확정 · C-3 결과값 어휘

2026-09-11 기획 결정 — 문장형 채택. 칩·요약·말풍선 모두 문장형(충분해요 · 잘하고 있어요 · 안정적이에요 …)으로 통일합니다. 「잘하고 있어요 / 부족해요」가 노력을 평가하는 말투로 읽히는 것은 허용하며, 화면 문구에서 우회하지 않습니다. 일상안정의 「안정적이에요」는 좋은 쪽에만 붙으므로 긍정 어감과 지표의 좋은 쪽이 일치합니다.

화면 반영 시 확인 — ① 칩·카드처럼 좁은 영역에 문장형이 들어가는지(가장 긴 라벨 “잘하고 있어요” 기준으로 폭 검증) ② 기획서 5·7장과 MRS 9장의 ‘평가·압박 어투 배제’ 조항은 이 결정과 충돌하므로 갱신 대상. 단 의료 판정 표현(정상/비정상·위험·진단) 금지는 그대로 유지됩니다(PX-M6).

확정 · C-1 지표명

2026-09-11 결정 — 생활여유 · 자기돌봄 · 일상안정으로 확정했습니다. 지표 2를 ‘건강돌봄’으로 쓰던 산출 파이프라인 표기는 폐기되며, 엔진 v5.7의 I1/I2/I3 표기(생활 여력 · 행동 기회 연결 · 개인 기준 변화)도 확정 명칭으로 갱신해야 합니다(C-4 · 개발팀).

HOME-001 · 오늘의 컨디션 카드

HOME-001

오늘의 컨디션 카드

홈 대시보드 섹션
목적
홈에서 오늘의 세 지표 상태를 한눈에 요약하고, 상세(HOME-003)로 펼쳐보게 한다.
진입
홈 대시보드 스크롤 노출. 별도 진입 동작 없음.
선행조건
로그인 · 건강 앱 연동 1개 이상(가입 시 완료 전제).

구성요소

상태 한 줄 검토

오늘 가장 두드러진 지표 1개를 골라 그 지표의 상태를 서술. 세 지표를 합쳐 ‘전반적인 상태’로 뭉뚱그리는 문장은 쓰지 않습니다(P5 — 각 지표가 답하는 질문이 다름). 선정 규칙 미확정.

지표 3요약

생활여유 · 자기돌봄 · 일상안정 각 상태 표현(충분해요/보통이에요/부족해요 등 문장형) + 방향 라벨(▲ 좋아졌어요 / · 큰 변화 없이 유지 / ▼ 주의가 필요해요). 점수/100·링 progress 비노출 — 내부 값은 화면에 바인딩하지 않음(P4). 일상안정은 주 단위 갱신이라 일 단위 방향 라벨을 표시하지 않음.

펼쳐보기

‘오늘의 컨디션’ 헤더 탭 → HOME-003 아코디언 확장. aria-expanded 토글.

빈 상태

기기 미연동/데이터 없음 시: 요약 대신 “건강 데이터가 모이면 오늘의 컨디션을 보여드려요” + 연결 유도.

상태

상태조건표시
정상지표 2개 이상이 고해상도(watch + 충분한 기준선)상태 한 줄 + 3지표 상태 표현·방향
부분수집일부 지표만 산출(저해상도 포함)산출된 지표만 상태 표현(‘참고’ 배지), 나머지 ‘관찰 중’
미수집세 지표 모두 ‘관찰 중’ 또는 연동 해제빈 상태 + 연결 유도

데이터 바인딩

입력
metric_state(당일, 3건) · metric_state.state_key · metric_state.direction · metric_state.resolution · deviceLinked
파생
상태 한 줄 = 대표 지표 1개의 상태 문구 템플릿(지표 기획서 7장). 내부 값(internal_value)은 화면에 바인딩하지 않음

예외

산출 지연

당일 metric_state 미생성: 직전 계산본 + “업데이트 중” 표기, 스켈레톤 노출.

일부 지표만 산출

산출 안 된 지표 자리에 “관찰 중 · 데이터가 모이면 보여드려요” 안내, 방향 라벨 생략.

저해상도(폰만)

생활여유만 저해상도 경로로 표시 가능. ‘참고’ 배지 + 방향 생략 가능, 문구 축약. watch 미사용자가 불리해 보이지 않게 표현(P2 · D-3).

HOME-003 · 오늘의 컨디션

HOME-003

오늘의 컨디션 (아코디언)

홈 · 기본 접힘
목적
세 지표의 오늘 상태와 근거가 된 건강 데이터, 평소 대비 변화, 해석 note를 보여준다.
진입
HOME-001 ‘오늘의 컨디션’ 헤더 탭 → 확장. 재탭 시 접힘.
기준
Baseline = 최근 기간의 개인 데이터(전날 대비 아님). 윈도우 길이 미확정 — 엔진 28일(최근 7일+직전 21일) / 산출 파이프라인 30일로 불일치, 기획서 9장 B-5에서 통일 예정. 안내 문구의 일수 표기는 확정 후 반영.

구성요소

지표 그리드(m-grid)

생활여유·자기돌봄·일상안정 3카드. 각 카드 = 지표명, 상태 표현(문장형), 방향 라벨. 링(점수 %)·점수/100은 제거(P4). 탭하여 선택/해제(단일 선택). ‘관찰 중’ 카드는 선택 불가.

상태 라인(condLine)

미선택 시 대표 지표 1개 문장(세 지표 종합 문장 금지 — P5). 선택 시 해당 지표 문장(예: “오늘은 여유가 부족한 편이에요.”).

근거 데이터 리스트(d-list)

미선택 → 기본 3항목(걸음·수면·안정 시 심박). 선택 → 해당 지표의 core/aux 데이터만. 각 행 = 아이콘·항목명·값·평소 대비(▲/▼/·).

해석 note(dNote)

미선택 → 기준선 안내. 선택 → 가장 크게 기여한 구성 요소 1~2개 요약(예: “활동이 저녁에 몰려 여유가 부족한 편이에요”). 질문·기록이 상태를 올린 것처럼 쓰지 않음(P1·P3).

지표 선택 시 노출 데이터 (지표 기획서 3장 매핑)

선택 지표노출 core노출 aux(요약)좋은 쪽
생활여유활동 시간대 분포, 비활동(좌식) 구간수면·활동량/강도·운동 기록·안정 시 심박/HRV·어려움 응답충분해요
자기돌봄비활동(좌식) 구간, 식사 기록활동 시간대 분포·일정(캘린더)·운동 기록·활동량잘하고 있어요
일상안정활동 시간대 분포, 비활동(좌식) 구간수면·체중·심박·활동량 흐름안정적이에요

‘좋은 쪽’은 지표마다 다르며 0~100 스케일의 높다/낮다가 아닙니다. 자가보고(어려움 응답)와 식사 기록은 노출 근거로는 쓰되 상태를 올리는 입력으로 표시하지 않습니다(P1·P3). 건보공단·의료이력은 노출 대상이 아닙니다.

상태 / 예외

상태조건표시
정상고해상도 — watch + 충분한 기준선상태 표현 + 방향 + 이유 + 근거 구성 요소 전체
부분수집저해상도 — 폰 활동 데이터만상태 표현(개략) + 이유 축약, 방향 생략 가능, ‘참고’ 배지
미수집기준선·기준점 부족 → ‘관찰 중’상태 미표시, “관찰 중 · 데이터가 모이면 보여드려요” · 선택 불가
연동 해제deviceLinked=false세 지표 모두 ‘관찰 중’. 아코디언 전체를 빈 상태 + 건강 앱 재연결 유도로 대체

지표별 최소 표시 조건 (지표 기획서 4·5·6·8장)

지표표시되는 최소 조건저해상도 대체미달 시
생활여유[고] 움직임 시간대 분포 + 수면  /  [저] 걸음 기록 또는 어려움 응답 1개  + 개인 기준선있음 — 3종 중 유일. 고·저 경로는 눈금이 달라 비교·차감하지 않음관찰 중
자기돌봄기준점 신호(식사 시각 또는 긴 비활동 종료·일정 전후) + 움직임 시간대 분포 — 둘 다 필수없음 — 시간대가 없으면 기회 자체를 정의 불가. 걸음 총량으로 대체 불가관찰 중
일상안정약 28일 관측 이력(최근 7일 + 직전 21일)에 걸음·움직임·수면 중 최소 1계열해상도보다 이력 기간이 관건. 당일 기록 없어도 이력 있으면 산출관찰 중(형성 기간은 B-9 미확정)
표현 제약

상태 표현·근거·note 모두 ‘평소(개인 기준) 대비’ 상대 표현. 절대 수치의 정상/비정상 판정, 위험·진단 표현 금지. 평가 어투는 허용(C-3 확정)하되, 산출이 코칭 순응도·목표 달성률을 재는 것처럼 설명하지는 않습니다. 자가보고에 증상·통증이 있으면 note 대신 상담 안내로 전환. (지표 기획서 7장 · MRS 9장)

LIFE-002

지표별 분석

생활 메인 탭
목적

구성요소

분석 기간
