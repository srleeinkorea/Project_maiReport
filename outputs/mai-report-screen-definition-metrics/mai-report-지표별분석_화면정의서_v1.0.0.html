1화면 개요

위치, 역할, 화면 구조

1.1 위치와 역할

생활 탭의 두 번째 서브탭(목표 분석 · 지표별 분석 · 생활 분석 · AI 인사이트). 홈의 오늘의 컨디션 카드나 › 를 누르면 이 탭으로 들어온다. 사용자는 세 카드를 내려 보며 생활여유 → 자기돌봄 → 일상안정 순으로 "지금 어느 구간인지 · 이번 주 어떻게 움직였는지 · 왜 그런지 · 어떤 데이터가 쓰였는지"를 확인한다.

1.2 화면 구조

상단 공통생활 헤더(주차 · 오늘 버튼) · 날짜 스트립 · 서브탭
카드 ① 생활여유헤더 · 주간 그래프 · 현재 흐름 · 핵심 데이터
카드 ② 자기돌봄동일 구성
카드 ③ 일상안정동일 구성 (기준: 최근 7일)

카드 순서는 고정이며 접힘/펼침이 없다. 세 카드 외의 요약·합산 영역은 두지 않는다.

1.3 기준일

날짜 스트립에서 선택한 날이 기준일이다. 기본은 오늘. 과거 날짜를 선택하면 그날의 구간·흐름·핵심 데이터를 보여주고, 미래 날짜는 선택할 수 없다. 이전 주로 이동하면 그 주 일요일이 기준일이 되며 읽기 전용이다.

4주간 그래프 규칙

숫자를 노출하지 않으면서 흐름을 읽게 하는 장치. 띠는 의미, 선은 움직임
요소규칙
구간 영역좋음 · 보통 · 주의 세 구간을 그래프 배경 영역으로 구분하고 각 구간에 짧은 이름을 붙인다(§5). 구간 비율은 구간 경계(잠정 66 / 33)를 따른다
기간월~일 7일. 기준일을 구분해 표시. 이전 주로 이동하면 그 주의 요일
값 표시값이 있는 날만 점을 찍고 이웃한 날끼리 선으로 잇는다
기준일다른 날과 구분되게 표시
결측 · 미래점을 찍지 않고 선을 끊는다. 0이나 이전 값으로 메우지 않는다. 미래 요일은 비워 둔다
표시하지 않는 것축 눈금·숫자, 점 위 값, 평균선, 증감 표시. 점을 눌러도 값이 뜨지 않는다
일상안정다른 두 지표와 같은 형식으로 그리되, 각 날의 값은 "그날 기준 최근 7일"로 산정한 것이다(§5)

상태조건화면
산정 가능기준일 구간이 산출됨§3 전체 구성
관찰 중기준일 구간을 산출할 수 없음(데이터 부족, 기준선 미형성 등)지표명만 두고 그래프·흐름·핵심 데이터 대신 빈 상태: "아직 관찰 중이에요" + 지표별 사유 한 줄. 구간 배지 없음. 결측을 낮은 구간으로 표시하지 않는다
주 중 일부 결측기준일은 산정되지만 주 중 일부 날이 결측정상 카드. 그래프에서 해당 날만 점 없이 선을 끊는다

9확인 필요 사항

이 문서 확정 전 담당자 결정이 필요한 항목
#항목내용상태
1흐름 문장 생성 규칙구간·변화 방향·핵심 데이터 조합별 문장 템플릿과 금지 어휘를 별도 문서로 확정작성 예정
2관찰 중 사유 문구지표별 산출 불가 원인(데이터 부족, 기준선 미형성, 기회 미관측 등)에 대응하는 문구 세트확인 필요
3구간 경계 66/33지표 엔진이 구간을 직접 내려주는지, 그래프 띠 비율을 고정할지확인 필요
4이전 주 조회 범위‹ 로 몇 주까지 거슬러 올라갈지(가입일 하한)확인 필요
5일상안정 주간 표현날마다 "그날 기준 최근 7일"로 그리는 방식이 사용자에게 자연스러운지 검증확인 필요
