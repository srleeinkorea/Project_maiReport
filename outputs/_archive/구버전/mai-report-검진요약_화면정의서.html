1화면 개요

위치, 역할, 화면 구조

1.1 위치와 역할

병원 탭의 첫 번째 서브탭(검진요약 · 진료요약 · 방문이력 · 읽을거리). 사용자가 직접 입력하지 않고 국민건강보험공단에서 받아온 검진 결과를 보여준다. 진료요약·방문이력은 건강보험심사평가원에서 받아오므로 출처가 다르다. 생활 탭이 매일 쌓이는 생활 기록을 다룬다면, 검진요약은 1~2년에 한 번 갱신되는 검진 결과를 다룬다.

1.2 화면 구조

①가져오기 전안내 카드 · 무엇을 볼 수 있는지 · "건강검진 데이터 가져오기"
②가져오는 중진행 카드 · 뼈대 화면
③가져온 뒤건강 나이 · 위험도 분석 진입 · 주요 검진 소견 · 검진 대상자 안내
④이어지는 화면주요질환 위험도 · 전체 검진 항목 · 항목 상세

세 상태가 같은 자리를 쓴다. ①에서 버튼을 누르면 ②로 바뀌고, 끝나면 ③으로 바뀐다.

1.3 이 화면의 성격

공단이 제공한 결과를 옮겨 보여주는 화면이다. 값을 새로 계산하거나 판정을 바꾸지 않는다. 건강 나이처럼 이 서비스가 계산하는 값은 무엇을 근거로 했는지 함께 밝힌다.

2.1 탭별 연동

검진은 국민건강보험공단, 진료는 건강보험심사평가원으로 기관이 달라 인증도 따로 한다. 하나의 버튼으로 두 기관을 묶지 않고 각 탭에서 그 탭에 필요한 데이터를 가져온다. 탭별 연동 표와 한쪽만 연동된 상태의 처리는 진료요약_화면정의서 §2.1 · §2.2에 있다.

7.3 상태 표기

공단 판정을 그대로 옮기되, 화면 문구는 서비스 공통 표기를 쓴다. AI검진요약 화면정의서에서 정한 것과 같은 규칙이다.

화면 문구공단 판정뜻
정상정상A지금 수준을 유지하면 되는 값
관리 필요정상B(경계)생활습관으로 지켜볼 값
확인 필요유질환 의심 · 질환 의심의료 상담이 필요한 값
"경계 · 주의 · 위험 · 심각 · 이상"은 화면 어디에도 쓰지 않는다. 사용자가 진단으로 받아들일 수 있고, 같은 값이 화면마다 다른 말로 불리면 신뢰가 떨어진다. 시안에 쓰인 "표준 · 경계 · 주의"는 이 규칙에 맞춰 "정상 · 관리 필요 · 확인 필요"로 바꾼다(§11).

여러 값을 가진 항목(간수치·신장수치)은 그중 가장 나쁜 판정을 행의 상태로 쓴다. 어떤 값 때문인지는 항목 상세에서 확인한다.
