AI 요약은 또래 분포 안의 위치를 이해하기 쉽게 정리한 참고 정보이며, 의학적 진단이나 의료진의 판단을 대신하지 않습니다. 결론과 먼저 볼 항목은 규칙이 정하고, AI는 수치 없는 문장만 씁니다.

계산 순서 (적용 절차서 PCT-002와 같음)

1. 검진일 기준 만 나이 → 5세 구간 (20세 미만은 계산 안 함, 80세 이상은 한 구간)
2. 성별·구간으로 기준표에서 내 행을 찾음
   - 키·체중·BMI·허리둘레 : 국민건강영양조사 2022~2024 경계값 99개 (p1~p99)
   - 혈압·혈당·지질·간·신장·혈색소 : 건강검진통계 2024 구간별 인원수
3. 분포 위치 P = 나보다 값이 작은 사람의 비율
   - 경계값표 : 내 값이 넘는 마지막 경계 k + 다음 경계까지의 비율
   - 인원표   : 내 값보다 아래 구간 인원 합 + 내 구간 인원 × (x−하한)/(상한−하한), ÷ 총 인원
4. 또래 상위 % : 낮을수록 좋은 항목 = P, 높을수록 좋은 항목(HDL·혈색소·eGFR) = 100 − P, 키·체중 = "큰 순 상위 (100 − P) %"
5. 100명 중 N번째 = 반올림 후 1~99로 제한 · 구간 라벨 1~25 좋음 / 26~60 또래 수준 / 61~85 나쁨 / 86~99 하위 15 %
6. BMI 18.5 미만, 수축기 90 미만, 이완기 60 미만은 순위 대신 "확인 필요"
7. 종합 = 방향 있는 항목 rank의 평균 (3개 미만이면 없음), 먼저 볼 항목 = rank 큰 순 3개
  • BMI는 키·체중을 넣으면 자동 계산됩니다. 결과지의 BMI를 쓰려면 BMI 칸에 직접 입력하세요.
  • 지질 4종(총콜레스테롤·HDL·중성지방·LDL)은 건강검진통계가 2024년 검사 대상자만 집계해 20~39세 여성은 "검사 대상 아님"으로 계산하지 않습니다.
  • 기준 데이터 출처: 질병관리청 국민건강영양조사 2022~2024 원시자료(성인 17,262명, 가중 백분위), 국민건강보험공단 건강검진통계 2024(KOSIS, 수검자 약 1,750만 명).
