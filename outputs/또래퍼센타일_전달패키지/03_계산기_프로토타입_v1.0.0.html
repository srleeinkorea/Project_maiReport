AI 요약 · 또래 기준

–

AI 요약은 또래 분포 안의 위치를 이해하기 쉽게 정리한 참고 정보이며, 의학적 진단이나 의료진의 판단을 대신하지 않습니다. 결론과 먼저 볼 항목은 규칙이 정하고, AI는 수치 없는 문장만 씁니다.

산출 방법

항목 i의 값 x, 또래(성별 × 10세 구간) 평균 μ, 표준편차 σ일 때

정규 항목 :  z = (x − μ) / σ
왜도 항목 :  z = (ln x − ln μ_g) / ln σ_g        # 중성지방·간효소 등 오른쪽 꼬리가 긴 항목은 로그정규
분포 위치 :  P = Φ(z) × 100                         # 또래 중 나보다 값이 낮은 사람의 비율

또래 상위 % (건강 순위)
  낮을수록 좋은 항목 :  rank = P            →  "상위 rank %"
  높을수록 좋은 항목 :  rank = 100 − P      →  HDL, 헤모글로빈
  방향 없는 항목     :  "큰 순 상위 (100 − P) %"로만 표기, 종합에서 제외  →  키, 체중
  종합               :  항목 rank의 산술평균 (가중치 없음, 구간 등급으로 표기 권장)
  • 표기는 "상위 23 %" 또는 "100명 중 23번째"로 통일합니다. 정확한 등수 표기는 하지 않습니다.
  • BMI·혈압은 너무 낮아도 문제이므로, 저체중·저혈압 범위에 들면 순위 대신 경고를 띄웁니다.
  • 정상/이상 판정과는 별개입니다. 상위 10 %여도 기준치를 넘을 수 있고, 하위 40 %여도 정상 범위일 수 있습니다.
기준 분포는 국민건강영양조사 공표 통계를 참고한 근사값입니다. 실제 서비스 적용 전에 국민건강보험공단 한국인 혈압·혈당 참조표준(2세 단위)과 건강검진 통계연보 값으로 교체해야 합니다. 아래 표의 JSON 구조를 그대로 유지하면 코드 수정 없이 교체됩니다.
