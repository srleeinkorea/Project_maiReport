또래 등수 산식 적용 절차

PCT-002v1.0 · 2026-09-14규격 PCT-001 · 조회 테이블 20번 CSV · 엑셀 02_또래등수_산식_v1.0.0.xlsx

검진 결과 값 하나를 받아 "같은 성별·나이대 100명 중 몇 번째"를 돌려주기까지의 절차입니다. 위에서부터 순서대로 따라가면 됩니다. 각 단계 끝의 예시는 남자 45세, BMI 24.5로 실제 조회 테이블 값을 써서 계산한 것입니다.

01계산 절차 (경계값표가 있는 항목: 키·체중·BMI·허리둘레)

STEP 1 나이 구하기

검진일 기준 만 나이를 계산합니다. 오늘 기준이 아니라 검진일 기준입니다. 같은 검진은 몇 년 뒤에 봐도 등수가 같아야 하기 때문입니다.

age = 검진일.year - 생년월일.year
if (검진일.month, 검진일.day) < (생년월일.month, 생년월일.day): age -= 1
예시 1981-03-10 생, 검진일 2026-04-12 → 45세

STEP 2 나이 구간 정하기

5세 단위로 묶습니다. 20세 미만은 계산하지 않습니다. 80세 이상은 한 구간입니다.

if age < 20:  return 계산 안 함
if age >= 80: band = "80세이상"
else:         lo = (age // 5) * 5;  band = f"{lo}-{lo+4}세"    # 45 → "45-49세"
예시 45세 → 45-49세

STEP 3 조회 테이블에서 내 행 찾기

항목·성별·구간 세 가지가 모두 같은 행 하나를 가져옵니다. 행이 없으면 계산하지 않고 "또래 비교 불가"로 둡니다.

row = table[(항목="BMI", 성별="남자", 연령="45-49세")]
bounds = [row.p1, row.p2, ..., row.p99]      # 오름차순 99개
예시 남자 45-49세 BMI 행: p1 18.0 … p25 23.2 … p39 24.45, p40 24.50, p41 24.54 … p50 25.3 … p75 27.6 … p99 35.9 (n=567)

STEP 4 내 값이 몇 번째 경계를 넘는지 찾기 (k)

경계값 99개 중 내 값보다 작거나 같은 것이 몇 개인지 셉니다. 이것이 k입니다. 오름차순 배열이므로 이진 탐색을 쓰면 됩니다.

k = 0
for i in 1..99:
    if bounds[i] <= x: k = i
    else: break
# 또는 k = bisect_right(bounds, x)
예시 x = 24.5. p40 = 24.50 ≤ 24.5 이고 p41 = 24.54 > 24.5 → k = 40

STEP 5 경계 사이 위치를 더하기 (보간)

내 값이 k번째 경계와 k+1번째 경계 사이 어디쯤인지 비율(0~1)을 구해 k에 더합니다. 이 값이 분포 위치 P이며 "나보다 값이 작은 사람이 100명 중 P명"이라는 뜻입니다.

if k == 0:        P = 1                       # p1보다 작음
elif k >= 99:     P = 99                      # p99 이상
else:
    lo, hi = bounds[k], bounds[k+1]
    frac = 0 if hi == lo else (x - lo) / (hi - lo)
    P = k + frac
예시 lo = p40 = 24.50, hi = p41 = 24.54, x = 24.5 → frac = 0 → P = 40.0. 만약 x가 24.52였다면 frac = 0.02/0.04 = 0.5 → P = 40.5

STEP 6 방향 뒤집기 → 또래 상위 % (rank)

P는 "작은 쪽에서 몇 번째"입니다. 항목마다 어느 쪽이 좋은지 다르므로 방향을 맞춥니다.

항목방향rank화면 문구
BMI, 허리둘레, 혈압, 혈당, 총콜레스테롤, LDL, 중성지방, 간효소, 크레아티닌낮을수록 좋음rank = P또래 상위 {rank} %
HDL, 혈색소, 신사구체여과율높을수록 좋음rank = 100 − P또래 상위 {rank} %
키, 체중방향 없음size = 100 − P큰 순 상위 {size} % (좋고 나쁨 표시 안 함, 종합 제외)
예시 BMI는 낮을수록 좋음 → rank = 40.0

STEP 7 저값 경고 확인

너무 낮아도 문제인 항목은 순위 대신 경고를 냅니다. 낮은 값이 "상위 1 %"로 보이는 것을 막기 위해서입니다.

if 항목 == BMI    and x < 18.5: return 확인필요("저체중")
if 항목 == 수축기 and x < 90:   return 확인필요("저혈압")
if 항목 == 이완기 and x < 60:   return 확인필요("저혈압")
예시 24.5 ≥ 18.5 → 해당 없음

STEP 8 표시값 만들기

display = clamp(round(rank), 1, 99)          # 0과 100은 쓰지 않음
label   = "또래보다 좋음"   if display <= 25
        = "또래 수준"       if display <= 60
        = "또래보다 나쁨"   if display <= 85
        = "또래 하위 15%"   otherwise
문구    = f"또래 상위 {display} % · 100명 중 {display}번째"
예시 display = 40, label = 또래 수준, 문구 = "또래 상위 40 % · 100명 중 40번째"

STEP 9 저장

검진 1건마다 항목별 결과를 저장하고, 화면은 저장값만 읽습니다. 조회 테이블 버전을 같이 남겨 테이블이 바뀌면 재계산합니다.

{ "exam_id": "...", "table_version": "knhanes-2022-2024.v1",
  "items": { "BMI": { "x": 24.5, "P": 40.0, "rank": 40.0, "display": 40,
                      "label": "MID", "k": 40, "cohort": "남자|45-49세" } } }

02경계값표가 아직 없는 항목 (혈압·혈당·지질·간·신장·혈색소)

이 항목들은 건강검진통계의 구간 인원표를 씁니다. STEP 3~5만 다르고 나머지는 같습니다.

STEP 3′ 내 행 찾기

성별·5세 구간 행을 가져옵니다. 행에는 구간별 인원수와 합계가 있습니다. 구간 경계는 열 이름에서 정하고, 양끝 열린 구간(예: "180 이상")은 계산용 바깥 경계를 둡니다(엑셀 D_ 시트 3~4행).

예시 남자 45-49세 수축기혈압: 합계 894,051 · 110 미만 89,345 · 110-119 234,887 · 120-129 253,557 · 130-139 220,513 · 140-149 60,221 · …

STEP 4′ 나보다 작은 사람 수 세기

below = Σ 인원[구간]                       for 구간.상한 <= x
      + 인원[내 구간] × (x − 하한) / (상한 − 하한)   # 내 값이 든 구간은 비율만큼
예시 x = 148: 140 미만 합계 798,302 + 140-149 구간 60,221 × (148−140)/10 = 48,177 → below = 846,479

STEP 5′ 비율로 바꾸기

P = below / 합계 × 100
예시 846,479 / 894,051 × 100 = 94.7 → rank 94.7 → display 95, "또래 하위 15%"
지질 4종(총콜레스테롤·HDL·중성지방·LDL)은 2024년 검사 대상자만 집계되어 20~39세 여성 행의 합계가 0입니다. 합계가 0이면 계산하지 말고 "또래 비교 불가"로 둡니다. 이 항목들도 국민건강영양조사 원시자료로 경계값표를 만들면 해결됩니다.

03종합

  1. 대상: 방향이 있는 항목 중 계산된 것(키·체중·경고 항목 제외).
  2. 항목이 3개 미만이면 종합을 만들지 않습니다.
  3. avg = mean(rank), 가중치 없음. 화면에는 숫자 대신 구간 라벨(STEP 8과 같은 경계)만 보여줍니다.
  4. 먼저 볼 항목: rank가 큰 순서로 최대 3개. rank > 85인 항목이 있으면 그것부터.

04조회 테이블 자체를 만드는 절차 (데이터 담당)

이미 만든 20번 CSV가 어떻게 나왔는지, 그리고 다른 항목으로 확장할 때 따라 할 절차입니다.

T1 원시자료 확보

국민건강영양조사 누리집 → 원시자료 → 다운로드 → 조사영역 "공통", 연도 3개년(2022~2024) → 기본DB SPSS. 사용자등록 후 이용자 준수사항에 동의하면 받을 수 있습니다.

T2 변수 뽑기

sex(1 남, 2 여), age, HE_ht, HE_wt, HE_BMI, HE_wc, wt_itvex(검진 가중치). 혈압은 HE_sbp/HE_dbp, 혈당은 HE_glu, 지질은 HE_chol/HE_HDL_st2/HE_TG/HE_LDL_drct, 간은 HE_ast/HE_alt, 신장은 HE_crea. 변수명은 연도별 이용지침서에서 확인합니다.

T3 대상 걸러내기

만 19세 이상, 값이 있고, 가중치가 0보다 큰 사람만. 3개년을 합칠 때는 각 연도 가중치를 3으로 나눕니다.

T4 집단별로 나누기

성별 × 5세 구간(20-24 … 75-79, 80세 이상). 한 집단의 표본이 30명 미만이면 그 집단은 만들지 않습니다.

T5 가중 백분위 계산

값 오름차순 정렬
W = Σ 가중치
for q in 1..99:
    target = W × q / 100
    누적 가중치가 target을 처음 넘는 사람 i를 찾음
    p_q = 값[i-1] + (값[i] − 값[i-1]) × (target − 누적[i-1]) / 가중치[i]   # 선형 보간

가중평균은 Σ(값 × 가중치) / W, 가중표준편차는 √( Σ(가중치 × (값 − 평균)²) / W ).

T6 검증

  • p1 ≤ p2 ≤ … ≤ p99 (오름차순) 확인.
  • p50이 가중평균과 크게 다르지 않은지(BMI·체중은 오른쪽 꼬리 때문에 평균이 p50보다 조금 큼).
  • 건강검진통계 구간표로 계산한 P와 비교. 예: BMI 24.5 → 경계값표 40.0, 구간표 41.2.

T7 버전과 출처 기록

파일명에 조사 연도, 생성일, 버전을 남기고, 화면 고지에 "국민건강영양조사 2022~2024(질병관리청)"를 표기합니다. 원시자료는 재배포하지 않고 요약표만 배포합니다.

06자주 틀리는 곳

  • 나이 기준을 오늘로 잡으면 같은 검진의 등수가 해마다 바뀝니다. 검진일 기준으로 고정합니다.
  • k를 셀 때 "작거나 같음"입니다. 경계값과 정확히 같은 값은 그 경계 번호가 k입니다.
  • hi == lo(경계값이 같은 구간)에서 0으로 나누지 않도록 frac = 0 처리합니다.
  • HDL·혈색소·eGFR은 반드시 100 − P로 뒤집습니다. 뒤집지 않으면 HDL이 높은 건강한 사람이 "또래 하위"로 나옵니다.
  • 0 %와 100 %는 표시하지 않습니다. 1~99로 자릅니다.
  • 단위가 다르면(혈당 mmol/L 등) 먼저 환산합니다. 환산표가 없으면 계산하지 않습니다.
  • BMI는 결과지에 있으면 결과지 값을, 없으면 체중 / (키/100)²로 계산해 소수 1자리로 씁니다.
