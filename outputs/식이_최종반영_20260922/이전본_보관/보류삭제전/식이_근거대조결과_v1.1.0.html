실제 전문의 승인미완료·출시 비활성

임상 검토 반영

  • WHO의 채소·과일 합계와 유리당 정의를 바로잡았다. 숫자·접시 수·음식 한 가지로 권고량 충족을 단정하지 않는다.
  • 과일 추천 제외는 사용자 정책으로 유지한다. 지방간 근거에서 가당 음료와 통과일을 혼동하지 않는다.
  • 신장질환의 칼륨·인·단백질·수분과 심부전 수분은 개인화 대상이다. 정보 부족으로 자동 권고를 보류하는 것과 해당 식품이 전원 금기라는 진술을 구분한다.
  • 당뇨병은 약물·저혈당 상황이 중요하다. 처치용 당 섭취를 ‘나쁜 행동’으로 기록하거나 공복·탄수화물 감량을 자동 지시하지 않는다.
  • 임신·섭식장애·영양결핍·암 치료·투석·수술후·연하장애에는 일반 목표가 개인 영양 계획을 대체하지 않는다.
  • 진료 코드 반복과 ‘관리 중’ 답은 임상 확진을 만들지 않는다. 기존 코드 범위는 미검증으로 남기고 실제 연동 코드체계·예외·재질문 규칙을 승인해야 한다.

의학적으로 틀린 부분이 전혀 없다고 보증하거나 실제 전문의 검수 완료라고 표기하지 않는다. 코드 판정, 개별 제한, 문구 노출 적합성, 질문의 타당성은 실제 의료 책임자의 승인이 남아 있다. 파일에 승인자·승인일을 임의 기입하지 않았다.
