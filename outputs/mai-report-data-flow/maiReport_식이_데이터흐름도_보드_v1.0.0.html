고정 1문항 + 회전 최대 1문항 · 3지선다 · 회전은 식습관 관찰 · 달성은 완료 토글

최종 파일상세기획데이터 흐름의학 근거 대조시나리오

기존 링크를 유지한 v1.1.0 반영본입니다. 이전 v1.0.0 내용은 최종 반영 폴더의 이전본 보관에 있습니다.

두 기록을 분리해서 이어간다

1. 입력진입 시각·고정 답·회전 답
검진·진료·개인 제한
2. 질문고정 1 + 관찰 회전 최대 1
각 3지선다
3. 관찰 저장끼니·질문 버전·선택지 코드
28일 집계 → 다음 세션
4. 목표 선정오늘 고정 답 + 전일까지 상태
회복/질환/검진/부담/일반
5. 공통 필터보류·과일 정책·개인 제한
시간·승인 → 모든 대체 후보 재검사
6. 달성 저장문구·이유 스냅샷 + 완료 토글
토글 → 축 단계 조정

회전 답 → 목표 달성 연결 없음. 어제 목표 대상 끼니 → 오늘 회전 질문 연결 없음.

확정된 구성

  • 매 세션 고정 1개와 회전 최대 1개. 각 질문은 선택지 3개를 유지한다.
  • 고정 답이 거의 못 먹음·결식이거나 아직 저녁 전이면 회전 문항을 조건상 생략한다. 21시 이후 기존 ‘아직 저녁 전’ 링크는 질문을 늘리지 않는 처리 상태다.
  • 어제 목표와 대상 끼니가 같다는 이유로 회전 축을 정하지 않는다. 어제 결식에 따른 단백질 질문 강제도 제거한다.
  • 회전 답은 식습관 관찰 자료다. 목표 완료·쉬기는 사용자 토글만 사용한다.
  • 과일 섭취 추가·대체 문구는 서비스 정책으로 제외한다. 통과일을 지방간의 원인으로 일괄 판정하는 문구를 쓰지 않는다.
  • 모든 풀과 대체 단계에서 동일한 승인·금지·개인 제한·시간 필터를 적용한다.
기획·데이터 수정 완료본. AI의 공식 근거 대조이며 실제 전문의 최종 승인 문서가 아닙니다. 실서비스 활성화는 승인자·승인일·대상 범위 확인 후 결정합니다.
