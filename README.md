## 규칙
- 파일 이름은 `..._v1.0.0.<확장자>`로 고정하고 버전은 파일 안에 적는다. 이름을 바꾸면 SharePoint 공유 주소가 끊긴다.
- 같은 파일을 두 폴더에 두지 않는다. 외부에 보낸 묶음은 `전달/`에 보낸 그대로 두므로 원본과 겹쳐도 된다.
- 새 엔진 주제(활동·수면 등)는 `엔진/식이/`의 구성(문구·데이터 계약·검수·엔진 코드)을 본떠 만든다.
- 새 문서가 화면정의서·목업이면 `화면/`의 탭 폴더에, 계산식·규칙·데이터 계약이면 `엔진/`에 넣는다. 어느 쪽도 아니면 `화면/90_기타`.
- 기획서·화면정의서·화면설계서는 `docs/화면/90_기타/기획기반/maiReport_문서표준_공통구조_v1.0.0.html`의 구조로 쓴다(양식은 같은 폴더 `양식/`). 그림은 별도 SVG·PNG가 아니라 HTML 안에 인라인으로 넣는다. 2026-10-14에 기존 SVG는 모두 HTML로 바꿨고 원본은 `_archive/svg를html로_2026-10-14/`.
