# Project_maiReport 폴더 구조

2026-10-14에 재편했다. 원본은 이 폴더 하나이고, 나머지(GitHub·공유 사이트·SharePoint)는 여기서 내보내는 사본이다.

기획 산출물(`docs/`)은 두 갈래다. **화면**은 프로토타입 하단 탭(홈·생활·병원·더보기) 기준으로 화면정의서·목업·예시 화면을 담고, **엔진**은 화면과 무관하게 돌아가는 계산·규칙(지표·식이·코칭목표·또래등수)의 기획서·산식·데이터 계약·검수 자료를 담는다. IA 문서의 「03 생성·분석 엔진」과 「04 화면 노출」 구분을 그대로 따른 것이다.

## 규칙
- 파일 이름은 `..._v1.0.0.<확장자>`로 고정하고 버전은 파일 안에 적는다. 이름을 바꾸면 SharePoint 공유 주소가 끊긴다.
- 같은 파일을 두 폴더에 두지 않는다. 전달용 묶음(`docs/엔진/또래등수/전달패키지/`)만 예외다.
- 새 문서가 화면정의서·목업이면 `화면/`의 탭 폴더에, 계산식·규칙·데이터 계약이면 `엔진/`에 넣는다. 어느 쪽도 아니면 `화면/90_기타`.
