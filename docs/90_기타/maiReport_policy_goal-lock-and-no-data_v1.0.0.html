정책 1

질문 답변 전에 완료한 기본 목표의 기록 처리

시나리오 — 사용자가 오늘의 질문에 답하기 전, 기본 목표(식이·운동·수면)를 완료 또는 쉬기로 처리한다. 이후 질문에 답하면 목표가 답변에 맞춰 재개인화된다. 이때 이미 처리한 기록이 사라지는가?

결론

사라지지 않는다. 사용자가 한 번이라도 완료·쉬기로 처리한 목표는 그날 하루 동안 내용과 상태를 모두 잠근다. 재개인화는 아직 손대지 않은(대기 상태) 목표에만 적용한다.

저장 모델 — 기록은 목표 "카드"가 아니라 "카테고리 × 일자"에 귀속

완료·쉬기 기록은 식이 / 운동 / 수면 카테고리별로 날짜에 저장된다. 화면에 보이는 목표 카드의 문구(제목·실행 방법)는 표현 계층일 뿐이며, 주간 목표 분석(LIFE-001)의 달성률은 이 카테고리 단위 기록을 기준으로 집계된다.

따라서 "기록이 사라지는가"의 실제 쟁점은 완료 표시가 붙은 카드의 문구를 개인화 버전으로 바꿔치기할 것인가이다. 바꿔치면 사용자가 실제로 한 행동(예: "식후 10분 걷기")과 화면에 남은 문구가 어긋나므로, 바꾸지 않는다.

대상질문 답변 후 처리비고
완료한 목표 유지 문구·완료 상태 그대로 고정 되돌리기(완료 취소) 전까지 잠금
쉬기한 목표 유지 문구·쉬기 상태 그대로 고정 완료와 동일하게 "사용자가 판단을 내린" 기록으로 취급
대기(미처리) 목표 교체 답변을 반영한 개인화 목표로 문구 갱신 상태는 계속 대기
오늘의 코칭 항상 재계산 기록이 아니라 조언이므로 최신 답변을 항상 반영
주간 달성률 (LIFE-001) 그대로 집계 그날 제시된 목표 3개가 분모. 완료한 기본 목표는 정상적으로 분자에 포함
목표별 연속일수(streak) 유지 카테고리 기준이므로 문구가 바뀌어도 연속 기록 승계

경계 사례

3개 모두 완료 후 답변 — 교체할 대기 목표가 없으므로 목표 카드는 그대로. 코칭만 개인화된다. 오늘은 개인화 목표를 보지 못하지만, 이미 실천을 마쳤으므로 문제되지 않는다(다음 날 정상적으로 개인화 목표 제시).

일부만 완료 후 답변 — 완료 1개(기본) + 대기 2개(개인화)로 카드가 섞인다. 섞임 자체는 허용하되, 대기 목표 상단에 "답변을 반영해 목표를 새로 추천했어요" 안내를 1회 노출한다.

답변을 되돌려 다시 선택 — 재계산이 다시 돌지만 여전히 대기 목표에만 적용된다. 이미 완료·쉬기한 목표는 계속 잠금.

완료를 취소(사용자가 직접 되돌림) — 잠금 해제되어 대기로 돌아가며, 이후에는 개인화 규칙을 다시 따른다.

기각한 대안 — "완료 상태를 개인화 목표로 이관"

완료 표시를 유지한 채 카드 문구만 개인화 버전으로 교체하는 방식. 사용자가 실제 수행한 행동과 화면 기록이 불일치하고, "내가 안 한 목표가 완료로 표시된다"는 신뢰 문제가 생겨 채택하지 않는다.

정책 2

생활(웨어러블) 데이터가 없을 때의 표시

시나리오 — 건강 데이터 접근 권한이 없거나(거부·미설정), 권한은 있으나 아직 수집된 데이터가 없다. 회복여유·생활부담·리듬안정성 등 생활 데이터 기반 지표를 계산할 수 없다.

결론

가짜 수치를 만들지 않는다. 데이터가 필요한 영역은 빈 상태 + 1탭 연동 경로로 보여주고, 오늘의 질문을 대안 입력 수단으로 안내한다. 질문·코칭·목표·병원(검진·진료) 영역은 정상 동작한다.

지표별 부분 계산 규칙 (상태 ④)

  • 각 지표에는 핵심 산출 데이터가 정의된다 — 회복여유: 심박·수면 / 생활부담: 걸음·활동칼로리·활동시간 / 리듬안정성: 취침시각·수면·활동.
  • 핵심 데이터가 하나라도 없으면 해당 지표는 계산하지 않고 "데이터 부족"으로 표시한다.
  • 핵심은 있고 보조 데이터만 없으면 계산하되, "정확도 낮음 · 참고용" 라벨을 함께 노출한다.
  • 지표 간 독립적으로 판단한다 — 한 지표가 빠져도 나머지는 정상 표시.

공통 원칙

  • 가짜 수치 금지 — 0점·"—점"처럼 측정값으로 오인될 자리표시를 쓰지 않는다.
  • 질문을 대안으로 제시 — 빈 상태 문구에서 "대신 오늘의 질문에 답하면 상태를 파악해 코칭해 드려요"로 연결한다.
  • 항상 1탭 복구 경로 — 모든 빈 상태에 연동/설정 CTA를 둔다.
  • 데이터 없을 때 질문 확장 — 결측을 보완하도록 그날 질문 세트를 더 넓게 구성할 수 있다(문항 수·주제 조정은 별도 정의).
  • 비의료 톤 유지 — 진단·위험 표현 없이 "상태를 계산할 수 없다 / 참고용"으로 서술한다.
빈 상태 카피 예시 — 오늘의 컨디션 지금은 연동된 생활 데이터가 없어 컨디션을 계산할 수 없어요. 건강 데이터를 연동하면 회복여유·생활부담·리듬안정성을 매일 확인할 수 있어요. 연동 전에는 오늘의 질문 답변으로 상태를 파악해 코칭해 드려요.
