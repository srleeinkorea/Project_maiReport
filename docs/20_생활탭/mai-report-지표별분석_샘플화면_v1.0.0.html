동일한 데이터(8월 4주 목요일 선택)를 세 가지 표현 방식으로 나란히 두었다. 값·문구는 예시다. 왼쪽이 권장안이며, 가운데는 주간 시각 요소를 완전히 없애기 부담스러울 때의 차선안, 오른쪽은 어색하다고 지적된 요일별 구간 칩 안(비교 기준)이다.

A. 시계열 제거 권장

카드 = 구간 배지 + 추세 한 줄 + 이번 주 해석 + 핵심 데이터. 주간 흐름은 해석 문장이 담당하고, 과거 날짜는 상단 스트립에서 눌러 본다.

비교 포인트. A는 카드 높이가 가장 낮고 시선이 배지 → 해석 → 데이터 순으로 한 번에 내려간다. '이번 주 해석'을 "주 전체 경향 + 최근 변화 + 이유"로 쓰면 C의 색 칸이 하려던 일을 문장이 더 정확히 한다. B는 A에 도트 한 줄만 더한 것이라 채점 프레이밍은 없지만, 상단 날짜 스트립과 역할이 겹친다. C는 헤더의 결론(▼ 낮아졌어요 / 보통이에요)을 색 7칸으로 다시 크게 반복하고, 일상안정은 지표 성격(여러 날의 방향)과 표현 단위(하루 판정)가 어긋난다. A의 일상안정 부제를 "최근 7일 기준"으로 바꾼 것도 같은 이유다.
