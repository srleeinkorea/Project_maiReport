1화면 개요

위치, 역할, 화면 구조

1.1 위치와 역할

병원 탭의 두 번째 서브탭(검진요약 · 진료요약 · 방문이력 · 읽을거리). 검진요약이 몸 상태를 다룬다면 진료요약은 병원을 어떻게 이용했는지를 다룬다. 값을 판정하거나 조언하지 않고 집계해 보여주는 화면이다.

출처가 검진요약과 다르다. 검진 결과는 국민건강보험공단에서, 진료 내역은 건강보험심사평가원에서 가져온다. 기관이 다르므로 인증과 갱신 시점도 따로 움직일 수 있다(§2 · §10).

1.3 집계 단위

모든 집계는 올해(1월 1일~오늘)가 기준이다. 검진요약과 달리 주차·검진 회차 개념이 없고, 해가 바뀌면 처음부터 다시 쌓인다. 지난해 수치는 진료비의 전년 비교에서만 쓴다.

1.4 이 화면의 성격

심평원에 청구·심사된 진료 내역을 근거로 한 집계다. 실제로 병원에서 결제한 금액과는 다를 수 있고, 심사가 끝나야 올라오므로 최근 달은 값이 비어 있거나 나중에 늘어난다. 이 두 가지를 화면에서 밝힌다(§7 · §8).

2.1 탭별 연동

검진은 국민건강보험공단, 진료는 건강보험심사평가원으로 기관이 달라 인증도 따로 한다. 하나의 버튼으로 두 기관을 묶지 않고, 각 탭에서 그 탭에 필요한 데이터를 가져온다.

탭기관데이터 가져오기 동작
검진요약국민건강보험공단공단 인증 → 건강검진 결과 수신
진료요약건강보험심사평가원심평원 인증 → 진료 내역 수신. 방문이력도 함께 채워진다
방문이력건강보험심사평가원진료요약과 같은 연동을 쓴다. 한쪽에서 가져오면 다른 쪽도 채워진다
읽을거리없음연동과 무관하므로 버튼을 노출하지 않는다

2.2 한쪽만 연동된 상태

검진만 가져오고 진료는 안 가져온 경우(또는 그 반대)가 흔하다. 탭마다 자기 연동 상태를 따로 보여준다.

상황화면
그 탭이 미연동가져오기 전 화면(§3). 다른 탭이 연동돼 있어도 이 탭은 미연동 화면을 보여준다
그 탭이 연동됨요약 화면. 상단 버튼은 최신 데이터로 갱신하는 경로가 된다
마지막 가져온 시점연동된 탭에는 언제 가져온 데이터인지 한 줄로 표시한다 — "2026년 9월 17일에 가져왔어요"
한 탭에서 가져왔다고 다른 탭이 채워지지 않는다. 사용자가 "이미 가져왔는데 왜 비어 있지"라고 느끼지 않도록, 미연동 탭의 가져오기 전 화면에 어느 기관에서 가져오는지를 문구로 밝힌다(§3.1).

대상 표현진료는 건별로 쌓이므로 "내역", 검진은 회차마다 판정이 나오므로 "결과". "정보"처럼 뭉뚱그린 말은 쓰지 않는다
기능 목록에 적은 "처방 이력 조회"는 이 화면에 없고 방문이력에서 확인한다. 가져온 뒤 사용자가 이 탭에서 찾지 못하는 일이 없도록, 방문이력으로 이어지는 경로를 화면에 두거나 목록 문구를 이 탭이 제공하는 것으로 좁힌다(§11).

7.2 막대 규칙

상황표시
금액 있음금액에 비례한 막대 + 위에 금액(4만 · 3만처럼 줄여서) + 아래 월(7월)
지출 없음막대를 그리지 않고 "0원". 지출이 없었다는 뜻이다
아직 오지 않은 달막대 자리를 비우고 "집계 전 · 0원". 0원과 구분한다
심사 지연심평원 심사가 끝나야 내역이 올라오므로 최근 달은 값이 나중에 늘어날 수 있다. 이 사실은 §8의 안내 문구로 갈음한다
분기 이동‹ 로 이전 분기, › 로 다음 분기. 오늘이 속한 분기에서는 › 를 비활성. 올해 1분기 이전으로는 가지 않는다

7.3 전년 비교

항목규칙
비교 대상지금 보고 있는 분기를 지난해 같은 분기와 비교한다. 진행 중인 분기는 오늘까지만 비교한다 — 올해 7월 1일~오늘과 지난해 7월 1일~같은 날짜를 맞대어 본다. 끝난 분기는 3개월 전체를 비교한다
이 방식을 쓰는 이유진행 중인 분기를 지난해 3개월 전체와 비교하면 아직 지나지 않은 기간까지 상대편에 들어가 항상 "덜 썼다"로 나온다. 같은 길이의 기간끼리 비교해야 증감이 뜻을 갖는다
기준일 표기진행 중인 분기에서는 비교 문구에 "지난해 같은 기간"이라고만 쓰고 날짜를 적지 않는다. 오늘까지라는 뜻이 "같은 기간"에 담긴다
문구더 썼으면 "지난해 같은 기간보다 n원 더 지출했어요", 덜 썼으면 "n원 덜 지출했어요", 같으면 "지난해 같은 기간과 비슷해요"
증감률"전년 대비 n% 증가 / 감소". 지난해 금액이 0원이면 비율을 쓰지 않고 금액만 말한다
지난해 기록 없음비교 블록 전체를 숨긴다
금액과 비율은 반드시 같은 기간에서 나와야 한다. 시안의 "27,000원 더 지출 · 63% 증가"는 두 값이 서로 맞지 않는다(63%가 맞으려면 지난해 금액이 약 43,000원이어야 하는데, 같은 화면의 분기 막대 합계와 어긋난다). 위 기준으로 다시 계산해 두 값을 맞춘다.

기준 밝히기진료비 카드 안내 문구에 본인부담금 기준임을 쓴다. 다른 금액을 섞어 쓰지 않으므로 항목마다 따로 표기하지는 않는다

10연동 규칙

트리거반영
"진료 데이터 가져오기" 탭심평원 인증 흐름 → 완료 시 수신 시작. 진료요약과 방문이력이 함께 채워진다
상단 "데이터 가져오기" 탭진료요약에서 누르면 심평원 인증으로 간다. 이미 연동돼 있으면 최신 내역으로 갱신한다
검진요약에서 가져오기 완료공단 데이터만 들어오므로 진료요약은 그대로 미연동이다. 이 탭에서 따로 가져와야 한다
방문이력에서 가져오기 완료같은 심평원 연동이므로 진료요약도 함께 채워진다

해가 바뀜대상 연도와 누적 금액이 새해 기준으로 초기화된다. 지난해 값은 전년 비교에서만 쓰인다
