1화면 개요

위치, 역할, 구조

1.1 위치와 역할

하단 내비게이션 병원 탭의 첫 번째 서브 탭. 서브 탭은 검진요약 · 진료요약 · 방문이력 · 읽을거리 네 개이며 진입 시 검진요약이 선택되어 있다. 사용자가 직접 입력하지 않고, 건강보험공단에서 받아온 검진 결과를 보여주는 읽기 중심 화면이다.

1.2 화면 구조

①가져오기 전안내 카드 · 얻을 수 있는 것 목록 · 가져오기 버튼
②가져오는 중진행 카드 · 뼈대 화면
③가져온 뒤건강 나이 · 위험도 분석 · 주요 소견 · 검진 안내
④이어지는 화면위험도 분석 · 전체 항목 · 항목 상세 · 검진 안내

세 상태는 같은 자리를 쓴다. 상단의 탭 줄과 데이터 가져오기 버튼은 어느 상태에서도 유지된다.

6.1 셀비 체크업

위험도 분석은 외부 서비스인 셀비 체크업이 담당한다. 검진 결과를 근거로 10대 질환의 발병 위험도, 위험 요인, 건강 나이를 분석해 리포트로 준다. 유료이며 결제 전에 어떤 검진 결과를 쓸지 고르고 생활 습관 몇 가지를 입력한다.

단계내용
소개무엇을 알 수 있는지 안내하고 분석 시작으로 넘긴다
검진 결과 선택가져온 검진 결과 중 분석에 쓸 회차를 고른다
생활 습관 입력운동 관련 항목을 직접 입력한다
결제이용 금액을 확인하고 결제한다
리포트건강 나이, 발병 통계지수, 질환별 위험도를 본다

이 화면의 상세 정의는 셀비 체크업 문서에서 다룬다. 검진요약에서는 진입까지만 책임진다.

10연동 규칙

공단 인증과 데이터 갱신
항목규칙
인증 진입§3의 실행 버튼과 §2의 데이터 가져오기 버튼 모두 같은 흐름으로 들어간다
인증 취소인증 도중 사용자가 그만두면 직전 상태로 돌아온다. 가져온 데이터가 있으면 그대로 유지한다

11예외

정상 흐름이 아닐 때
상황화면

12확인 필요

결정이 남아 있는 것
  • 건강 나이를 계산할 항목이 부족할 때 카드를 감출지, 다른 안내로 대체할지
  • 검진 대상이 아닌 해에 §8 카드를 다른 문구로 보여줄지, 감출지
  • 가져온 데이터를 얼마 동안 유지하고, 언제 다시 가져오도록 권할지
  • 주요 소견 다섯 항목을 항상 고정할지, 값이 없는 항목이 많을 때 대체 항목을 넣을지
  • 가져오는 중에 앱을 완전히 종료했다가 다시 들어왔을 때 이어서 진행할지, 처음부터 다시 받을지
