화면별 문서 현황

전체 앱 구성 흐름도(IA)의 화면 목록에 맞춰, 화면마다 기획서 · 화면정의서 · 화면설계서가 어디에 있는지 모은 표

작성일 2026-10-14버전 1.1기준 IA v1.0.0(2026-10-14 갱신) · docs 폴더 재편(90_기타 분할) 후
있음일부없음 · 기획서 = 왜 · 무엇을(기능 단위) · 화면정의서 = 화면 요소와 표시 규칙 · 화면설계서 = 상태와 화면 이동이 이어지는 상세 흐름

비어 있는 곳과 채우는 순서

세 문서를 화면마다 모두 만들 필요는 없다. 기획서는 기능 단위로, 화면설계서는 상태와 이동이 복잡한 화면에만 둔다.

  1. 홈 · 오늘의 질문 → 코칭 → 목표 — 홈 화면설계서(2026-10-14, v0.2)를 만들고 미결 7가지를 결정했다. 기획서는 아직 식이 · 코칭목표 엔진 문서에 흩어져 있다.
  2. 검진 리포트 등록(QR · 업로드 · 검수) — 프로토타입에만 있다. 기획서와 화면정의서가 모두 없다.
  3. 병원 탭의 방문이력 · 읽을거리 · 데이터 가져오기 — 프로토타입에만 있다. 화면정의서가 없다.
  4. 알림(헤더 · 알림 목록) — 알림 정책 문서는 있지만 화면정의서가 없다.
  5. 건강데이터 연동 — 화면정의서와 예시 화면은 있으나 권한 · 소스 선택 · 해제가 이어지는 설계서가 없다.

세 문서는 기획 문서 공통 구조에 맞춰 쓴다(머리말 → 한눈에 보기 → 본문 → 확인 필요 → 바뀐 것). 2026-10-14부터 예시 화면 · 흐름도 SVG는 모두 HTML로 바꿨다.

단순 화면(언어 · 약관 보기 · 로그아웃)은 더보기 화면정의서 한 장으로 충분하다. 셀비 체크업과 내정보 · 진료정보 연동은 화면설계서가 기획과 정의를 함께 담고 있어 따로 만들지 않는다.
