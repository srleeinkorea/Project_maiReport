최신 결정 · 반영 상태
  1. 현재 전달본과 다음 버전 구분 — 2026-10-19 연구소 전달 데이터 계약 v1.4.0은 식이 최대 2문항 기준입니다. 식사 시각 질문·diet_meal_time·식후 행동 판정은 다음 버전이며, 정본과 시연에는 관련 설계가 남아 있습니다.
  2. 문구 반복 방지 365일 — 최신 계약의 CFG-065·V-45에 반영했습니다. 연구소의 실제 서버 조회 기간과 데이터 버전 변경 후 사용 이력 유지 여부는 반영 확인 중입니다. 알림의 30일 조회와 식습관의 28일 관찰 기간은 별도 기준입니다.
  3. 질문·코칭·목표 — 질문 완료 후 코칭과 잠긴 목표를 만듭니다. 이미 열린 목표는 유지하고, 답을 수정할 때는 답변으로 만든 미완료 목표만 다시 만듭니다. 홈에는 행동 한 줄, 이유는 목표 분석에 표시합니다.
  4. AI 인사이트 — 자동 생성이 아니라 사용자가 실행합니다. 연동·기록 일수·최근 4주·재분석 가능 여부를 확인하며, 오늘의 질문 완료 여부와는 무관합니다.
  5. 진료정보 화면의 확정 기획 — 진단명이 없으면 병원·날짜·진료비·처방 중 받은 정보만 표시합니다. 진료 이용현황은 진료요약 오른쪽 위 「이용현황 ›」에서 진입하도록 결정됐습니다. 시연의 버튼 반영 여부는 별도 대조가 필요합니다.
  6. 연동 관리 — 갱신·해제는 더보기에서 처리합니다. 즉시 삭제와 회원탈퇴의 법정 보관 안내 정합성은 기존 확인 항목으로 남깁니다.
