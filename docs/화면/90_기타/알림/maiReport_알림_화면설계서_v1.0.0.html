06

시나리오

45세, 워치 착용. 수요일.

  1. 아침에 질문 4개에 답해 목표 3개가 열렸음. 낮에 활동 목표 하나를 완료했음.
  2. 19시, 잠금 화면에 「자기 전까지 오늘의 목표 2개를 실천할 수 있어요.」 푸시가 옴. 누르면 홈 「오늘의 목표」 위치로 들어옴. 헤더 종에 점이 보임.
  3. 종을 누르면 알림 목록이 열리고 점이 사라짐. 어제 점검 공지를 누르면 행이 펼쳐져 자세한 안내가 보임. 뒤로 가면 홈.
  4. 다음 날 질문에 답하지 않아 목표가 잠겼음. 19시 푸시는 오지 않고 목록에도 아무것도 쌓이지 않음.
