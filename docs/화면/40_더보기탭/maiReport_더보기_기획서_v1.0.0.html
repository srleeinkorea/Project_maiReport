한눈에 보기

이 문서가 다루는 것더보기 탭에 모인 계정 · 연동 · 서비스 설정 · 법적 문서의 역할과 규칙. 건강 데이터를 해석하지 않고 「확인하고 · 바꾸고 · 나간다」만 하는 영역
가장 중요한 결정연동 관리(건강 앱 · 검진 · 진료)는 더보기에서만 함. 다른 탭에는 이리로 오는 링크만 둠. 동의는 가입 때와 검진 · 진료 연동 때 두 번만 받고, 갱신 · 재조회에는 다시 받지 않음
아직 정해지지 않은 것10-14에 2건을 결정해 닫았음. 남은 것: ② 탈퇴 후 보관 기간과, 검진 · 진료 연동 해제 시 즉시 삭제가 「법… / ③ 개인정보 제3자 제공 동의의 노출 시점(제공받는 자 확정 후). 자세한 내용은 「확인 필요」.
01

배경과 목표

서비스는 카카오 계정, 건강 앱, 공단 · 심평원, 외부 AI 네 곳과 연결됨. 사용자가 「지금 무엇이 연결돼 있고, 무엇에 동의했고, 어떻게 끊는지」를 한 곳에서 알 수 없으면 신뢰가 생기지 않음. 더보기는 그 한 곳임.

목표는 두 가지임. 연동 · 동의 · 알림 · 이용권 상태를 읽기 쉽게 보여주고, 바꾸는 동작은 확인을 거쳐 되돌릴 수 있게 함. 하루에 여러 번 오는 화면이 아니므로 짧고 분명해야 함.

04

동작 방식

화면 구성 순서 · 아래 순서는 기획 기준안임. 디자인 · UX 흐름상 정보 우선순위나 스크롤 흐름이 어색하면 디자인 검토 후 영역 순서는 조정할 수 있음. 단, 각 영역 안의 기능 · 표시 규칙은 그대로 둠.

  1. 목록: 위에서 아래로 「나 → 내 데이터 연동 → 앱 사용 설정 → 법적 문서」. 항목은 한 줄에 하나, 누르면 그 항목만 다루는 화면으로 감. 연동 항목 오른쪽에는 상태값을 붙이지 않음(상태는 각 연동 화면에서).
  2. 내정보: 카카오에서 받은 이름 · 생년월일 · 연락처 · 이메일을 조회만 함. 「관리 중인 질환」은 고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환 중 복수 선택해 저장하고 목표 추천 · 주의 문구에만 씀. 회원탈퇴는 내정보 안에서만 들어감.
  3. 건강데이터 연동: 앱 하나를 고르고 휴대폰 권한을 허용하면 연동. 해제하면 새 데이터만 멈추고 받아 둔 값은 남음. 흐름은 건강데이터 연동 화면설계서.
  4. 건강검진 · 진료정보 연동: 검진(공단)과 진료(심평원)를 각각 가져오고 해제함. 처음에만 개인정보 동의와 민감정보 동의 2개를 받고, 갱신 · 재조회에는 받지 않음. 주민번호는 입력칸 아래 안내만 두고 서버에 보관하지 않음. 해제는 확인 시트를 거치며 즉시 삭제됨.
  5. 동의 관리: 필수 3개(이용약관 · 개인정보 수집 이용 · 민감정보 처리)는 동의일만, 선택 3개(건강정보 활용 · 마케팅 정보 수신 · 서비스 품질 향상)는 켜고 끔. 항목명을 누르면 2026-10-13 법무 검토 최종본 전문이 열림.
  6. 알림 관리: 공지사항은 끌 수 없고, 오늘의 목표 알림(매일 저녁)만 켜고 끔. 광고성 알림은 동의 관리의 마케팅 수신에서 바꿈.
  7. 이용권 관리: 프로모션 기간에는 「Selvy Checkup · 프로모션 기간 · 무상 제공 중」 카드 하나만. 내역은 보이지 않음.
  8. 언어: 고르면 즉시 적용. 지원 언어가 하나여도 항목을 숨기지 않음.
  9. 로그아웃 · 회원탈퇴: 둘 다 확인을 거침. 탈퇴는 「모든 개인정보가 삭제되며 복구할 수 없어요」를 보여주고 누르면 바로 처리함.
05

규칙과 예외

규칙예시예외
연동 관리는 더보기에서만병원 탭 검진요약에는 연동 갱신 링크가 없음. 홈의 「건강 데이터 연결하기」는 더보기 연동 화면으로 보냄병원 탭 빈 화면의 「가져오기」 버튼은 최초 연동만 시작함
동의는 두 번만가입 때 개인정보 · 선택 동의, 검진 · 진료 연동 때 민감정보 동의(이미 했으면 생략)ChatGPT 요약은 동의가 아니라 확인 팝업 1번
필수 동의는 여기서 끄지 못함동의 관리의 필수 항목에는 스위치가 없고 동의일만철회는 탈퇴로 안내
항목 오른쪽 값은 읽기용, 탭 영역은 줄 전체언어 「한국어」 글자를 눌러도 줄 전체를 누른 것과 같음—
계정을 벗어나는 동작은 목록 카드 밖에로그아웃은 목록 아래 텍스트, 탈퇴는 내정보 안—
해제는 확인 시트를 거침건강데이터 · 검진 · 진료 모두 「해제할까요?」 시트로그아웃도 확인. 언어 변경은 확인 없음
건강 데이터 값 · 해석 · 코칭을 두지 않음더보기 어디에도 걸음 수나 지표가 없음—

기능 정의

기능정의서 §3 「진입 · 권한 · 연동」 일부와 §11 「더보기 · 계정」을 이 기획서로 옮긴 표.

기능언제하는 일 · 결과어긋나면
더보기 목록 구성더보기 탭 진입프로필 카드 아래 연동 · 서비스 · 법적 정보 세 묶음과 로그아웃 · 앱 버전을 둠. 언어만 현재 값을 보여줌연동 상태는 목록에 표시하지 않음
내정보 조회프로필 카드 선택카카오 계정의 이름 · 생년월일 · 연락처 · 이메일을 조회 전용으로 보여줌앱에서 값을 바꾸지 않음
관리 중인 질환 입력내정보 › 관리 중인 질환고혈압 · 당뇨병 · 이상지질혈증 · 만성 신장질환 중 고르고 저장. 목표 추천 · 주의 문구에만 씀하나도 고르지 않으면 저장 버튼을 켜지 않음. 입력하지 않으면 「없음」
연동할 앱 선택건강데이터 연동 시작 · 해제 후 재연동안드로이드에서 삼성헬스 · 헬스 커넥트 중 하나. 아이폰은 건너뜀설치되지 않은 앱은 설치 안내
연동 상태 판정권한 응답 · 앱 실행허용된 항목이 하나라도 있으면 연동. 앱 이름과 마지막 동기화 시각을 남김모두 꺼지면 미연동으로 되돌리고 관련 화면을 연동 전 상태로
건강데이터 연동 해제[연동 해제] 후 확인새 데이터를 더 가져오지 않음. 받아 둔 값 · 리포트 · 기록은 남김확인 없이 해제되지 않음
검진 · 진료 연동 관리건강검진 · 진료정보 선택각각 마지막 업데이트 · 가져온 기간 · 개별 업데이트 · 해제. 업데이트에 재동의 없음해제는 확인 시트 뒤 즉시 삭제
동의 관리동의 관리 선택필수는 동의일만, 선택은 켜고 끔. 바꾼 시점을 남김. 항목명으로 전문을 엶필수는 여기서 끄지 못함. 철회는 탈퇴로 안내
알림 수신 설정알림 관리 선택공지사항은 끌 수 없고, 오늘의 목표 알림만 켜고 끔휴대폰 알림 권한이 꺼져 있으면 알림이 가지 않는다고 알림
이용권 현황이용권 관리 선택「주요질환 위험도 분석 이용권」 카드 1개. 프로모션 기간 · 무상제공중내역은 표시하지 않음
언어 설정언어 선택표시 언어를 바꾸고 즉시 적용번역이 없는 화면은 기본 언어
약관 · 정책 조회법적 정보 항목 선택이용약관 · 개인정보 처리방침을 각각 전문으로. 2026-10-13 최종본(시행 2026-11-01)불러오지 못하면 다시 시도. 동의서는 여기 두지 않음
로그아웃로그아웃 후 확인이용 상태를 끊음. 다시 로그인하면 기록을 그대로 볼 수 있음을 알림확인 없이 처리하지 않음
회원탈퇴내정보에서 선택「모든 개인정보가 삭제되며 복구할 수 없어요」 뒤 탈퇴하기를 누르면 바로 처리목록에서 바로 진입하는 경로를 두지 않음

07

성공 기준

  • 연동 상태와 동의 상태를 더보기 안에서 두 번 이내의 탭으로 확인할 수 있음.
  • 해제 · 로그아웃 · 탈퇴 어느 것도 확인 없이 일어나지 않음.
  • 검진 · 진료 갱신 때 동의 화면이 다시 뜨지 않음.
  • 더보기 어디에도 건강 수치 · 해석이 노출되지 않음.
