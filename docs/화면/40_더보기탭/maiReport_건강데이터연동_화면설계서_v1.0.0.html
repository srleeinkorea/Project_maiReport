분기와 예외

상황화면다음
권한을 모두 거부0단계로 돌아오고 「권한을 허용해야 연동할 수 있어요」 + 「다시 연동하기」다시 누르면 ②(OS가 다시 묻지 않으면 「설정 열기」)
OS 설정에서 권한을 막아 둠안내 문구를 「설정에서 허용」으로 바꾸고 「설정 열기」설정 앱 → 돌아오면 0단계에서 다시 판정
일부 항목만 허용④ 상태 바 아래 「가져오지 않는 항목이 있어요 · 수면」(3개 넘으면 「수면 외 2개」). 값이 비는 자리에는 「수면 권한이 꺼져 있어요 · 권한 켜기 ›」권한 설정 → 다음 동기화에서 안내가 사라짐
아이폰에서 어떤 항목이 7일간 한 건도 안 들어옴「수면 데이터를 가져오지 못하고 있어요 · 건강 앱에서 접근을 허용해 주세요」. 권한 꺼짐과 데이터 없음을 구분할 수 없어 단정하지 않음—
권한은 있으나 데이터가 아직 없음(신규 · 미착용)④는 연동됨. 홈 · 생활은 「데이터를 모으는 중」 안내, 버튼 없음하루 이상 쌓이면 자동 표시
앱이 설치되지 않음①에서 고르면 설치 안내설치 후 ①로
동기화 실패(네트워크 · 앱 오류)상태 바는 마지막 성공 시각 유지, 기록에 「실패 · 사유」. 화면을 오류로 덮지 않음연동 유지, 다음 동기화에서 재시도
휴대폰에서 권한 철회다음 동기화가 실패로 남고 「다시 허용해 주세요」 안내연동 상태 유지
동기화 중 화면 이탈계속 진행. 돌아오면 그 시점 상태—
앱 바꾸기④에서 바로 바꾸는 길 없음. ⑤ → 해제 → ①바꾼 날 00시부터 새 앱 값. 이전 날짜 값은 그대로

데이터와 연동

단계주고받는 것외부 호출
② 권한요청 항목 12개(걸음 수 · 활동 칼로리 · 활동 시간 · 운동 기록 · 심박수 · 수면 · 체중 · 체지방률 · 체질량지수 · 키 · 혈압 · 혈당)의 읽기 권한. 쓰기 권한은 요청하지 않음HealthKit / Health Connect / 삼성헬스 권한 요청 1회
③ 첫 동기화허용된 항목의 과거 데이터(앱이 주는 범위, 또는 최근 30일)건강 플랫폼 읽기
④ 자동 · 직접 동기화마지막 동기화 이후 새 값. 단위 표준화 · 출처 우선순위 적용 후 저장앱을 켤 때 1회, 직접 탭 시 1회
⑤ 해제연동 상태 「미연동」, 권한 요청 철회(플랫폼이 허용하면). 저장된 값 · 기록은 유지—

한 날짜의 데이터는 한 앱에서만 옴. 활동 시간은 걸음 기록에서 직접 산출하고 운동 시간은 운동 세션만 합산함. 비어 있던 날짜가 나중에 채워져도 그날의 지표와 리포트는 다시 계산하지 않음.

06

시나리오

47세 갤럭시 사용자가 홈의 「건강 데이터 연결하기」를 눌렀음.

  1. 더보기 › 건강데이터 연동 화면이 미연동 상태로 열림. 「연동하기」를 누름.
  2. 소스 선택에서 삼성헬스를 고르고 「다음」. 휴대폰이 권한 화면을 띄움. 수면만 빼고 허용함.
  3. 상태 바가 「삼성헬스 동기화 중…」으로 바뀌고, 20초 뒤 「연동됨 · 방금 전」이 됨. 그 아래 「가져오지 않는 항목이 있어요 · 수면」이 보임.
  4. 홈으로 돌아가면 컨디션 게이지와 건강 데이터 카드가 바로 그려지고, 수면 줄에는 「수면 권한이 꺼져 있어요 · 권한 켜기 ›」가 보임.
  5. 권한을 켜고 다음 날 앱을 열자 자동 동기화에서 수면이 들어오고 안내가 사라짐. 연동 기록에 「완료 · 자동 · 걸음 · 심박 · 수면」이 쌓임.
  6. 워치를 바꿔 헬스 커넥트로 옮기려 「연동 해제」 → 확인 시트 → 해제. 미연동 화면에 「연동 해제 전 기록이에요」 라벨이 붙은 기록이 남음. 「다시 연동하기」로 헬스 커넥트를 고르면 그날 00시부터 새 앱 값이 쌓임.

확인 필요

질문누가 정하나기한상태
① 앱에서 해제할 때 휴대폰 읽기 권한까지 실제로 거둬지는지(HealthKit · Health Connect)개발—닫힘(10-14) · 앱 해제는 앱의 연동만 끊음. OS 권한은 앱이 거둘 수 없으므로 해제 완료 화면에 「휴대폰 설정에서 권한도 거둘 수 있어요」 한 줄을 둠. 플랫폼별 실제 동작은 개발 메모로 남김
② 권한 모두 거부 뒤 OS가 다시 묻지 않을 때의 「설정 열기」 딥링크 가능 여부개발—닫힘(10-14) · 가능한 플랫폼은 「설정 열기」로 앱 설정 화면 딥링크, 불가하면 경로 안내 문구(설정 › 앱 › 마이리포트 › 권한)로 대체
③ 첫 동기화의 과거 데이터 범위(앱이 주는 만큼 vs 최근 30일) 확정기획 · 개발—닫힘(10-14) · 첫 동기화는 최근 30일. 그 이전은 가져오지 않음
