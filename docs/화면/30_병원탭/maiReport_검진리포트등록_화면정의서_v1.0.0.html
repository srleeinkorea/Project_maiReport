한눈에 보기

이 문서가 다루는 것등록 흐름의 화면 7개(액션 시트 · 카메라 · 인식 결과 확인 · 업로드 · 추출 중 · 추출 데이터 확인 · 완료)와 원본 미리보기에 무엇이 보이고 어떤 규칙으로 표시되는지.
가장 중요한 결정두 길 모두 사용자가 확인 화면(인식 결과 확인 · 추출 데이터 확인)에서 「저장하기」 「최종 등록」을 눌러야 저장됨. QR을 읽는 동안은 새 화면을 열지 않고 카메라 위에 카드로 진행을 보여 줌.
아직 정해지지 않은 것10-14에 4건을 결정해 닫았음. 남은 것 없음. 자세한 내용은 「확인 필요」.

영역별 정의

③ 닫기시트 아래 둥근 ✕. 배경을 눌러도 닫힘—

REG-002 카메라

요소표시 규칙데이터 출처
① 제목 · 닫기QR이면 「AI REPORT QR 스캔」, 촬영이면 「검진 리포트 촬영」. 오른쪽 ✕진입 모드
② 안내 사각형QR은 정사각형 테두리, 촬영은 세로 결과지 비율 테두리에 스캔 선진입 모드
③ 안내 문장QR 「리포트에 인쇄된 QR 코드를 사각형 안에 맞춰 주세요.」 촬영 「검진 결과지를 사각형 안에 맞춰 주세요. 표가 잘리지 않게 찍어 주세요.」진입 모드
④ 수신 카드QR이 읽히면 카메라 위에 카드 「리포트를 불러오고 있어요 / QR에 담긴 분석 결과를 확인하는 중이에요」. 리포트를 받고 대상자 확인을 통과하면 인식 결과 확인(REG-003)으로 넘어감. 대상자가 다르면 카드에 「본인 리포트가 아니에요」와 「다시 스캔」QR 내용 · 대상자 확인 결과
⑤ 하단 조작앨범 🖼 · 셔터 · 「완료」. QR 모드에서는 셔터 없이 자동 인식, 「완료」 숨김. 촬영 모드에서는 찍은 장 수 「n장 촬영됨」과 「완료 (n장)」촬영 장 수

REG-003 인식 결과 확인(AI REPORT)

요소표시 규칙데이터 출처
헤더「‹ 인식 결과 확인」—
수신 요약썸네일 · 「AI REPORT · n개 항목 인식」 · 출처 태그 「QR 수신」 또는 「📷 촬영 인식」QR 내용 · 촬영 결과
인식된 항목검진일 · 검진기관 · 검사 종류 · 판독 결과(소견 · AI 점수). 항목을 누르면 고칠 수 있음. 확신이 낮은 값은 강조인식 결과
하단 버튼「다시 촬영」 · 「저장하기」. 저장 뒤 같은 자리에 「AI REPORT 분석이 완료됐어요 / 방문이력에 AI 분석 결과가 추가됐어요.」 1초 뒤 홈을 깔고 그 위에 AI REPORT 결과 화면. 오늘의 질문 · 코칭 · 목표는 처음 상태로—

REG-004 검진정보 리포트 등록(업로드)

요소표시 규칙데이터 출처
① 헤더✕ · 「검진정보 리포트 등록」—
② 소개「내 검진정보 리포트를 등록해 보세요.」 「AI가 자동으로 데이터를 추출하여 등록해 드릴게요.」—
③ 업로드 방법「아래 방법 중 하나로 검진 리포트를 업로드해 주세요. 여러 장일 경우 순서대로 업로드해 주세요.」 + 버튼 3개(📷 카메라 · ▣ 앨범 · PDF). 카메라는 1장씩, 앨범 · PDF는 여러 개 선택—
④ 업로드 파일 목록제목 「업로드 파일」 + 「n개」. 없으면 「아직 업로드된 파일이 없습니다. / 사진 또는 PDF 파일을 선택해 주세요.」 있으면 행마다 썸네일(PDF는 「PDF」 글자) · 파일명 · 「n페이지 · 출처」 또는 「PDF 문서 · PDF」 · 삭제 ✕. 최대 10개선택한 파일
⑤ 다음파일이 1개 이상일 때만 활성파일 수

REG-005 데이터 추출 중

요소표시 규칙데이터 출처
헤더✕ · 「데이터 추출중」. ✕는 추출을 멈추고 업로드 화면으로(파일 유지)—
진행 카드「진행률 n%」 + 막대. 단계 3줄: 「파일 업로드 완료」 「문서 인식 및 추출」 「검진 결과 정리」. 끝난 단계는 ✓, 남은 단계는 ·추출 진행

REG-006 추출 데이터 확인

요소표시 규칙데이터 출처
① 헤더✕ · 「추출 데이터 확인」. ✕는 등록하지 않고 닫음(값은 버림, 파일은 남김)—
② 안내「최종 등록 전에 추출된 데이터를 확인 후 잘못된 값을 수정해 주세요.」—
③ 원본 파일「▤ 원본 파일 · n개 ›」. 누르면 원본 미리보기업로드 파일
④ 항목 묶음「기본 정보」(검진일 · 검진기관) → 「계측 검사」 → 「혈액 및 기타 검사」. 행 = 항목명 · 값 입력칸 · 단위. 읽히지 않은 항목은 빈 칸으로 둠추출값
⑤ 확신 낮은 값값 칸 강조 + 「확인해 주세요」. 사용자가 고치면 사라짐확신도
⑥ 다시 업로드업로드 화면으로, 파일 유지—
⑦ 최종 등록검진일이 비어 있으면 비활성. 누르면 저장 후 완료 화면검수값

원본 리포트 미리보기 · 등록 완료

요소표시 규칙데이터 출처
미리보기✕ · 「n/전체」 · 좌우 탭으로 장 이동. PDF는 쪽 단위업로드 파일
완료✓ · 「검진정보 리포트 등록 완료」 · 「검진정보에 저장되었어요. 병원 탭 검진정보에서 결과를 확인해 보세요.」 · 「등록 결과 보기」(검진 상세, 거기서 AI 요약으로) · 「다음에 볼게요」(방문이력)등록 결과

상태별 표시

화면상태무엇이 보이나예시
REG-002 카메라권한 없음카메라 대신 「카메라 권한이 필요해요」 + 「설정 열기」. 앨범도 같은 방식—
QR 읽는 중사각형과 안내 문장 유지. 읽히지 않으면 그대로(오류 문구 없음)—
수신 중 → 확인 화면카메라 위 카드가 회전 표시 → ✓ 「리포트를 받았어요」. 바로 인식 결과 확인(REG-003)—
대상자 불일치카드에 「본인 리포트가 아니에요」와 「다시 스캔」. 저장하지 않음. 이름 표기만 다른 경우는 확인 필요—
REG-004 업로드파일 없음빈 목록 안내, 「다음」 비활성「아직 업로드된 파일이 없습니다.」
파일 있음목록 · 「n개」 · 「다음」 활성「2개」
받을 수 없는 파일목록에 넣지 않고 이유를 토스트로「PDF와 사진만 올릴 수 있어요」 「파일이 너무 커요(최대 30MB)」
REG-005 추출 중진행18% → 66% → 100%, 단계 ✓—
실패「리포트를 읽지 못했어요. 다시 올려 주세요.」 + 「다시 업로드」. 파일 유지—
REG-006 확인정상세 묶음의 값. 「최종 등록」 활성—
읽힌 항목 없음「읽을 수 있는 항목이 없어요」 + 「다시 업로드」만—
검진일 없음검진일 칸 강조, 「최종 등록」 비활성—
등록 뒤검진요약 · 방문이력방문이력에 「일반검진 · 📷 등록」 카드, 검진요약은 판정 없이 「검진 항목을 정리했어요」와 「판정 정보 확인」 배지—
05

동작

사용자가 하면화면은
방문이력 「+」를 누르면액션 시트가 올라옴. 바깥을 누르거나 ✕로 닫음
홈 헤더 QR 버튼을 누르면유형 선택 없이 QR 카메라
QR이 사각형 안에 들어오면자동 인식. 카메라 위에 수신 카드 → 인식 결과 확인 화면. 「저장하기」를 누르면 홈 + AI REPORT 결과 화면. 오늘의 질문 · 코칭 · 목표가 처음 상태로 돌아감
촬영 모드에서 셔터를 누르면장 수가 늘고 하단에 썸네일 최근 3장과 「n장 촬영됨」. 「완료 (n장)」가 켜짐
업로드에서 카메라 · 앨범 · PDF를 누르면기기 카메라 · 사진 선택 · 파일 선택이 열리고, 고른 파일이 목록 끝에 붙음
목록의 ✕를 누르면그 파일만 빠짐. 0개가 되면 「다음」 비활성
「다음」을 누르면추출 중 화면. 끝나면 자동으로 확인 화면
확인 화면에서 값을 고치면즉시 반영. 확신 낮음 표시가 사라짐
「원본 파일 n개 ›」를 누르면미리보기. ✕로 돌아오면 고치던 값이 그대로
「다시 업로드」를 누르면업로드 화면, 파일 유지. 추출값은 버림
「최종 등록」을 누르면저장 후 완료 화면. 「등록 결과 보기」 → 검진 상세, 「다음에 볼게요」 → 방문이력
