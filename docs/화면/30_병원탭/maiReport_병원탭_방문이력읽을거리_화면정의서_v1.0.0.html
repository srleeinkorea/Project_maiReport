03

영역별 정의

① 데이터 가져오기(빈 화면)

요소표시 규칙데이터 출처
제목 · 설명검진: 「건강검진 정보를 가져와 주세요 / 건강보험공단의 검진 정보를 확인할 수 있어요.」 진료: 「진료 정보를 가져와 주세요 / 건강보험심사평가원의 진료 정보를 확인할 수 있어요.」—
볼 수 있는 것 목록검진 4개(최근 건강검진 결과 조회 · 주요 질환 위험도 예측 · 건강나이 측정 · 건강검진 결과 AI 요약 분석), 진료 3개(병원 방문 내역 조회 · 처방 이력 조회 · 진료비 지출 통계)—
가져오기 버튼「건강검진 데이터 가져오기」 / 「진료 데이터 가져오기」. 누르면 동의 2개(이미 동의했으면 생략) → 본인 확인 → ②—
보조 안내검진 빈 화면 하단: 「간편인증으로 1분이면 완료돼요. 진료정보는 따로 가져올 수 있어요.」—

② 가져오는 중

요소표시 규칙데이터 출처
스피너 · 제목「검진 데이터를 가져오는 중」 / 「진료 데이터를 가져오는 중」—
안내「{기관}에서 데이터를 불러오는 중입니다. 최대 1분 정도 소요될 수 있습니다.」 기관은 국민건강보험공단 / 건강보험심사평가원—
스켈레톤요약 화면 모양의 자리 표시 5줄. 다른 탭으로 가도 진행은 계속되고, 방문이력 카드의 버튼은 「가져오는 중…」으로 바뀜—

③ 방문이력

요소표시 규칙데이터 출처
연동 안내 카드아직 연동하지 않은 정보만 줄로. 제목 「연동하면 더 볼 수 있어요」, 설명 「검진정보와 진료정보는 제공 기관이 달라 각각 인증해야 해요.」 줄: 🩺 검진정보 「건강검진 결과가 이 목록에 함께 표시돼요」 / 📋 진료정보 「병원 방문 · 처방 기록이 함께 표시돼요」, 각 줄에 「데이터 연동하기」. 둘 다 연동되면 카드가 사라짐연동 상태
필터칩전체 · 검진 · 진료 · AI REPORT. 하나만 선택. 기본 「전체」. 해당 종류 기록이 0건이면 칩을 숨기지 않고 빈 목록 안내—
연도 구분최신 연도부터. 연도 머리글 아래 날짜 내림차순검진 · 진료 · 등록 건의 날짜
검진 카드아이콘 · 검진 종류(일반검진 · 암검진 등) · 「✦ AI 요약」 표시(요약이 있을 때) · 기관명 · ›검진 건
진료 카드병원명 · 진료과 · 처방 건수 · ›진료 건
AI REPORT 카드「AI」 표시 · 제목(예: 흉부 X-ray AI 분석) · 요약(예: 오른쪽 폐 경화 소견 · AI 점수 19) · 상태(확인 필요 / 특이 소견 없음) · ›등록 건
「+」 버튼화면 오른쪽 아래 고정. 누르면 등록 유형 선택 시트—

④ 읽을거리

요소표시 규칙데이터 출처
제목기록이 있으면 「내 소견과 관련된 읽을거리」, 없으면 「건강 읽을거리」연동 · 등록 상태
카드 4개분류(예: 폐 질환 · 안저 질환) · 제목 · 그림. 내 질환 · 소견과 연결된 글을 앞에 둠. 카드마다 다른 바탕콘텐츠 목록 + 매칭 규칙

⑤ 읽을거리 상세

요소표시 규칙데이터 출처
머리말그림 · 제목 · 첫 문단(요약)콘텐츠
본문원인 · 진단 · 치료 · 예방 순서의 소제목. 소제목은 빠질 수 있지만 순서는 바꾸지 않음콘텐츠
출처맨 아래. 출처 없는 글은 싣지 않음콘텐츠

⑥ AI REPORT 결과

요소표시 규칙데이터 출처
리포트 카드제목 · 날짜 · 검사 종류 · 판독 엔진 · 「PDF」(원본 열기)등록 건
소견 목록원본 리포트의 소견 체계 그대로(경화 · 결절 · 기흉 · 흉막 삼출 · 무기폐 · 심장비대 · 종격동 비대 …). 각 줄: 소견 이름 · 설명 한 줄 · 판정(확인 필요 / 특이 소견 없음)등록 건
고지「AI REPORT는 흉부 X-ray 영상을 분석한 참고 결과이며, 의학적 진단이나 의료진의 판독을 대신하지 않습니다.」 항상 표시—
04

상태별 표시

상태무엇이 보이나예시
둘 다 미연동 · 등록 없음검진요약 · 진료요약은 ①. 방문이력은 연동 안내 카드 2줄 + 「아직 기록이 없어요. 연동하거나 리포트를 등록해 보세요」첫 진입
검진만 연동검진요약 정상, 진료요약 ①(진료), 방문이력 카드에 진료 줄만—
가져오는 중해당 요약 탭 ②, 방문이력 카드 버튼 「가져오는 중…」최대 1분
가져오기 실패①로 돌아가고 상단에 사유 + 「다시 시도」. 부분 성공이면 받은 만큼 보여주고 「일부만 가져왔어요」「인증에 실패했어요」 / 「기관 응답이 없어요」
필터 결과 0건「{종류} 기록이 없어요」 한 줄. AI REPORT는 「+로 리포트를 등록해 보세요」 덧붙임—
진단명 없는 진료 건카드에 병원 · 날짜만, 상세는 요약만확인 필요 ②
읽을거리 연결 기록 없음일반 건강 글 4개, 제목 「건강 읽을거리」—
AI REPORT 원본 PDF 없음⑥을 열지 않고 카드에 「원본을 불러올 수 없어요」결과만 단독 노출하지 않음

동작

사용자가 하면화면은
① 가져오기 버튼을 누르면동의 시트(2개, 이미 동의했으면 생략) → 본인 확인 → ②. 인증 화면은 기관이 그림
② 진행 중 다른 탭으로 가면진행은 계속. 돌아오면 그 시점 상태, 끝났으면 요약
③ 필터칩을 누르면목록이 즉시 걸러지고 연도 머리글은 남은 기록 기준으로 다시 묶임
③ 카드를 누르면검진 → 검진상세, 진료 → 진료상세, AI REPORT → ⑥
③ 「+」를 누르면등록 유형 선택 시트(AI REPORT / 일반 검진 결과지 등록)
③ 안내 카드의 「데이터 연동하기」를 누르면그 줄의 기관 인증으로. 버튼이 「가져오는 중…」으로 바뀜
④ 카드를 누르면⑤로. 뒤로 오면 스크롤 위치 유지
⑥ 「PDF」를 누르면원본 리포트 뷰어. 확대 · 축소
⑥에서 뒤로③에서 왔으면 ③, 등록 직후면 홈

확인 필요

질문누가 정하나기한상태
