한눈에 보기

이 문서가 다루는 것병원 탭 첫 화면인 검진요약의 세 상태(가져오기 전 · 가져오는 중 · 가져온 뒤)와, 검진요약에서 이어지는 화면 네 개(검진대상조회 · 셀비 체크업 소개 · 항목 상세 · 검진상세).
가장 중요한 결정검진 대상 정보는 검진 결과와 같은 간편인증 한 번으로 함께 가져옴. 검진대상조회는 공단 값을 받은 글자 그대로 보여줌. 대상이 아니어도 카드를 감추지 않고 문구만 바꿈. 다시 가져오기는 더보기에서만.
아직 정해지지 않은 것6건(§07). 건강 나이 계산 불가 시 처리, 데이터 유지 기간, 주요 소견 고정 여부, 앱 종료 후 이어받기, 검진대상 API 계약 포함 여부, 공단 값 전체 목록.

06

시나리오

A. 40세 김마이님, 처음 병원 탭에 들어옴 (대상)

  1. 검진요약에 「건강검진 정보를 가져와 주세요」가 보임. 「건강검진 데이터 가져오기」를 누르고 카카오톡 인증을 한 번 함.
  2. 「검진 데이터를 가져오는 중」 카드가 30초쯤 보인 뒤 검진요약으로 바뀜. 건강 나이 45세(실제 40세보다 +5), 혈압 · 콜레스테롤 「경계」.
  3. 맨 아래 「김마이님은 2025년도 건강검진 대상자입니다.」 카드에서 「검진 안내 확인하기」를 누름. 다시 인증하지 않고 바로 검진대상조회가 열림.
  4. 일반검진 「본인부담 없음」, 위암 · 유방암 「10%부담」, 자궁경부암 「본인부담 없음」, 대장암 「대상아님」을 봄.

B. 올해 대상이 아닌 사람

  1. 검진 결과는 정상으로 들어오고, 공단 검진 대상 결과가 비어 옴.
  2. 맨 아래 카드가 「…2025년도 건강검진 대상이 아닙니다.」로 바뀜. 버튼을 누르면 「올해는 건강검진 대상이 아닙니다」 안내만 보임.

C. 검진 대상만 못 받아옴

  1. 검진 결과는 들어왔으나 검진 대상 조회가 실패함.
  2. 건강 나이 · 소견 카드는 그대로 보이고, 맨 아래 카드만 「올해 검진 대상 정보를 불러오지 못했습니다.」. 더보기 > 검진 · 진료정보 연동에서 다시 가져오면 채워짐.
