1화면 개요

위치, 역할, 구조

1.1 위치와 역할

하단 내비게이션 병원 탭의 첫 번째 서브 탭. 서브 탭은 검진요약 · 진료요약 · 방문이력 · 읽을거리 네 개이며 진입 시 검진요약이 선택되어 있음. 사용자가 직접 입력하지 않고, 건강보험공단에서 받아온 검진 결과를 보여주는 읽기 중심 화면임.

1.2 화면 구조

①가져오기 전안내 카드 · 얻을 수 있는 것 목록 · 가져오기 버튼
②가져오는 중진행 카드 · 뼈대 화면
③가져온 뒤건강 나이 · 위험도 분석 · 주요 소견 · 검진 안내
④이어지는 화면위험도 분석 · 전체 항목 · 항목 상세 · 검진 안내

※ 화면 구성 순서 — 위 순서는 기획 기준안이다. 디자인·UX 흐름상 정보 우선순위나 스크롤 흐름이 어색한 경우 디자인 검토 후 영역 순서는 조정할 수 있다. 단, 각 영역 내부의 기능·표시 규칙은 유지한다.

세 상태는 같은 자리를 씀. 상단의 탭 줄과 데이터 가져오기 버튼은 어느 상태에서도 유지됨.

6.1 셀비 체크업

위험도 분석은 외부 서비스인 셀비 체크업이 담당함. 검진 결과를 근거로 10대 질환의 발병 위험도, 위험 요인, 건강 나이를 분석해 리포트로 줌. 유료이며 결제 전에 어떤 검진 결과를 쓸지 고르고 생활 습관 몇 가지를 입력함.

단계내용
소개무엇을 알 수 있는지 안내하고 분석 시작으로 넘김
검진 결과 선택가져온 검진 결과 중 분석에 쓸 회차를 고름
생활 습관 입력운동 관련 항목을 직접 입력함
결제이용 금액을 확인하고 결제함
리포트건강 나이, 발병 통계지수, 질환별 위험도를 봄

이 화면의 상세 정의는 셀비 체크업 문서에서 다룸. 검진요약에서는 진입까지만 책임짐.

8.1 검진대상조회

올해 내가 받을 수 있는 검진 항목을 확인하는 화면. 공단 조회 결과를 받은 글자 그대로 보여줌.

영역내용
일반검진정보일반검진 · 구강검진 두 줄. 값은 공단 글자 그대로(예: 「본인부담 없음」)
암검진공단이 보낸 암 종류를 보낸 순서대로 한 줄씩. 값은 공단 글자 그대로(예: 위암 「10%부담」, 대장암 「대상아님」)
규칙내용
값 표시앱에서 대상 여부를 판단하거나 글자를 바꾸지 않음. 「대상아님」이 아닌 값만 강조해 눈에 띄게 함
빈 값값이 비어 온 줄은 넣지 않음. 예: 청소년은 일반검진 · 구강검진이 비어 올 수 있음 → 그 두 줄을 빼고, 일반검진정보 카드 자체가 비면 카드도 뺌
대상 아님공단이 「건강검진 대상자가 아닙니다」로 답하면 결과가 비어 옴. 이때 일반검진 · 암검진 카드 대신 「올해는 건강검진 대상이 아닙니다」와 「건강보험공단 조회 결과, 0000년에 받을 수 있는 일반검진 · 구강검진 · 암검진이 없습니다.」를 보여줌
표시하지 않는 것조회기준일, 수검완료 여부. 공단 조회 결과에 없는 값이라 넣지 않음
화면 안 버튼두지 않음. 이 화면에서 따로 인증하지 않음(§10)

10연동 규칙

공단 인증과 데이터 갱신
항목규칙
인증 진입§3의 실행 버튼과 §2의 데이터 가져오기 버튼 모두 같은 흐름으로 들어감
인증 취소인증 도중 사용자가 그만두면 직전 상태로 돌아옴. 가져온 데이터가 있으면 그대로 유지함
다시 가져오기이미 데이터가 있어도 다시 받아올 수 있음. 성공하면 기존 결과를 최신 결과로 바꿈
실패 시 기존 데이터다시 가져오다 실패해도 기존에 가져온 결과는 지우지 않음
표시 기준여러 해 결과가 있어도 가장 최근 검진 결과를 기준으로 표시함
검진 대상 함께 조회검진 결과를 가져올 때 같은 간편인증 한 번으로 검진 대상 정보도 함께 가져와 저장함. 검진대상조회(§8.1)는 저장된 값을 보여주기만 하고, 들어갈 때마다 인증을 다시 받지 않음
검진 대상 갱신다시 가져오기를 할 때 검진 결과와 함께 바뀜. 검진 결과는 받았는데 검진 대상만 실패하면 검진 결과는 그대로 쓰고, §8 카드와 §8.1 화면은 「올해 검진 대상 정보를 불러오지 못했습니다.」로 대신함

12확인 필요

결정이 남아 있는 것
  • 건강 나이를 계산할 항목이 부족할 때 카드를 감출지, 다른 안내로 대체할지
