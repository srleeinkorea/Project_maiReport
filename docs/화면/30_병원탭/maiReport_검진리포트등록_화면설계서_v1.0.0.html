한눈에 보기

이 문서가 다루는 것방문이력의 「+」를 누른 순간부터 리포트가 방문이력에 들어갈 때까지 화면이 어떻게 이어지는지. 3장의 왼쪽 화면은 직접 눌러 볼 수 있음. 데이터는 모두 가상임.
가장 중요한 결정두 길 모두 사용자가 확인 화면을 지나야 저장됨. QR 길은 카메라 → 인식 결과 확인 → 저장 → 결과 화면, 업로드 길은 업로드 → 추출 중 → 추출 데이터 확인 → 최종 등록 → 완료.
아직 정해지지 않은 것10-14에 3건을 결정해 닫았음. 남은 것: 원본 파일 보관 기간. 자세한 내용은 「확인 필요」.

06

시나리오

44세 직장인, 회사 종합검진 결과지 PDF 1개와 사진 2장.

  1. 병원 탭 › 방문이력에서 「+」를 누름. 시트에서 「일반 검진 리포트 등록」을 고름.
  2. 업로드 화면. 「PDF」로 결과지 PDF를, 「앨범」으로 추가 사진 2장을 올림. 목록에 3개, 「다음」이 켜짐.
  3. 추출 중. 18% → 66% → 100%, 세 단계에 ✓가 붙음.
  4. 추출 데이터 확인. 기본 정보(2025.11.18 · KMI 광화문센터), 계측 검사, 혈액 검사가 보임. 공복혈당이 「1O2」로 읽혀 노란 표시와 「확인해 주세요」. 「원본 파일 3개 ›」로 PDF를 넘겨 보고 102로 고침.
  5. 「최종 등록」. 완료 화면. 「등록 결과 보기」를 누르면 검진 상세, 거기서 AI 검진요약 「검진 항목을 정리했어요」를 만들 수 있음.
  6. 방문이력에 「2025년 · 일반검진 · KMI 광화문센터 · 📷 등록」 카드가 생겼음. 연동 건과 같은 모양이고 출처 태그만 다름.

질문누가 정하나기한상태
확신 낮은 값의 표시(칸 색 · 문구)와 기준 신뢰도디자인 · 개발인식 엔진 결정 뒤닫힘(10-14) · 값 칸 테두리 강조 + 「확인해 주세요」. 기준은 신뢰도 80% 미만 또는 형식 불일치. 색은 디자인에서
