06

시나리오

44세, 공단 검진 연동 완료, 진료정보 미연동, AI REPORT 1건 등록.

  1. 병원 탭 첫 화면 검진요약에 건강나이 45세와 주요 소견(공복혈당 경계)이 보임. 「검진 상세 보기」로 전체 항목을 확인하고 결과지 원본을 넘겨 봄.
  2. 방문이력으로 가면 상단에 「진료정보 · 데이터 연동하기」 안내 카드 한 줄과 2026년 아래 AI REPORT · 검진 카드 두 장이 보임. 「AI REPORT」 필터를 누르면 한 장만 남음.
  3. 읽을거리에는 흉부 X-ray 소견과 연결된 「폐 질환」 글이 앞에 옴. 한 편을 열어 원인 · 진단 · 치료 · 예방을 읽고 출처를 봄.
