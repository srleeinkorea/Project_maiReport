01

배경과 목표

검진 결과지는 받은 뒤 서랍에 들어가고, 어느 병원에 언제 갔는지는 기억에만 남음. 병원 탭은 공단의 검진 결과, 심평원의 진료 · 처방 기록, 사용자가 직접 등록한 리포트를 한 곳에 모아 「내 의료 기록이 무엇을 뜻하는지」 이해하게 하는 자리임.

목표는 세 가지임. 가져오기 전에는 무엇을 볼 수 있는지 분명히 알려 연동을 유도함. 가져온 뒤에는 요약 → 목록 → 상세 → 원문으로 깊이를 고를 수 있게 함. 기록과 연결된 읽을거리로 다음 행동을 돕음.

04

동작 방식

화면 구성 순서 · 아래 순서는 기획 기준안임. 디자인 · UX 흐름상 정보 우선순위나 스크롤 흐름이 어색하면 디자인 검토 후 영역 순서는 조정할 수 있음. 단, 각 영역 안의 기능 · 표시 규칙은 그대로 둠.

가져오기 전

  1. 검진요약 탭은 「건강검진 정보를 가져와 주세요」 빈 화면임. 무엇을 볼 수 있는지 네 가지(최근 건강검진 결과 조회 · 주요 질환 위험도 예측 · 건강나이 측정 · 검진 결과 AI 요약)와 「건강검진 데이터 가져오기」 버튼. 진료요약 탭도 같은 틀로 세 가지(병원 방문 내역 · 처방 이력 · 진료비 지출 통계).
  2. 버튼을 누르면 개인정보 · 민감정보 동의 2개(이미 동의했으면 생략)와 본인 확인을 거쳐 가져옴. 「가져오는 중」 카드는 「국민건강보험공단에서 데이터를 불러오는 중입니다. 최대 1분 정도 소요될 수 있습니다」를 보여주고, 다른 탭으로 가도 계속됨.
  3. 방문이력 탭은 가져오기 전에도 열림. 상단에 「연동하면 더 볼 수 있어요」 카드 하나에 아직 연동하지 않은 정보만 줄로 나열함. 기관이 달라 각각 인증해야 하므로 버튼은 줄마다 둠.

가져온 뒤

  1. 검진요약: 건강나이, 셀비 체크업 진입, 주요 검진 소견 5행(혈압 · 혈당 · 콜레스테롤 · 간수치 · 신장수치, 표준 · 경계 · 주의), 검진 대상 안내.
  2. 진료요약: 병원 · 진료과 TOP 3, 올해 진료비, 분기 차트와 전년 대비. 금액에는 「공단 기준으로 계산한 금액이에요. 최근 한 달 이내 진료는 아직 반영되지 않을 수 있어요」를 붙임.
  3. 방문이력: 검진 · 진료 · AI REPORT 건을 연도별 시간순으로 한 목록에. 필터칩(전체 · 검진 · 진료 · AI REPORT). 카드를 누르면 검진상세 · 진료상세 · AI REPORT 결과로.
  4. 읽을거리: 내 질환 · 소견에 맞춘 콘텐츠 카드 4개(예: 흉부 엑스레이에서 흔한 10가지 비정상 소견, 폐결핵의 원인과 증상). 상세는 원인 · 진단 · 치료 · 예방 · 출처 순.
빈 화면(무엇을 볼 수 있나)→동의 2개 · 본인 확인→가져오는 중(최대 1분)→요약→방문이력 목록→상세 · 원문

규칙과 예외

규칙예시예외
검진과 진료는 각각 인증하되 안내는 한 카드에방문이력 상단 카드에 「검진정보 · 진료정보」 두 줄, 버튼은 줄마다둘 다 연동되면 카드 없음
연동 갱신 · 해제는 병원 탭에 두지 않음검진요약 하단의 「마지막 업데이트 · 연동 관리」 링크는 뺐음(2026-09-23)더보기 › 건강검진 · 진료정보 연동에서만
한쪽만 연동되면 그쪽만 보여주고 나머지는 안내검진만 연동: 검진요약 정상, 진료요약은 빈 화면, 방문이력은 검진 건만 + 진료 안내 줄—
등록한 리포트는 연동 건과 같은 목록에, 출처만 구분AI REPORT 카드에 「AI」 표시와 「확인 필요 / 특이 소견 없음」 상태—
세부 항목이 오지 않는 진료 건은 요약만심평원이 진단명을 주지 않으면 병원 · 날짜 · 진료비만확인 필요 ②
사용자 메모는 연동 데이터와 구분해 저장진료상세 메모 칸. 연동 데이터를 덮어쓰지 않음—
AI 결과에는 진단을 대신하지 않는다는 고지를 함께AI REPORT 결과 · ChatGPT 요약 하단 문구고지 없이 결과만 보여주는 화면을 만들지 않음
읽을거리는 내 질환 · 소견과 연결된 것만AI REPORT에 경화 소견 → 폐 질환 글 우선연결할 기록이 없으면 일반 건강 글 4개

기능 정의

기능정의서 §8 「병원 · 의료 기록」을 이 기획서로 옮긴 표.

기능언제하는 일 · 결과어긋나면
검진 · 진료 최초 연동[데이터 가져오기] · 빈 상태 카드개인정보 동의와 민감정보 동의 체크박스 2개(이미 동의했으면 생략), 본인 확인 뒤 데이터를 가져오고 기간과 시각을 남김. 주민번호는 안내 문구만 두고 서버에 보관하지 않음. 기관별 동의는 따로 받지 않음실패하면 사유를 남기고 다시 시도하게 함. 부분 성공도 기록함
연동 상태 요약병원 탭 진입검진 · 진료 각각의 연동 여부와 마지막 갱신 시각을 요약함한쪽만 연동됐으면 그쪽만 보여주고 나머지는 연동 안내를 둠
데이터 갱신더보기에서 갱신 선택최신 상태로 다시 가져옴. 이미 있는 건은 중복으로 쌓지 않음. 재동의는 받지 않음갱신 중에는 다시 누를 수 없게 함
검진요약 구성검진요약 탭건강나이, 확인이 필요한 주요 소견, 검진 안내를 정리함검진 기록이 없으면 불러오기 안내만
검진 상세 조회검진 건 선택한 건의 전체 항목과 참고치 대비 상태를 보여줌항목이 일부만 있으면 있는 것만 보여주고 누락을 밝힘
문진표 · 결과지 원문검진 상세에서 선택원래 문서 형식 그대로 보여줌. 확대 · 축소원문이 없는 건은 진입 경로를 두지 않음
방문이력 조회방문이력 탭검진 · 진료 · 등록한 리포트를 연도별 시간순으로 모아 보여줌. 필터로 종류를 고름아무 기록도 없으면 연동과 등록 두 길을 함께 안내함
진료 상세 조회진료 건 선택진단명 · 이번 진료비(공단 · 본인) · 처방약 · N번째 방문 · 메모세부 항목이 오지 않는 건은 요약만
진료 메모메모 작성 · 수정사용자가 남기는 메모를 저장하고 연동 데이터와 구분해 표시함연동 데이터를 메모로 덮어쓰지 않음
진료 이용현황진료요약에서 선택연도별 진료비 · 자주 이용한 병원 · 진료과기간에 기록이 없으면 그 구간을 비워 둠. 진입 버튼이 아직 없음(확인 필요 ③)
검진대상조회검진요약에서 선택올해 받을 수 있는 일반검진 · 구강검진 · 암검진과 공단 값(예: 「본인부담 없음」 · 「10%부담」 · 「대상아님」)검진 결과를 가져올 때 함께 조회. 결과가 비어 오면 「올해는 건강검진 대상이 아닙니다」
AI REPORT 결과 표시AI REPORT 카드 선택 · 등록 직후소견별 결과(확인 필요 · 특이 소견 없음)와 원본 PDF를 함께. 점수는 판독 보조값이며 확률이나 중증도가 아님을 밝힘원본이 없으면 결과만 단독으로 보여주지 않음
읽을거리읽을거리 탭내 질환 · 소견과 연결된 콘텐츠 카드 4개. 상세는 원인 · 진단 · 치료 · 예방 · 출처연결할 기록이 없으면 일반 건강 글. 출처 없는 글은 싣지 않음
