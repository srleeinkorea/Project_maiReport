1. 배경과 목표

검진 결과지는 받은 뒤 서랍에 들어가고, 어느 병원에 언제 갔는지는 기억에만 남는다. 병원 탭은 공단의 검진 결과, 심평원의 진료 · 처방 기록, 사용자가 직접 등록한 리포트를 한 곳에 모아 「내 의료 기록이 무엇을 뜻하는지」 이해하게 하는 자리다.

목표는 세 가지다. 가져오기 전에는 무엇을 볼 수 있는지 분명히 알려 연동을 유도한다. 가져온 뒤에는 요약 → 목록 → 상세 → 원문으로 깊이를 고를 수 있게 한다. 기록과 연결된 읽을거리로 다음 행동을 돕는다.

4. 동작 방식

가져오기 전

  1. 검진요약 탭은 「건강검진 정보를 가져와 주세요」 빈 화면이다. 무엇을 볼 수 있는지 네 가지(최근 건강검진 결과 조회 · 주요 질환 위험도 예측 · 건강나이 측정 · 검진 결과 AI 요약)와 「건강검진 데이터 가져오기」 버튼. 진료요약 탭도 같은 틀로 세 가지(병원 방문 내역 · 처방 이력 · 진료비 지출 통계).
  2. 버튼을 누르면 개인정보 · 민감정보 동의 2개(이미 동의했으면 생략)와 본인 확인을 거쳐 가져온다. 「가져오는 중」 카드는 「국민건강보험공단에서 데이터를 불러오는 중입니다. 최대 1분 정도 소요될 수 있습니다」를 보여주고, 다른 탭으로 가도 계속된다.
  3. 방문이력 탭은 가져오기 전에도 열린다. 상단에 「연동하면 더 볼 수 있어요」 카드 하나에 아직 연동하지 않은 정보만 줄로 나열한다. 기관이 달라 각각 인증해야 하므로 버튼은 줄마다 둔다.

가져온 뒤

  1. 검진요약: 건강나이, 셀비 체크업 진입, 주요 검진 소견 5행(혈압 · 혈당 · 콜레스테롤 · 간수치 · 신장수치, 표준 · 경계 · 주의), 검진 대상 안내.
  2. 진료요약: 병원 · 진료과 TOP 3, 올해 진료비, 분기 차트와 전년 대비. 금액에는 「공단 기준으로 계산한 금액이에요. 최근 한 달 이내 진료는 아직 반영되지 않을 수 있어요」를 붙인다.
  3. 방문이력: 검진 · 진료 · AI REPORT 건을 연도별 시간순으로 한 목록에. 필터칩(전체 · 검진 · 진료 · AI REPORT). 카드를 누르면 검진상세 · 진료상세 · AI REPORT 결과로.
  4. 읽을거리: 내 질환 · 소견에 맞춘 콘텐츠 카드 4개(예: 흉부 엑스레이에서 흔한 10가지 비정상 소견, 폐결핵의 원인과 증상). 상세는 원인 · 진단 · 치료 · 예방 · 출처 순.
빈 화면(무엇을 볼 수 있나)→동의 2개 · 본인 확인→가져오는 중(최대 1분)→요약→방문이력 목록→상세 · 원문

5. 규칙과 예외

규칙예시예외
검진과 진료는 각각 인증하되 안내는 한 카드에방문이력 상단 카드에 「검진정보 · 진료정보」 두 줄, 버튼은 줄마다둘 다 연동되면 카드 없음
연동 갱신 · 해제는 병원 탭에 두지 않는다검진요약 하단의 「마지막 업데이트 · 연동 관리」 링크는 뺐다(2026-09-23)더보기 › 건강검진 · 진료정보 연동에서만
한쪽만 연동되면 그쪽만 보여주고 나머지는 안내검진만 연동: 검진요약 정상, 진료요약은 빈 화면, 방문이력은 검진 건만 + 진료 안내 줄—
등록한 리포트는 연동 건과 같은 목록에, 출처만 구분AI REPORT 카드에 「AI」 표시와 「확인 필요 / 특이 소견 없음」 상태—
세부 항목이 오지 않는 진료 건은 요약만심평원이 진단명을 주지 않으면 병원 · 날짜 · 진료비만확인 필요 ②
사용자 메모는 연동 데이터와 구분해 저장진료상세 메모 칸. 연동 데이터를 덮어쓰지 않는다—
AI 결과에는 진단을 대신하지 않는다는 고지를 함께AI REPORT 결과 · ChatGPT 요약 하단 문구고지 없이 결과만 보여주는 화면을 만들지 않는다

기능 정의

기능정의서 §8 「병원 · 의료 기록」을 이 기획서로 옮긴 표.

기능언제하는 일 · 결과어긋나면
검진 · 진료 최초 연동[데이터 가져오기] · 빈 상태 카드개인정보 동의와 민감정보 동의 체크박스 2개(이미 동의했으면 생략), 본인 확인 뒤 데이터를 가져오고 기간과 시각을 남긴다. 주민번호는 안내 문구만 두고 서버에 보관하지 않는다. 기관별 동의는 따로 받지 않는다실패하면 사유를 남기고 다시 시도하게 한다. 부분 성공도 기록한다
연동 상태 요약병원 탭 진입검진 · 진료 각각의 연동 여부와 마지막 갱신 시각을 요약한다한쪽만 연동됐으면 그쪽만 보여주고 나머지는 연동 안내를 둔다
데이터 갱신더보기에서 갱신 선택최신 상태로 다시 가져온다. 이미 있는 건은 중복으로 쌓지 않는다. 재동의는 받지 않는다갱신 중에는 다시 누를 수 없게 한다
검진요약 구성검진요약 탭건강나이, 확인이 필요한 주요 소견, 검진 안내를 정리한다검진 기록이 없으면 불러오기 안내만

7. 성공 기준

  • 빈 화면에서 「가져오기」를 누른 사용자의 80% 이상이 1분 안에 요약 화면을 본다.
  • 방문이력에서 검진 · 진료 · 등록 건이 한 목록에 시간순으로 섞여 보이고, 필터로 즉시 나뉜다.
  • AI REPORT 결과에 원본 PDF 링크와 고지가 항상 함께 있다.
  • 읽을거리 4개 중 최소 2개가 사용자의 기록과 연결된 글이다(기록이 있을 때).
