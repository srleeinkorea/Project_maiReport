01

배경과 목표

건강검진 결과는 공단 연동으로 들어오지만, 연동 전 기록 · 직장 검진 · 민간 검진 · 영상 AI 판독 결과(AI REPORT)는 연동으로 받을 수 없음. 사용자가 손에 쥔 결과지를 앱에 넣을 길이 있어야 방문이력이 빈 채로 남지 않고, 검진 요약 · AI 요약 · 또래 비교가 더 많은 사용자에게 동작함.

목표는 두 가지임. 첫째, 결과지를 찍거나 QR을 읽는 것만으로 값이 항목별로 정리되게 함. 둘째, 자동으로 읽은 값이 틀릴 수 있으므로 사용자가 반드시 한 번 확인하고 저장하게 함.

04

동작 방식

화면 구성 순서 · 아래 순서는 기획 기준안임. 디자인 · UX 흐름상 정보 우선순위나 스크롤 흐름이 어색하면 디자인 검토 후 영역 순서는 조정할 수 있음. 단, 각 영역 안의 기능 · 표시 규칙은 그대로 둠.

두 갈래 모두 「수집 → 추출 → 사용자 검수 → 저장」 네 단계를 지킴. 다른 점은 수집 방법과 추출 결과의 모양임.

유형 선택→수집(QR 촬영 / 파일 업로드)→추출(값을 항목으로 정리)→사용자 검수(확인 · 수정)→저장 → 방문이력 · 결과 화면

AI REPORT (QR)

  1. 홈 헤더의 「AI REPORT 스캔」 또는 방문이력 「+」 › AI REPORT를 누르면 QR 카메라가 열림. 안내: 「리포트에 인쇄된 QR 코드를 사각형 안에 맞춰 주세요」.
  2. QR을 읽으면 리포트 내용(검진일 · 검진기관 · 검사 종류 · 판독 결과)을 받아 옴. 예: 2026.09.22 · MAIHUB · 흉부 X-ray(R-PA) · 경화, AI 점수 19.
  3. 인식 결과 확인 화면에서 항목을 보여주고, 틀린 값은 눌러서 고칠 수 있음. 「다시 촬영」과 「저장하기」.
  4. 저장하면 방문이력에 AI REPORT 건이 생기고, 곧바로 AI REPORT 결과 화면이 열림. 스캔한 사람이 가장 먼저 보고 싶은 것은 방금 등록한 결과이기 때문임. 결과를 닫으면 홈이 드러남.

일반 검진 리포트 (촬영 · 업로드)

  1. 방문이력 「+」 › 일반 검진 리포트를 누르면 등록 안내 화면이 열림. 「여러 장일 경우 순서대로 업로드해 주세요」. 입력 방법은 카메라 · 앨범 · PDF 세 가지.
  2. 올린 장수를 보여주고 「다음」을 누르면 추출이 시작됨. 진행률과 세 단계(파일 업로드 완료 · 문서 인식 및 추출 · 검진 결과 정리)를 보여줌.
  3. 추출 데이터 확인 화면에서 항목과 값을 확인하고 고침. 원본을 장 단위로 넘겨 대조할 수 있음. 확신이 낮은 값은 눈에 띄게 표시함.
  4. 「최종 등록」을 누르면 검수한 값만 저장되고, 방문이력과 검진요약 · 검진상세에 반영됨. 완료 화면에서 다음 행동(검진상세 보기 · AI 요약)을 안내함.

규칙과 예외

규칙예시예외
검수 없이는 저장되지 않음QR을 읽자마자 방문이력에 들어가지 않고, 확인 화면의 「저장하기」를 눌러야 들어감없음. 검수를 건너뛰는 설정을 두지 않음

등록 건은 출처를 「등록」으로 표시해 연동 건과 구분함방문이력 카드에 출처 태그—

성공 기준

  • QR 스캔부터 결과 화면까지 30초 안에 끝남(QR 인식 1회 기준).
  • 일반 검진 리포트 3장 기준, 추출 완료까지 1분 이내. 1분을 넘기면 진행 상태를 유지한 채 알림.
  • 검수 화면에서 사용자가 고치는 값의 비율이 10% 아래로 내려감(인식 품질 지표).
  • 등록 건이 방문이력 · 검진요약 · 검진상세에 연동 건과 같은 모양으로 보임.
