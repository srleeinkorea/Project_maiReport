한눈에 보기

이 문서가 다루는 것사용자가 종이 · PDF로 받은 검진 결과와 AI REPORT를 앱에 넣는 두 갈래 길(QR 스캔 · 촬영 · 업로드)과, 읽어 들인 값을 사람이 확인한 뒤에만 저장하는 원칙
가장 중요한 결정읽어 들인 값은 사용자 검수를 거쳐야만 저장된다. 검수를 건너뛰는 경로는 두지 않는다
아직 정해지지 않은 것일반 검진 리포트에서 인식 항목의 범위(어떤 검사 항목까지 뽑는지)와 확신이 낮은 값의 표시 기준

1. 배경과 목표

건강검진 결과는 공단 연동으로 들어오지만, 연동 전 기록 · 직장 검진 · 민간 검진 · 영상 AI 판독 결과(AI REPORT)는 연동으로 받을 수 없다. 사용자가 손에 쥔 결과지를 앱에 넣을 길이 있어야 방문이력이 빈 채로 남지 않고, 검진 요약 · AI 요약 · 또래 비교가 더 많은 사용자에게 동작한다.

목표는 두 가지다. 첫째, 결과지를 찍거나 QR을 읽는 것만으로 값이 항목별로 정리되게 한다. 둘째, 자동으로 읽은 값이 틀릴 수 있으므로 사용자가 반드시 한 번 확인하고 저장하게 한다.

2. 대상과 상황

인물상황바라는 것
58세, 폐렴으로 진료 후 흉부 X-ray를 찍고 AI REPORT 종이를 받음병원 로비에서 리포트의 QR을 앱으로 스캔한다판독 결과가 무엇인지 바로 알고, 기록으로 남기고 싶다
44세, 회사 종합검진을 민간 병원에서 받아 PDF로 받음집에서 PDF를 앱에 올린다공단 검진처럼 항목별 값과 판정이 정리되고 다음 검진과 비교되길 바란다

3. 범위

이번에 하는 것하지 않는 것
  • AI REPORT: QR 스캔 → 인식 결과 확인 → 저장 → 결과 화면
  • 일반 검진 리포트: 카메라 촬영 · 앨범 · PDF 업로드(여러 장) → 추출 → 검수 → 등록
  • 등록된 건을 방문이력에 「등록」 출처 표시로 넣기
  • 같은 리포트를 다시 등록하면 기존 건을 갱신
  • 사용자가 검사 값을 빈 양식에 직접 타이핑해 넣는 수동 입력 화면
  • 공단 · 심평원 연동으로 들어온 건의 수정
  • 리포트 원본 이미지의 공유 · 내보내기
  • AI REPORT 외 다른 영상 AI 결과 형식

4. 동작 방식

두 갈래 모두 「수집 → 추출 → 사용자 검수 → 저장」 네 단계를 지킨다. 다른 점은 수집 방법과 추출 결과의 모양이다.

유형 선택→수집(QR 촬영 / 파일 업로드)→추출(값을 항목으로 정리)→사용자 검수(확인 · 수정)→저장 → 방문이력 · 결과 화면

AI REPORT (QR)

  1. 홈 헤더의 「AI REPORT 스캔」 또는 방문이력 「+」 › AI REPORT를 누르면 QR 카메라가 열린다. 안내: 「리포트에 인쇄된 QR 코드를 사각형 안에 맞춰 주세요」.
  2. QR을 읽으면 리포트 내용(검진일 · 검진기관 · 검사 종류 · 판독 결과)을 받아 온다. 예: 2026.09.22 · MAIHUB · 흉부 X-ray(R-PA) · 경화, AI 점수 19.
  3. 인식 결과 확인 화면에서 항목을 보여주고, 틀린 값은 눌러서 고칠 수 있다. 「다시 촬영」과 「저장하기」.
  4. 저장하면 방문이력에 AI REPORT 건이 생기고, 곧바로 AI REPORT 결과 화면이 열린다. 스캔한 사람이 가장 먼저 보고 싶은 것은 방금 등록한 결과이기 때문이다. 결과를 닫으면 홈이 드러난다.

일반 검진 리포트 (촬영 · 업로드)

  1. 방문이력 「+」 › 일반 검진 리포트를 누르면 등록 안내 화면이 열린다. 「여러 장일 경우 순서대로 업로드해 주세요」. 입력 방법은 카메라 · 앨범 · PDF 세 가지.
  2. 올린 장수를 보여주고 「다음」을 누르면 추출이 시작된다. 진행률과 세 단계(파일 업로드 완료 · 문서 인식 및 추출 · 검진 결과 정리)를 보여준다.
  3. 추출 데이터 확인 화면에서 항목과 값을 확인하고 고친다. 원본을 장 단위로 넘겨 대조할 수 있다. 확신이 낮은 값은 눈에 띄게 표시한다.
  4. 「최종 등록」을 누르면 검수한 값만 저장되고, 방문이력과 검진요약 · 검진상세에 반영된다. 완료 화면에서 다음 행동(검진상세 보기 · AI 요약)을 안내한다.

규칙예시예외

AI REPORT의 소견 이름과 점수는 원본 리포트(Lunit INSIGHT CXR)의 10가지 이상 소견 체계를 그대로 따른다. 점수는 판독 보조값이며 확률이나 중증도가 아니다.

7. 성공 기준

  • QR 스캔부터 결과 화면까지 30초 안에 끝난다(QR 인식 1회 기준).
  • 일반 검진 리포트 3장 기준, 추출 완료까지 1분 이내. 1분을 넘기면 진행 상태를 유지한 채 알린다.
  • 검수 화면에서 사용자가 고치는 값의 비율이 10% 아래로 내려간다(인식 품질 지표).
  • 등록 건이 방문이력 · 검진요약 · 검진상세에 연동 건과 같은 모양으로 보인다.
