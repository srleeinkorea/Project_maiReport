홈 화면설계서

홈의 여섯 영역이 시각 · 연동 상태 · 답변 진행에 따라 어떻게 바뀌고 서로 어떻게 이어지는지를 동작하는 화면으로 정리한 설계서임. 왼쪽 화면은 직접 눌러 볼 수 있고, 오른쪽에는 지금 보이는 상태의 이유와 상태 전이 규칙, 화면 이동, 결정 사항을 적었음. 문구와 표시 규칙은 홈 화면정의서, 질문 · 코칭 · 목표가 만들어지는 순서는 하루 생성 순서도, 식이 질문의 상세는 식이 화면설계서를 따름.

영역별 상태 전이

각 영역이 가질 수 있는 상태와, 무엇이 그 상태를 바꾸는지
영역상태바뀌는 조건
오늘의 질문진행 중 → 모두 완료첫 진입 때 그날 문항 세트를 한 번 정함(최대 5~6문항). 한 문항씩 보여주고 고르면 0.5초 뒤 다음으로 넘어감. 끼니 질문에 답하면 같은 자리에서 식사 시각 질문이 이어짐(어제 저녁 · 「못 먹거나 거름」은 묻지 않음). 마지막 문항에 답하면 완료 상태가 되고 「오늘 답변 모두 보기」가 생김. 답하지 않은 문항은 하루 동안 남음. 끼니 구간이 바뀌면 답하지 않은 식사 문항의 끼니만 갱신됨.
오늘의 코칭답변 전 → 생성 중 → 행동 한 줄모든 문항에 답한 시점에 한 번 만듦. 일부만 답했으면 「답변 전」 그대로임. 답변을 고치면 생성 중 → 결과를 다시 거침. 낮 동안 기기 데이터가 늘어도 문구는 바뀌지 않음. 17시 이후 생성이면 마무리형 문구를 씀. 「생성 중」이 5초를 넘으면 식이 기본 문구를 먼저 보여주고 응답이 오면 교체함.
오늘의 목표잠김 → 기본 ⇄ 완료첫 진입 때 목표마다 판정함. 식이는 항상 잠긴 채 시작함. 활동은 오늘 걸음 기록, 수면은 어젯밤 수면 기록이 있으면 바로 만들고 없으면 잠금. 잠긴 목표는 질문에 모두 답한 시점에 코칭과 함께 열림. 타일을 누르면 완료, 다시 누르면 취소(홈에는 「쉬기」가 없음). 완료한 목표와 기기 데이터로 만든 목표는 답변을 고쳐도 바뀌지 않음. 자동 완료는 없음. 건강 데이터가 없으면 활동은 기본 문구로 바로 열고 수면만 잠금. 「기록 있음」은 오늘 걸음 1건 · 어젯밤 수면 세션 1개면 충분함.
오늘의 컨디션미연동 · 관찰 중 · 구간 표시건강 데이터가 없으면 게이지 대신 연동 안내와 버튼. 연동됐지만 기록이 부족하면 빈 게이지와 「관찰 중」. 기록이 있으면 세 지표를 각각 세 구간 중 하나로 표시하고, 주의 구간이 하나라도 있을 때만 요약 한 줄을 붙임. 기기 데이터가 갱신될 때마다 다시 계산함(질문 답변은 지표에 들어가지 않음).
오늘의 건강 데이터숨김 · 값 + 어제 대비미연동이면 컨디션 영역에 이미 안내가 있으므로 이 영역은 숨김. 연동이면 걸음 · 수면 · 안정 시 심박 세 줄을 보여주고 어제 값과의 차이만 적음. 값이 없는 줄은 「기록 없음」. 걸음은 자정 기준 누적이라 오전에는 작음.
나의 건강, 숫자로 한눈에결과 없음 · 점수 · 건강나이 · 등수AI 인사이트 결과가 있으면 최근 결과의 점수와 분석 기간만, 없으면 안내 문구와 「분석하기」(생활 › AI 인사이트로 이동). 검진정보가 없으면 건강나이 · 또래 등수 대신 검진 연동 안내 카드 하나.
헤더 알림점 없음 · 점 표시안 읽은 알림이 있으면 점만 표시함. 누르면 알림 목록으로 이동함. 숫자는 쓰지 않음.

결정 사항 (2026-10-14)

초안의 미결 7가지를 아래와 같이 정했음. 홈 화면정의서 · 기능정의서 · IA에도 같은 내용을 반영했음.
  1. 미연동일 때 활동 · 수면 목표 — 활동은 기록 없이도 안전한 기본 문구(예: 「점심 식후 10분 걷기」)로 첫 진입 때 바로 열고, 수면만 잠가 수면 문항 답변으로 만듦. 타일 3개가 모두 잠겨 빈 화면처럼 보이지 않게 하기 위해서임.
  2. 「쉬기」 — 홈 타일에는 두지 않음. 탭 한 번 = 완료, 다시 탭 = 취소뿐임. 쉬기는 생활 › 목표 분석에서만 기록함.
  3. 식이 외 문항 — 코칭 문구에 실제로 필요한 입력부터 문항을 만듦. 웨어러블로 받을 수 없는 입력(확진 질환 · 식사 시각 · 피로감)이 먼저이고, 활동 문항은 연동 사용자에게 불필요해 뒤로 둠. 수면 · 피로감 · 운동 문항은 지식DB 자가응답 질문 12개에서 고름. 전체 문구는 「오늘의 질문 문구」 문서.
  4. 코칭 생성 시간 — 「생성 중」은 최대 5초. 5초가 지나면 답변만으로 정할 수 있는 식이 기본 문구를 먼저 보여주고, 응답이 오면 조용히 교체함. 예: 「못 먹거나 거름」이면 「다음 끼니는 거르지 말고 조금이라도 챙겨 먹기」.
  5. 잠금 판정 기준 — 활동은 오늘 걸음 기록이 1건이라도 있으면, 수면은 어젯밤 수면 세션이 1개라도 있으면 「기록 있음」으로 봄. 문구의 숫자는 최근 개인 기록으로 정하므로 오늘 값이 작아도 됨.
  6. 저녁 안내 문장 — 17시 이후 「오늘 저녁」 질문 아래 「오늘 저녁을 드신 뒤 답해주세요」를 유지함. 식사 시각 질문 단계에는 다시 붙이지 않음.
  7. 결식 3일 연속 안내 — 이 판에서는 제외하고 보류를 유지함. 코칭 문구가 화면에 나오는 것을 확인한 뒤 코칭 한 줄로 다시 검토함.
