오늘의 질문 · 질문과 선택지

사용자가 홈의 「오늘의 질문」 카드에서 보는 질문과 선택지를 한곳에 모음. 화면에 나가는 글자 그대로 적음. 선택지는 모두 3개이고 건너뛰기는 없음.

기준일 2026-10-15식이 정본 식이 개발 전달 데이터 계약 v1.3.0식이 질문 확정보완 질문 지식DB 문구 기준

하루에 묻는 순서

한 번에 한 질문씩 같은 카드에서 바뀜. 하루 최대 5~6문항
① 식사 질문→ ② 식사 시각→ ③ 식이 회전 질문 1개→ ④ 보완 질문
  • 진료정보에 아직 확인하지 않은 질환이 있는 날은 ① 자리에 질환 확인 질문이 먼저 나옴. 하루 1개까지.
  • ① 에서 「못 먹거나 거름」을 고르면 ② 식사 시각은 묻지 않음.
  • 건강 앱에 그 끼니 식사 기록이 있으면 ② 식사 시각은 묻지 않음.
