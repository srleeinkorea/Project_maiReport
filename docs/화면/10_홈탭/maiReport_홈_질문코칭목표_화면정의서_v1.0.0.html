한눈에 보기

이 문서가 다루는 것홈 위쪽 세 영역(오늘의 질문 · 오늘의 코칭 · 오늘의 목표)에 무엇이 보이고 각 요소가 어떤 규칙으로 표시되는지. 컨디션 · 건강 데이터 · 건강 요약 영역은 홈 화면 전체 정의서를 봄.
가장 중요한 결정질문은 한 번에 한 문항만 보이고, 코칭 카드와 잠긴 목표 타일은 모두 답한 순간에 함께 바뀜. 타일에는 행동 문구만 두고 이유 · 근거 · 연속일수는 쓰지 않음.
아직 정해지지 않은 것10-14에 5건을 결정해 닫았음. 남은 것 없음. 자세한 내용은 「확인 필요」.
01

화면 개요

역할들어오는 길나가는 곳
오늘 할 일을 정해 주는 홈의 머리 부분. 질문으로 재료를 모으고, 코칭 한 줄과 목표 3개로 결론을 보여 줌.앱 실행 · 하단 탭 「홈」 · 생활 탭에서 잠긴 목표 타일을 눌렀을 때(남은 질문으로 이동) · 알림(질문 남았어요)오늘 답변 모두 보기(답 수정) · 생활 탭 › 목표 분석(「n/3 완료 ›」) · 남은 질문(잠긴 타일 탭)
02

화면 구성

※ 화면 구성 순서 — 위 순서는 기획 기준안이다. 디자인·UX 흐름상 정보 우선순위나 스크롤 흐름이 어색한 경우 디자인 검토 후 영역 순서는 조정할 수 있다. 단, 각 영역 내부의 기능·표시 규칙은 유지한다.

번호영역한 줄 설명
①오늘의 질문진행 표시 · 질문 · 일러스트 · 선택지 3개. 한 번에 한 문항. 모두 답하면 완료 카드로 바뀜
②오늘의 코칭라벨과 핵심 행동 한 줄. 답변 전 → 생성 중 → 결과 세 상태
③오늘의 목표제목 · 「n/3 완료 ›」 · 타일 3개(식이 · 활동 · 수면). 타일은 잠김 · 기본 · 완료 세 상태
03

영역별 정의

① 오늘의 질문

요소표시 규칙데이터 출처
진행 표시「오늘의 질문 · n/N」. N은 그날 문항 수(5 미만). 식사 시각 질문도 1개로 셈. 「못 먹거나 거름」을 고르면 시각 · 회전 문항이 빠져 N이 줄어듦(예: 1/4 → 2/2)그날 문항 상태
질문끼니 이름이 문장 첫머리에 옴. 끼니는 진입 시각으로 정함: 04~10시 어제 저녁 · 10~12시 오늘 아침 · 12~17시 오늘 점심 · 17~24시 오늘 저녁 · 00~04시 어제 저녁. 아침·낮은 현재형, 17시 이후 첫 진입은 과거형. 질문 카드 폭 한도 32자문항 풀(식이 8축 · 보완 문항) · 진입 시각
안내 문장17~24시 「오늘 저녁」 식사 질문 아래에만 「오늘 저녁을 드신 뒤 답해주세요」. 버튼이 아니며 저장하지 않음. 00~04시와 점심에는 붙이지 않음진입 시각
일러스트문항 종류별 그림 1개. 종류는 디자인에서 정함문항 종류
선택지항상 3개. 좋음 · 보통 · 나쁨 순서. 판단 어투 없이 사실만(「없었어요」). 등급 라벨 없음. 건너뛰기 버튼 없음. 답 버튼 폭 한도 14자(시각 선택지와 「못 먹거나 거름」은 예외)문항 풀의 선택지
식사 시각 선택지식사 답 바로 뒤 같은 자리에서 버튼 3개로 바뀜. 오전·오후는 위에 작게, 시각은 크게. 1시간 간격, 답한 시각을 10분 단위로 내림. 아침은 「7시 이전 · 7시~8시 · 8시 이후」 고정. 점심 오후 2시 · 저녁 오후 9시를 넘으면 그 시각에 답한 것과 같은 선택지를 보여 주고 작은 글씨(「1시간 이내」 등)를 뺌답한 시각 · 끼니
완료 카드모두 답하면 「오늘의 질문 완료 / 잘 했어요 👍 답변을 모두 완료했어요!」 + 클립보드 일러스트 + 「오늘 답변 모두 보기 ›」 · 「오늘의 몸 상태를 계속 유지해 봐요!」그날 문항 상태

② 오늘의 코칭

요소표시 규칙데이터 출처
라벨「오늘의 코칭」 고정—
본문핵심 행동 한 줄. 이유 · 근거 · 목표 이유는 싣지 않음. 17시 이후 생성이면 남은 시간에 맞는 마무리형 문구코칭 생성 결과(답 + 기기 데이터)

③ 오늘의 목표

요소표시 규칙데이터 출처
섹션 제목「오늘의 목표」 + 오른쪽 「n/3 완료 ›」. n은 완료한 타일 수. 탭하면 생활 탭 › 목표 분석목표 기록
타일 3개식이 · 활동 · 수면 고정 순서. 카테고리 아이콘·이름과 목표 문구만. 이유 · 비교 문구 · 연속일수 · 축 · 단계 · 근거는 두지 않음. 타일 문구 폭 한도 22자, 두 줄 이내, 명사형 또는 「~하기」. 「~하세요」 · 수치 목표(식이) · 질환명은 쓰지 않음목표 기록(카테고리 × 날짜)
잠김 타일카테고리 · 「오늘의 질문에 답하면 목표가 생성돼요.」 · 자물쇠 표시목표 잠금 판정
완료 타일완료 표시. 문구는 그대로 읽을 수 있어야 함(취소선 없음)완료 토글
안내 타일(식이)후보가 없는 날 「오늘은 개인 식사 계획을 먼저 확인해 주세요」. 완료 버튼이 없고 n/3 분모에서 뺌식이 목표 생성 결과
안내 1회일부 목표를 완료한 뒤 답을 마쳐 대기 타일만 바뀌었을 때, 대기 타일 위에 「답변을 반영해 목표를 새로 추천했어요」를 1회 표시목표 기록 변경
홈과 생활 탭 › 목표 분석은 같은 타일 컴포넌트를 씀. 한쪽에서 완료하면 다른 쪽도 같은 상태임.
04

상태별 표시

영역상태무엇이 보이나예시
① 오늘의 질문진행 중현재 문항 하나. 답하지 않은 문항은 하루 동안 그대로 남음「오늘의 질문 · 2/4 · 점심은 언제쯤 드셨어요?」
저녁 식사 전 안내17~24시 「오늘 저녁」 질문 + 안내 문장. 답하기 전까지 회전 문항과 식이 목표 생성을 기다림「오늘 저녁은 평소만큼 드셨나요?」 아래 「오늘 저녁을 드신 뒤 답해주세요」
끼니 구간 넘어감미답 식이 문항의 끼니 이름만 새 구간으로 바뀜. 문항 수는 그대로아침에 「어제 저녁」 → 오후 1시 재진입 시 「오늘 점심」
모두 완료완료 카드「잘 했어요 👍 답변을 모두 완료했어요!」
답변 수정 뒤완료 카드 유지. 코칭 ②가 생성 중 → 결과로 다시 바뀜—
② 오늘의 코칭답변 전「먼저 오늘의 질문에 답하고, 나에게 맞는 코칭을 받아보세요.」 일부만 답한 상태도 같음—
생성 중마지막 답 직후부터 응답 도착까지, 최대 5초. 5초가 지나면 답변만으로 정할 수 있는 식이 기본 문구를 먼저 보여 주고 응답이 오면 조용히 바꿈5초 뒤 「다음 끼니는 거르지 말고 조금이라도 챙겨 먹기」 → 응답 도착 시 교체
결과핵심 행동 한 줄「점심 뒤 10분만 걸어 보세요」
저녁 결과17시 이후 생성이면 마무리형「오늘은 11시 전에 잠자리에 들어 보세요」
③ 오늘의 목표잠김식이는 항상 잠긴 채 시작. 수면은 어젯밤 수면 세션이 1개도 없으면 잠김. 활동은 걸음 기록이 1건이라도 있으면 개인 기록으로, 없어도(미연동) 안전한 기본 문구로 열림. 타일 3개가 모두 잠기지는 않음워치 없는 사용자: 식이 🔒 · 활동 열림 · 수면 🔒. 미연동: 활동 「점심 식후 10분 걷기」
기본카테고리 · 목표 문구「🚶 활동 · 6,500걸음 걷기」
완료완료 표시 + 문구 유지. 「n/3 완료」 갱신「1/3 완료 ›」
안내 상태(식이)안내 문구만. 완료 버튼 없음「오늘은 개인 식사 계획을 먼저 확인해 주세요」
목표 없는 날세 목표 모두 안 만들어졌으면 목표 분석의 이어가기 코멘트는 「생성된 목표가 없어요」—
공통건강 데이터 미연동세 영역 모두 정상 동작. 질문이 입력을 대신함. 빈 상태는 컨디션 · 건강 데이터 영역에만 둠—
공통오류 · 생성 실패5초 뒤 식이 기본 문구가 보이므로 빈 카드는 없음. 응답이 끝내 오지 않을 때의 재시도는 확인 필요—
05

동작

사용자가 하면화면은
선택지를 누르면고른 버튼만 강조하고 0.5초 뒤 다음 문항으로 자동 전환. 저장에 실패하면 선택 상태를 유지하고 재시도하며 다음으로 넘어가지 않음
식사 답을 누르면(어제 저녁 · 결식 제외)같은 카드의 글과 버튼이 시각 질문으로 바뀜. 새 화면은 없음
마지막 문항에 답하면① 완료 카드 ② 코칭 「생성 중」 → 결과 ③ 잠긴 타일이 열림. 기기 데이터로 이미 열린 타일은 그대로
「오늘 답변 모두 보기 ›」를 누르면답변 보기 화면. 답을 바꾸면 「답변을 다시 선택하면 코칭과 목표에 바로 반영돼요」. 식사 카드 아래 시각 답도 같은 버튼으로 다시 고를 수 있음
잠긴 타일을 누르면남은 질문으로 이동(질문 영역으로 스크롤하고 그 문항을 보여 줌). 생활 탭에서 눌렀으면 홈으로 이동
기본 타일을 누르면완료로 바뀌고 「n/3 완료」가 오름. 목표 분석의 연속일수 · 코멘트 · 최근 7일도 즉시 갱신. 타일을 길게 누르거나 상세에서 이유 한 줄을 짧게 볼 수 있음(목표 분석 탭에는 상시 표시)
완료 타일을 누르면완료 취소. 대기로 돌아가며 이후 답 수정 시 재생성 대상이 됨
「n/3 완료 ›」를 누르면생활 탭 › 목표 분석(오늘)
같은 날 다시 들어오면이미 만든 세트 · 코칭 · 목표를 그대로. 미답 식이 문항만 끼니 구간에 맞춰 갱신
낮 동안 기기 데이터가 늘면질문 · 코칭 · 목표는 그대로. 컨디션과 건강 데이터 값만 갱신
