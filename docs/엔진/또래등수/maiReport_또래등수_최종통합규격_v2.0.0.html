3기준표(경계값표)

서버 상주 테이블: 20_국민건강영양조사_2022-2024_백분위_키체중BMI허리.csv — 항목×성별×5세구간 104행, 행마다 p1~p99 경계값 99개. 버전 표기 knhanes-2022-2024.v1. 질병관리청 국민건강영양조사 원시자료(3개년 합산, 가중 백분위) 기반 실측치입니다.

전달본이 참조한 표(폐기)또래등수_경계값표_신체계측4항목_2024.csv — 국민건강보험공단 2024 건강검진통계연보 구간표 기반. 키·체중은 "평균+표준편차 가정"의 임시 추정치였음
통합본 채택(최종)국민건강영양조사 원시자료 기반 백분위표. 키·체중도 실측 분포로 계산된 확정치

4계산

STEP 1 · 내 행 찾기

bounds = [p1, p2, …, p99]   # 해당 항목·성별·연령구간 행, 오름차순

STEP 2 · k (내 값보다 작거나 같은 경계값 개수)

k = bisect_right(bounds, x)          # 0 ~ 99

STEP 3 · 경계 사이 보간 → 분포 위치 P

if k == 0:     P = 1
elif k >= 99:  P = 99
else:
    lo, hi = bounds[k-1], bounds[k]
    frac = 0 if hi == lo else (x - lo) / (hi - lo)
    P = k + frac
# P의 뜻: "나보다 값이 작은 사람이 100명 중 P명"

STEP 4 · 등수와 구간

rank = clamp(round(P), 1, 99)        # 화면의 "N등" — 방향 뒤집기 없음
band = ceil(rank / 20)               # 1~5, 사람 그림 위치
가장 중요한 정정 사항 — 방향 뒤집기 폐지.
PCT-001·PCT-002는 항목마다 better: low|high를 두고, 키처럼 "높을수록 좋은" 항목은 rank = 100 − P로 뒤집었습니다(키 180cm → 1등).
통합본은 이를 폐지합니다: 네 항목 모두 같은 방향, 1등 = 값이 가장 작음. 키가 커도 작아도 "좋고 나쁨"이 아니라 그냥 위치이기 때문입니다. 통합본 기준이면 키 180cm(여/45세)는 1등이 아니라 99등 근처가 나와야 합니다.

health = warn  if  BMI < 18.5  or  BMI >= 25
health = warn  if  허리둘레 >= 85 (여)  or  >= 90 (남)
