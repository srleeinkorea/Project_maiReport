# 또래 등수 산식 · 개발/디자인 전달본

대상: 신체계측 4항목(키 · 체중 · BMI · 허리둘레). 화면 문구 "내 또래 100명 중 N등".
버전: 2026-09-14 · 참조표 2024 건강검진통계연보 기준

---

## 1. 입력

| 값 | 어디서 | 비고 |
|---|---|---|
| 성별 | 프로필 | 남 / 여. 없으면 등수 계산 안 함 |
| 나이 | 검진일 기준 만 나이 | 5세 연령대로 변환: 19세 이하, 20~24, 25~29, … , 80~84, 85 이상 (15구간) |
| 키 cm, 체중 kg, 허리둘레 cm | 검진 결과지 | 소수 1자리 |
| BMI | 결과지 값. 없으면 계산 | **BMI = 체중(kg) ÷ 키(m)²**, 소수 1자리 반올림 |

## 2. 참조표

파일 `또래등수_경계값표_신체계측4항목_2024.csv` (12,000행)
열: `항목, 단위, 성별, 연령대, 백분위(1~100), 값`

서버 적재 형태: `T[항목][성별][연령대][p] = 값` (p = 1 … 100)
뜻: 그 집단에서 값이 작은 쪽부터 p% 되는 지점의 값. 예 `T[BMI][여][40~44세][80] = 26.6`

- BMI · 허리둘레: 공단 통계연보 실측 분포에서 계산 (확정)
- 키 · 체중: 평균 + 표준편차 가정 추정값 (임시). 국민건강영양조사 원시자료가 확보되면 이 두 항목 행만 교체
- 표는 연 1회 갱신, 요약 저장 시 표 버전(연도)을 함께 저장

## 3. 산식

사용자 값 v, 표 `T[항목][성별][연령대]`의 100개 값에 대해

```
a = 값이 v보다 작은 개수
b = 값이 v와 같은 개수
P = a + 0.5 × b                 (0 ~ 100)
rank = 올림(P);  P가 0이면 rank = 1     → 1 ~ 100  ("N등")
band = 올림(rank ÷ 20)                   → 1 ~ 5   (사람 그림 위치)
```

- 1등 = 값이 가장 작음, 100등 = 가장 큼. 네 항목 모두 같은 방향
- 등수는 위치일 뿐, 좋고 나쁨이 아님

## 4. 건강 기준 (등수와 별개)

```
health = warn  if  BMI ≥ 25
health = warn  if  허리둘레 ≥ 85 (여) / ≥ 90 (남)
그 외 ok. 키·체중은 항상 ok
```
근거: 국민건강보험공단 판정기준(비만).

## 5. 계산 예 (여성 42세)

| 항목 | 값 | a | b | P = a + 0.5b | rank = 올림(P) | band |
|---|---|---|---|---|---|---|
| 키 | 164.2 cm | 72 | 1 | 72.5 | 73등 | 4 |
| 체중 | 69.3 kg | 84 | 0 | 84 | 84등 | 5 |
| BMI | 25.7 | 76 | 0 | 76 | 76등 | 4 |
| 허리둘레 | 86.0 cm | 86 | 0 | 86 | 86등 | 5 |

(여성 40~44세 표로 실제 계산한 값. 키·체중은 추정 표라 원시자료 교체 시 바뀔 수 있음)

## 6. 화면 매핑

| 출력 | 화면 요소 | 규칙 |
|---|---|---|
| value + unit | 측정값 | 소수 1자리 |
| rank | "내 또래 100명 중 **N등**" | 항목 색으로 강조 |
| band | 사람 그림 5개 중 진하게 칠할 위치, "나" 말풍선, 등수 구간 라벨 강조 | 구간 라벨: 1~20등 · 21~40등 · 41~60등 · 61~80등 · 81~100등 |
| band → 문구 | 상태 배지 | 아래 표 |
| health | 배지 톤 | warn = 주의 톤, 그 외 band 2~4 안정 톤 · band 1·5 중립 톤 |

배지 문구

| band | 키 | 체중 | BMI | 허리둘레 |
|---|---|---|---|---|
| 1 | 작은 편이에요 | 가벼운 편이에요 | 낮은 편이에요 | 가는 편이에요 |
| 2 | 조금 작은 편이에요 | 조금 가벼운 편이에요 | 조금 낮은 편이에요 | 조금 가는 편이에요 |
| 3 | 평균적인 편이에요 | 평균적인 편이에요 | 평균적인 편이에요 | 평균적인 편이에요 |
| 4 | 조금 큰 편이에요 | 조금 무거운 편이에요 | 조금 높은 편이에요 | 조금 굵은 편이에요 |
| 5 | 큰 편이에요 | 무거운 편이에요 | 높은 편이에요 | 굵은 편이에요 |

## 7. 예외

| 상황 | 처리 |
|---|---|
| 성별 없음 | rank = null |
| 항목 값 없음 | 그 카드 제거, 순서 당김 |
| rank = null | 등수 "—", 사람 그림 전부 연한 톤, "나" 없음, 안내 문구 "또래 비교 데이터를 준비 중이에요" |
| 값이 표 범위 밖 | 그대로 계산 (a = 0 → 1등, a = 100 → 100등) |
| 결과지 BMI와 계산 BMI가 0.2 이상 차이 | 결과지 값 사용, 로그 기록 |

## 8. 서버 응답

```json
{ "key": "bmi", "value": 25.7, "unit": "kg/m²", "rank": 76, "band": 4, "health": "warn" }
```
+ `tableVersion: "2024"`, `computedAt`
