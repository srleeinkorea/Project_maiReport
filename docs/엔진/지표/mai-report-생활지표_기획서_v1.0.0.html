1.1 목적

마이리포트 v2는 검진·진료 이력 열람에 AI 웰니스 코칭을 더함. 코칭이 설득력을 가지려면 "지금 내 생활이 어떤지"를 사용자가 바로 확인할 수 있는 근거 지표가 필요하며, 세 지표가 그 역할을 함. 세 지표는 사용자를 평가하는 점수가 아니라, 생활 패턴을 이해하고 조절할 지점을 보여주는 해석 지표임.

1.2 왜 3개이며 왜 합치지 않는가

세 지표는 같은 기록(걸음·수면·운동·식사 답변)을 다른 시간 범위와 다른 질문으로 본 결과임. 하나로 합치면 "오늘 하루 구성이 아쉬워서"인지 "기회에 움직이지 않아서"인지 "요즘 흐름이 꺾여서"인지 구분할 수 없음.

  • 예: 잠은 6시간뿐이었지만 식후마다 걸었다면 → 짜임새 있는 하루는 보통, 행동 기회 대응은 높음.
  • 예: 오늘은 잘 짜인 하루였지만 지난주보다 걸음과 운동이 줄었다면 → 짜임새 있는 하루는 높음, 생활 변화 추이는 낮음.

1.3 공통 설계 원칙

P1 · 식이 답변은 I1에만 직접 반영

오늘의 질문 중 식이 답변(식사 구성·부담·식사 시각)은 I1 식사 균형과 식사–수면 간격에 점수로 들어감. 식사 시각은 I3 식사 시각 규칙성에도 씀. 그 밖의 질문 답변은 이유 설명·코칭 문구 선택에만 씀.

P2 · 디바이스 데이터가 기본 축

워치가 있으면 더 자세히, 없으면 걸음 합계로 계산함. 움직임량은 걸음 · 빠르게 걸은 시간 · 운동 시간 중 가장 좋은 하나만 쓰므로 워치가 없어도 만점에 닿을 수 있음.

P3 · 기록 행위는 점수가 아님

식사를 기록했다는 사실로 점수를 올리지 않음. 점수에 들어가는 것은 답변의 내용(무엇을 얼마나 먹었나, 몇 시에 먹었나)임.

P4 · 숫자는 내부 계산용

0~100 내부 점수는 구간 판정에만 쓰고, 화면에는 상태 라벨과 흐름만 보여줌. 건강 평가·성과 점수처럼 쓰지 않음.

P5 · 종합 점수 없음

세 지표를 합산·평균하지 않음. 홈 요약 문장도 대표 지표 1개 또는 주의 구간 지표만 언급함.

P6 · 결측은 0이 아님

미착용·미수집·권한 미허용은 0점으로 채우지 않음. 빠진 항목은 계산에서 빼고, I1은 충족률로 점수 신뢰도를 반영함. 모든 근거가 없으면 「관찰 중」.

P7 · 비교는 같은 조건끼리

I3는 최근·직전 두 기간에 같은 항목이 각각 3일 이상 있을 때만 비교함. 한쪽 기간만 기록이 크게 줄면 그 항목은 비교에서 뺌.

P8 · 규칙 기반

학습 모델이 아니라 미리 정한 규칙과 기준값으로 동작함. 실사용 데이터는 이상 반응 확인·기준값 보정에만 씀.

2.3 날짜는 두 가지임 — 실제 날짜와 세션 날짜

성격이 다른 두 날짜를 하나로 묶지 않음. 서로 다른 문제를 풀기 때문임. 용어는 「식이 질문·목표 상세 기획」 ②와 같음.

오늘 하루를 네 조각으로 나눠 봄 — 충분히 잤나 · 균형 있게 먹었나 · 충분히 움직였나 · 식사와 잠 사이 간격이 알맞았나. 한 조각만 좋아서는 높게 나오지 않고, 여러 조각이 고르게 채워질수록 높아짐. 기록이 빠진 조각이 많으면 그만큼 점수를 낮춰 "근거가 적은 날"을 반영함.
