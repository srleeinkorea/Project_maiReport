최근 28일 동안 생활이 어느 방향으로 변했는가?

4주 추세 · 하루 마감 후 한 번 갱신

1.1 목적

마이리포트 v2는 검진·진료 이력 열람에 AI 웰니스 코칭을 더함. 코칭이 설득력을 가지려면 "지금 내 생활이 어떤지"를 사용자가 바로 확인할 수 있는 근거 지표가 필요하며, 세 지표가 그 역할을 함. 세 지표는 사용자를 평가하는 점수가 아니라, 생활 패턴을 이해하고 조절할 지점을 보여주는 해석 지표임. 건강 상태나 질환 위험을 진단하지 않음.

1.2 왜 3개이며 왜 합치지 않는가

세 지표는 같은 기록(걸음·수면·운동·식사 답변·행동 응답)을 다른 시간 범위와 다른 질문으로 본 결과임. 하나로 합치면 "오늘 기본 생활이 비어서"인지 "기회에 움직이지 않아서"인지 "요즘 흐름이 꺾여서"인지 구분할 수 없음.

  • 예: 잠은 6시간뿐이었지만 식후마다 걸었다면 → 몸잠밥 지수는 중간, 내실천 지수는 높음.
  • 예: 오늘은 이상적인 하루였지만 지난 몇 주보다 걸음과 운동이 줄고 있다면 → 몸잠밥 지수는 높음, 일상결 지수는 주춤기.

1.3 공통 설계 원칙

P1 · 미관측 ≠ 0

자료 없음 · 기기 미착용 · 질문 무응답 · 해당 없음 · 실제 0을 서로 구분함. 자료가 없어 계산하지 못한 값을 0점으로 바꾸지 않음.

P2 · 비중을 옮기지 않음

자료가 없는 영역 · 항목의 비중을 남은 영역에 넘기지 않음. 그래서 일부 자료만 있는 날은 총점만 보고 판단하지 않고 「일부 기록」으로 따로 표시함.

P3 · 일부 자료는 낮은 단계가 아님

일부 기록 · 준비 중 · 확인 불가 상태에는 3단계 라벨을 붙이지 않음. 낮은 단계로 표시하지 않음.

P4 · 기록 행위는 점수가 아님

기록했다는 사실로 점수를 올리지 않음. 점수에 들어가는 것은 답변의 내용(식이 질문 답, 식사량, 식사 시각)과 확인된 행동임.

P5 · 종합 점수 없음

세 지표를 합산·평균하지 않음. 같은 활동을 답변과 기기가 함께 확인해도 두 번 더하지 않음.

P6 · 진단 아님

의학적 건강 점수가 아니며 개인의 능력이나 운동 품질을 평가하지 않음. 높은 점수도 건강이 좋아졌다는 진단이 아님.

2.3 날짜는 두 가지임 — 실제 날짜와 세션 날짜

성격이 다른 두 날짜를 하나로 묶지 않음. 서로 다른 문제를 풀기 때문임. 용어는 「식이 질문·목표 상세 기획」 ②와 같음.

날짜경계적용 대상이유
실제 날짜자정걸음 · 활동 시간 · 운동 세션 등 기기에서 받는 모든 값의 날짜 귀속. 세 지표의 기준일. 끼니 이름을 붙일 때도 이 날짜를 씀애플 건강 · 삼성 헬스가 자정 기준으로 일별 값을 줌. 다른 경계로 재집계하면 같은 날 걸음수가 기기 앱과 다르게 보임

I1

몸잠밥 지수오늘의 상태 · 산식 v0.25 · 사용 승인

오늘의 수면 · 움직임 · 식사가 권장 행동에 얼마나 가까운지 세 영역을 같은 비중으로 보여줌

정의 · 핵심 관점

세 영역(몸 = 움직임, 잠 = 수면, 밥 = 식사)이 각각 최대 33.33점임. 자료가 없는 영역의 점수를 다른 영역에 넘기지 않으므로, 총점만 보고 세 영역이 모두 충분하다고 판단하면 안 됨. 그래서 세 영역 자료가 다 모이기 전에는 단계 라벨을 붙이지 않고 「일부 기록」으로 표시함.

8공통 데이터 처리 흐름

기록의 날짜와 출처 확인 → 중복 정리 → 공통 형식 → 지표 계산 → 화면 단계

01
날짜 · 출처 확인사용자 지역 날짜로 묶고, 어느 서비스에서 어떤 항목 · 단위로 왔는지 보관
02
중복 정리같은 기록은 하나만. 여러 앱이 같은 활동 시간을 기록하면 겹친 구간 정리
03
공통 형식단위 · 시각 통일. 자료 없음 · 미착용 · 무응답 · 해당 없음 · 실제 0 구분
04
지표 계산지표별 기록만 넣어 점수와 계산 가능 상태를 함께 만듦
05
화면 단계점수와 자료 상태로 단계 결정. 일부 기록 · 준비 중은 낮은 단계로 표시하지 않음
공통 안전장치 — 계산하지 못한 값을 0점으로 바꾸지 않음 · 비중을 옮기지 않음 · 세 지표 합산 금지 · 같은 활동 이중 가산 금지 · 소모 열량만으로 운동 세션을 만들지 않음 · 휴대폰을 안 쓴 시간을 수면으로 보지 않음

산출 주기 · 저장

  • 몸잠밥 · 내실천은 낮 동안 기록이 들어올 때마다 다시 계산함(잠정값). 내실천은 하루 안에서 내려가지 않음.
  • 일상결은 하루 동안 전날 마감값을 유지하고, 하루 마감 후 한 번 갱신함.
  • 산출물에 점수 · 계산 가능 상태 · 영역/묶음/항목별 점수 · 들어온 자료 범위 · 산식 버전을 함께 남김.
  • 구간 판정은 지표 엔진이 상태 키로 내려주는 것을 기본으로 함.
