끼니 추천 문구 89개 정리안

작성일 2026-10-19대상 목표문구 DIET-P-0412~0500 (아침추천 · 저녁추천 · 샐러드)기준 데이터 계약 v1.4.0 · 서버 1.1.1
문제
끼니 추천 문구 89개는 「아침추천: 연어/두부」, 「저녁추천: 고등어/갈치」, 「참치샐러드+1/2소스」처럼 타일에 특정 음식 이름이 들어감. 52개는 성격 칸이 비어 있어 신장질환 금지 규칙(늘리기 · 줄이기 · 수분)에 걸리지 않음. 그래서 신장질환 사용자에게 시금치 · 브로콜리 · 고등어 같은 문구가 나갈 수 있음.
왜 지금
문구 반복 방지 조회 기간을 365일로 늘리면, 지금은 목록 뒤쪽이라 거의 안 나오던 이 문구들이 자주 나옴. 일반 사용자 기준 1년에 76종, 신장질환 사용자도 45종이 나옴.
정리안
같은 뜻의 문구를 24개 묶음으로 모음. 묶음마다 대표 문구 하나만 음식 종류로 다시 써서 사용, 나머지 65개는 보류. 단백질 · 잡곡 · 생선을 곁들이라는 문구는 성격을 늘리기로 맞춰 신장질환 사용자에게 빼고, 채소 반찬은 칼륨이 적은 채소만 예로 들어 신장질환 사용자에게도 나가게 함.
