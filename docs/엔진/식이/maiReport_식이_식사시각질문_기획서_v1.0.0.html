한눈에 보기

이 문서가 다루는 것매일 나가는 식사 질문(「{끼니}은 평소만큼 드셨나요?」)에 답하면 같은 자리에서 「{끼니}은 언제쯤 드셨어요?」를 한 번 더 물어 식사 시각을 받는 단계
가장 중요한 결정질문 1개로 센다(식이 최대 3문항 · 전체 최대 5문항). 버튼 3개는 1시간 간격이고 답한 시각에서 거꾸로 센다. 어제 저녁과 「못 먹거나 거름」에는 묻지 않는다
아직 정해지지 않은 것걸음 기록만으로 「식후에 걸었다」고 판정해도 되는지(계산식 전달 문서 확인 대기). 그 밖의 설계·데이터·구현 기준은 모두 정해져 반영됨

1. 배경과 목표

자기돌봄 지표와 일상안정 지표에는 「식후에 움직였는지」를 보는 칸이 있는데, 앱은 식사 시각을 모른다. 그래서 이 칸이 늘 비어 있고, 식후에 걷지 않은 날도 걸은 날과 같은 점수가 나왔다(하루 8,000보 예시에서 매일 72점).

식사 질문 바로 뒤에 시각을 한 번 더 물으면 이 칸이 채워진다. 같은 예시에서 식후에 걸은 날은 81점, 안 걸은 날은 61점으로 갈라져 실제 생활이 점수에 드러난다. 새 화면을 만들지 않고 이미 있는 질문 카드에서 글과 버튼만 바꾸는 방식이라 사용자 부담은 버튼 한 번이다.

2. 대상과 상황

인물상황바라는 것
지영 씨, 44세 사무직오후 1시 20분 점심을 먹고 자리에 앉아 앱을 연다. 「오늘 점심은 평소만큼 드셨나요?」에 「충분히 먹음」을 누른다길게 입력하지 않고 버튼 한 번으로 끝내고 싶다. 「오후 12:20 이후」를 누르면 끝
민수 씨, 58세 자영업밤 11시 30분에야 앱을 연다. 저녁은 7시 20분쯤 먹었다너무 세밀하게 묻지 않았으면 한다. 버튼은 「오후 8:00 이후 / 7:00~8:00 / 7:00 이전」이라 「7:00~8:00」 하나만 누르면 된다
아침 8시에 앱을 연 누구나이 시간에는 「어제 저녁」을 묻는다어제 일을 시각까지 떠올리게 하지 않는다. 시각 단계가 아예 나오지 않는다

3. 범위

이번에 하는 것하지 않는 것
  • 식사 질문 뒤 같은 자리에서 시각 단계 1문항(점심·저녁 「언제쯤」, 아침 「몇 시쯤」)
  • 버튼 3개 생성 규칙(1시간 간격 · 10분 내림 · 끼니별 멈춤 시각 · 아침 고정)
  • 답으로 식사 시각을 추정해 저장(건강 앱 → 걸음 단서 → 평소 시각 → 범위 가운데)
  • 「오늘 답변 모두 보기」에서 답 수정
  • 데이터 계약 · 참조 구현 · 프로토타입 · 시뮬레이터 반영
  • 식후에 걸었는지 판정하는 지표 계산 자체(계산식 전달 문서 쪽)
  • 식후 걷기 확인 알림
  • 시각 단계의 「건너뛰기」 버튼
  • 야식 질문(식사 시각 축, DIET-Q-04)의 변경
  • 식사 시각으로 좋음·나쁨 등급이나 코칭 문구를 만드는 일

4. 동작 방식

오후 1시 20분에 앱을 열어 점심 질문에 답하는 경우다. 세 화면 모두 홈의 같은 질문 카드이고, 글과 버튼만 바뀐다.

지금과 같은 회전 질문. 번호가 하나 밀림
  1. 식사 질문에 답한다. 「충분히 먹음」 또는 「적게 · 몇 입만」이면 다음으로 간다. 「못 먹거나 거름」이면 먹은 시각이 없을 수 있어 시각 단계와 회전 질문 없이 바로 다음 질문(2/3)으로 넘어간다.
  2. 같은 카드가 시각 질문으로 바뀐다. 점심·저녁은 「{끼니}은 언제쯤 드셨어요?」, 아침은 「아침은 몇 시쯤 드셨어요?」. 진행 번호는 1개 늘어난다(1/5 → 2/5).
  3. 버튼 3개가 그 자리에서 만들어진다. 점심·저녁은 답한 시각을 10분 단위로 내린 뒤 1시간씩 거꾸로 센 구간이다. 오전·오후는 위에 작게, 시각은 크게, 아래에 「1시간 이내 · 1~2시간 전 · 그보다 전」을 작게 쓴다. 아침은 늘 「7시 이전 / 7시~8시 / 8시 이후」다.
  4. 버튼을 누르면 0.5초 뒤 다음 질문으로 넘어간다. 건너뛰기는 없다. 답과 함께 사용자가 본 버튼의 시각 구간을 저장한다.
  5. 서버가 식사 시각을 추정한다. 건강 앱에 식사 기록이 있으면 그 시각(이때는 시각 단계도 묻지 않음). 없으면 고른 구간 안에 걷다가 15분 넘게 멈춘 걸음 단서가 하나뿐이면 그 시각, 구간이 2시간을 넘거나 비면 「모름」, 지난 2주 평소 식사 시각이 구간 안이면 그 시각, 아니면 구간 가운데. 「모름」은 계산에서 빠질 뿐 점수를 깎지 않는다.
  6. 「오늘 답변 모두 보기」에서 식사 카드 아래에 시각 질문이 같이 보이고, 답할 때 본 버튼 그대로 다시 고를 수 있다.

5. 규칙과 예외

규칙예시예외
시각 단계는 식사 답이 「충분히 먹음」「적게 · 몇 입만」일 때, 끼니가 오늘 아침·점심·저녁일 때만 나온다오후 2시 10분 점심 「적게 · 몇 입만」 → 시각 단계 나옴「못 먹거나 거름」 · 어제 저녁(자정~오전 10시) · 건강 앱에 그 끼니 식사 기록이 있으면 묻지 않고 조건상 생략으로 기록
질문 1개로 센다. 진행 번호도 따로 센다식사 1/5 → 시각 2/5 → 채소 3/5시각을 묻지 않는 날은 1/4부터. 「못 먹거나 거름」이면 시각·회전이 빠져 다음이 2/3
점심·저녁 버튼은 답한 시각을 10분 단위로 내린 뒤 1시간씩 거꾸로 센 3구간오후 1:47 → 1:40 기준 → 12:40 이후 / 11:40~12:40 / 11:40 이전반올림하지 않는다. 반올림하면 아직 오지 않은 시각이 버튼에 들어간다
끼니별 멈춤 시각(점심 오후 2시 · 저녁 오후 9시)을 넘으면 그 시각에서 멈춘다오후 4:30 점심 → 오후 1:00 이후 / 12:00~1:00 / 12:00 이전멈춘 동안은 아래 작은 글씨를 뺀다

아침은 7시 · 8시 정각으로 고정오전 10:20에도 11:40에도 같은 버튼출시 뒤 「8시 이후」가 30%를 넘으면 경계를 다시 본다
시각 표기는 「오후 1:10」처럼 오전·오후를 붙인다앞뒤가 다르면 「오전~오후 11:20~12:20」아침 버튼은 「7시 이전」처럼 시만 쓴다. 시각 단계 버튼은 답 버튼 5~7자 규칙의 예외
점수·등급·축 상태를 만들지 않는다어떤 버튼을 눌러도 식이 축 판정과 목표 선정은 그대로식사 시각 응답은 사실 빈도만 저장한다는 기존 원칙 그대로
시각 단계 중 앱을 나갔다 오면 식사 답은 두고 버튼은 다시 들어온 시각으로 새로 만든다오후 1:20에 식사 답 → 나감 → 오후 3시 복귀 → 「오후 1:00 이후 / …」로 멈춘 버튼—
