01

한눈에 보기

이 문서가 다루는 것

  • 식사 질문에 답한 뒤, 같은 카드에서 한 번 더 묻는 질문
    「{끼니}은 언제쯤 드셨어요?」
  • 화면 · 규칙 · 데이터 · 들어 있는 자리

가장 중요한 결정

  • 질문 1개로 셈
    식이 최대 3문항, 전체 최대 5~6문항
  • 선택지는 3개
    점심 · 저녁은 「1시간 이내 / 1~2시간 전 / 그보다 전」
    답하는 시각을 기준으로 1시간씩 거슬러 셈
    예) 오후 1:20에 답한 「1시간 이내」 = 오후 12:20 이후, 「1~2시간 전」 = 11:20~12:20
    아침은 「7시 이전 / 7시~8시 / 8시 이후」, 저녁을 밤 9시 뒤에 답할 때와 어제 저녁은 「7시 이전 / 7시~9시 / 9시 이후」로 고정
  • 늦게 답해도 고를 칸이 있게
    점심은 오후 2시가 지나서 답해도 2시에 답한 것과 같은 선택지를 보여 줌
    예) 오후 4:30 점심 → 「오후 1:00 이후 / 12:00~1:00 / 12:00 이전」
    저녁은 밤 9시가 지나서 답하면 「7시 이전 / 7시~9시 / 9시 이후」로 바꿔 물음
    예) 밤 11:30 저녁 → 5시에 먹은 사람도 10시에 먹은 사람도 고를 수 있음
  • 묻지 않는 경우
    「못 먹거나 거름」을 골랐을 때
  • 어제 저녁도 물음
    선택지는 「7시 이전 / 7시~9시 / 9시 이후」 고정
    일상안정이 최근 7일의 식후 행동을 합산해 어제 값도 쓰이기 때문
  • 평가하지 않음
    언제 먹었는지를 잘했다 · 못했다로 매기지 않음
    어떤 선택지를 골라도 식이 점수 · 오늘의 목표는 그대로
    답은 「밥 먹고 움직였는지」를 보는 데만 씀

아직 정해지지 않은 것

  • 없음. 설계 · 데이터 계약 · 구현 기준 모두 정해져 있음
  • 임시값(5분 · 300보 · 15분 · 2주 등)은 출시 뒤 실제 데이터로 고침

용어 풀이

말뜻
식사 질문매일 나가는 「{끼니}은 평소만큼 드셨나요?」. 답은 「충분히 먹음 / 적게 · 몇 입만 / 못 먹거나 거름」
시각 단계식사 질문에 답한 바로 뒤, 같은 카드에서 「언제쯤 드셨어요?」를 묻는 것
회전 질문채소 · 국물 · 단 간식처럼 날마다 바뀌는 식이 질문
선택지 상한 시각점심 오후 2시, 저녁 오후 9시.
점심은 이 시각이 지나서 답해도 2시에 답한 것과 같은 선택지를 보여 줌
예) 오후 4:30에 답해도 「1:00 이후 / 12:00~1:00 / 12:00 이전」
저녁은 이 시각이 지나서 답하면 고정 선택지 「7시 이전 / 7시~9시 / 9시 이후」로 바꿔 물음
선택지 하한 시각선택지가 이 시각보다 이르게 내려가지 않음. 점심 12시, 저녁 4시.
예) 오후 12:20에 답하면 「12:00 이후 / 11:00~12:00 / 11:00 이전」
식후 행동밥 먹고 30분 안에 걸었는지. 자기돌봄 · 일상안정 지표에 들어감(생활여유에는 없음)
걸음 단서걸음 기록에서 걷다가 15분 넘게 멈춘 자리. 식당에 가서 앉아 먹은 모습으로 봄
평소 시각지난 2주 동안 같은 끼니를 먹은 시각의 가운데 값
모름식사 시각을 정할 수 없는 경우. 계산에서 빠질 뿐 점수를 깎지 않음
모의실제 사용자가 아직 없어 가상 사용자로 계산한 결과
02

배경과 목표

구분내용
지금 문제자기돌봄 · 일상안정 지표에 「밥 먹고 움직였는지」 칸이 있음. 앱이 밥 먹은 시각을 몰라 이 칸이 늘 비어 있음. 하루 8,000보 예시에서 걸은 날도 안 걸은 날도 72점
목표식사 질문 뒤에 시각을 한 번 더 받아 이 항목을 채움. 같은 예시에서 걸은 날 81점, 안 걸은 날 61점으로 갈림
사용자 부담새 화면 없음. 기존 카드의 글과 선택지만 바뀜. 선택지 1회
Fig 1 · 문제 → 원인 → 이 기획
해석: 공란의 원인은 입력이 없어서임. 새 화면 없이 질문 1개를 이어 물으면 풀림. 등급 오류일은 약 3분의 1로 줄어듦(모의).

대상과 상황

인물상황실제 동작

민수 씨 · 58세 자영업밤 11시 30분에 앱을 엶. 저녁은 7시 20분쯤 먹음밤 9시가 지났으므로 선택지는 「7시 이전 / 7시~9시 / 9시 이후」. 「7시~9시」를 고름
아침 8시에 앱을 연 사용자이 시간에는 「어제 저녁」을 물음「어제 저녁은 몇 시쯤 드셨어요?」가 이어짐. 하루 지난 끼니라 선택지는 「7시 이전 / 7시~9시 / 9시 이후」로 고정. 어젯밤에 이미 답했으면 다시 묻지 않음
04

범위

이번에 하는 것

  • 식사 질문 뒤 같은 자리에서 시각 단계 1문항(점심 · 저녁 「언제쯤」, 아침 「몇 시쯤」)
  • 선택지 3개 만드는 규칙: 글자는 「1시간 이내 / 1~2시간 전 / 그보다 전」. 각 선택지의 시각 구간은 답한 시각을 10분 단위로 내린 뒤 1시간씩 거꾸로 센 구간 3개(화면에는 보이지 않고 저장에만 씀). 점심은 오후 2시가 지나서 답해도 2시에 답한 것과 같은 선택지(선택지 상한 시각), 점심 12시 · 저녁 4시 아래로는 내려가지 않음(선택지 하한 시각). 상한 · 하한에 걸린 동안은 시각 글자로 보여 줌.
    아침은 「7시 이전 / 7시~8시 / 8시 이후」, 저녁을 밤 9시 뒤에 답할 때와 어제 저녁은 「7시 이전 / 7시~9시 / 9시 이후」 고정
  • 답으로 식사 시각 추정 · 저장
  • 식후에 걸었는지 걸음 기록으로 판정해 완료 · 미완료 · 모름으로 저장
  • 「오늘 답변 모두 보기」에서 답 수정

하지 않는 것

  • 사용자에게 식사 시각을 숫자로 직접 입력하게 하는 것
  • 식사 시각으로 좋음 · 나쁨 등급이나 코칭 문구를 만드는 것
  • 판정 결과로 점수를 내는 지표 계산(계산식 전달 문서 영역)

규칙과 예외

규칙예시예외 · 비고
식사 답이 「충분히 먹음」「적게 · 몇 입만」일 때만 나옴오후 2시 10분 점심 「적게 · 몇 입만」 → 나옴「못 먹거나 거름」 · 건강 앱에 그 끼니 식사 기록이 있으면 묻지 않음. 「왜 안 물었는지」만 기록
어제 저녁(자정~오전 10시)에도 물음. 선택지는 「7시 이전 / 7시~9시 / 9시 이후」 고정아침 8:20 → 「어제 저녁은 몇 시쯤 드셨어요?」 · 「7시~9시」일상안정이 최근 7일의 식후 행동을 합산해 어제 값도 쓰이기 때문. 어젯밤에 이미 답했으면 다시 묻지 않음
질문 1개로 셈. 진행 번호도 따로 셈식사 1/5 → 시각 2/5 → 채소 3/5「못 먹거나 거름」이면 시각 · 회전이 빠져 다음이 2/3
점심 · 저녁 선택지는 「1시간 이내 / 1~2시간 전 / 그보다 전」. 각 선택지의 시각 구간은 답한 시각을 10분 단위로 내린 뒤 1시간씩 거꾸로 센 3구간(저장용)오후 1:47 → 1:40 기준 → 12:40 이후 / 11:40~12:40 / 11:40 이전반올림하지 않음. 반올림하면 아직 안 온 시각이 선택지에 들어감
