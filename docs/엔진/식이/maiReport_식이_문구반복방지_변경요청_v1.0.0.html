2변경 요청 — 문구 반복 방지 조회 기간 30일 → 365일

지금 생기는 일

지금 규칙은 「최근 30일에 안 나온 문구를 문구 번호 순으로 먼저」. 30일이 지난 문구는 한 번도 안 나온 문구와 같은 줄에 서고, 번호가 앞이라 다시 뽑힘. 그래서 목록 앞쪽 몇 개만 계속 돎.

예: 일반 사용자, 매일 13시 접속, 단 음료 입문 단계. 쓸 수 있는 문구는 11개.

3확인 요청

번호내용왜
3-1데이터 버전이 바뀌어도 문구 사용 이력은 이어 볼 수 있는지.규칙 문서 11.1은 버전이 바뀌면 문구 사용 이력도 새로 시작한다고 적음. 그러면 새 버전을 올릴 때마다 모든 사용자가 목록 첫 문구부터 다시 봄. 문구 내용이 같은 줄은 이력을 이어 주는 것을 희망함.
3-2규칙 문서 8.3 문구 고르기 설명 고치기.지금 「최근 30일 안 쓴 문구 → 오래전에 쓴 문구 → 데이터 순서」로 적혀 있어 「한 번도 안 쓴 문구가 먼저」로 읽힘. 실제 동작은 조회 기간 밖 문구와 안 쓴 문구를 같이 놓고 데이터 순서로 고름. 정확히 30일 전에 쓴 문구도 「최근」으로 봄.
3-3규칙 문서 예시를 1.1.1 기준으로 고치기.예시는 1.0.4 기준. 「국 대신 나물 반찬」은 1.1.1에서 채소 기본 단계로 옮겨짐. 새벽 문구 설명도 다름(1.1.1은 새벽 3시에 「내일 채소 꺼내 두기」가 나옴).
