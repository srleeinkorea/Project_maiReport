끼니별 식사 시각 질문

매일 나가는 식사 질문 바로 뒤에 「언제쯤 드셨어요?」 질문을 하나 더해 식사 시각을 받음. 받은 시각으로 「식후에 움직였는지」를 볼 수 있게 되어 자기돌봄과 일상안정 지표가 더 정확해짐.

질문 1개 추가식이 최대 3문항, 전체 최대 5~6문항. 시각을 묻지 않는 날은 지금처럼 4문항임.
선택지는 「1시간 이내 / 1~2시간 전 / 그보다 전」실제 시각을 크게 보여 줘서 몇 시인지 바로 고름.
모르면 「모름」계산에서 빠질 뿐 점수를 깎지 않음.

화면 흐름

오후 1:20에 앱을 열어 점심 질문에 「충분히 먹음」를 누른 경우임. 시각 질문도 1개로 세어 번호가 1/5 → 2/5 → 3/5로 이어짐.

  • 새 화면은 없음. 식사 질문에 답하면 같은 자리의 글과 선택지가 시각 질문으로 바뀜. 질문 수와 번호에서는 1개를 더한 것으로 세요.
  • 건너뛰기 버튼은 없음. 다른 식이 질문처럼 셋 중 하나를 골라야 다음 질문으로 넘어감.
  • 「못 먹거나 거름」에는 묻지 않음. 먹은 시각이 없을 수 있어서 바로 다음 질문으로 넘어감.
  • 잘못 골랐다면 「오늘 답변 모두 보기」에서 다시 고를 수 있음.
  • 건강 앱에 식사 기록이 있으면 그 시각을 쓰고 이 단계는 건너뜀.
  • 선택지 시각은 10분 단위로 내림함. 오후 1:47에 답하면 오후 1:40 기준임.

끼니별로 무엇을, 어떻게 묻나

어떤 끼니를 물을지는 지금처럼 앱에 들어온 시각으로 정함. 선택지는 1시간 간격이고, 답한 시각에서 거꾸로 세다가 끼니마다 정한 선택지 상한 시각(아침 9시 · 점심 오후 2시 · 저녁 오후 9시)을 넘으면 그 시각에 답한 것과 같은 선택지를 보여 줌. 늦게 답해도 선택지가 끼니 시간 안에 머물게 하려는 것임.

추정 시각을 정하는 순서

세 끼 모두 같은 순서를 따름. 위에서부터 먼저 맞는 것을 씀.

1단계

고른 선택지로 범위 정하기

예) 오후 2:10에 「오후 12:00~오전 1:00」을 고르면 점심은 이 1시간 안에 있었다고 봄. 끼니 시작 기본값(아침 6시 · 점심 11시 · 저녁 4시)보다 이른 부분은 잘라 냄.

2단계

범위 안에서 시각 고르기

  1. 걸음 기록에서 걷다가 15분 넘게 멈춘 곳이 한 번만 있으면 그 시각. 식당까지 걸어가 앉아서 먹는 모습임. 확신 높음
  2. 범위가 2시간을 넘거나 비어 있으면 여기서 멈추고 모름
  3. 지난 2주 평소 식사 시각이 범위 안에 있으면 그 시각 확신 보통
  4. 둘 다 없으면 범위 가운데 확신 보통

3단계

식후 걸음을 볼 시간 정하기

  • 걸음 단서나 평소 시각으로 잡았으면 추정 시각부터 30분
  • 범위 가운데로 잡았으면 범위 전체 + 30분. 실제로 걸었는데 놓치는 일을 줄이기 위해서임.
  • 모름은 계산에서 빠지고 점수를 깎지 않음.

실제와 얼마나 차이 나나

실제 사용 데이터가 아직 없어 가상 사용자로 끼니마다 2만 일을 만들어 계산했음. 가정: 점심 오후 12:20±25분 · 저녁 오후 7:00±45분 · 아침 오전 7:40±40분에 먹고(저녁은 식후 20분~2시간 뒤에 답하되 10%는 밤 9시 반 뒤), 맞는 선택지를 고르는 비율 85%, 걸음 단서가 보이는 날 35%, 평소 식사 시각이 잡힌 사용자 50%, 실제로 식후에 걸은 날 50%. 실제 데이터가 생기면 가정만 바꿔 다시 계산함.

지표에 쓰이는 곳

계산식 전달 문서(LJH)의 지표 계산기로 직접 돌려 본 결과임.

자기돌봄식후에 움직였는지가 「식후 행동」 칸이 됨. 하루 8,000보 예시에서 지금 72점(좋음) → 식후에 걸었으면 81점, 안 걸었으면 61점(보통).
일상안정최근 7일과 그 전 7일의 식후 행동 비율을 비교함. 각 7일에 3일 이상 답이 있어야 들어감.
생활여유계산식에 식사 시각이 없어서 달라지지 않음.

식후에 걸었는지 판정하는 방법

계산식 전달 문서(LJH)는 「어떤 행동을 식후 행동으로 볼지는 서비스가 정하고, 계산기는 완료 · 미완료 · 모름만 받는다」고 함. 그래서 서비스가 걸음 기록으로 판정(방법 A)함. B · C는 비교를 위해 함께 적은 다른 방법임. 판정 질문은 「식사 시각 뒤 걸음 기록만 보고 식후에 걸었다고 볼 수 있나?」 아래 예시는 모두 같은 사람임. 오후 1:20에 점심 「오후 12:20 이후」를 골랐고, 실제로 오후 12:55~1:05에 10분 걸었음.

방법 A · 채택

걸음 기록으로 판정함

판정 방법
식후 걸음 보는 시간 안에 5분 넘게 이어 걸었거나(분당 20보 이상), 합계 300보 이상이거나, 운동 기록이 시작됐으면 「걸었음」. 아니면 「안 걸었음」. 걸음 기록이 비어 있는 시간이면 「모름」.
예시
오후 12:20~1:50 사이에 10분 걸음 → 걸었음. 자기돌봄 72 → 81.
같은 날 걷지 않았다면 → 안 걸었음. 72 → 61(보통).
화면
더 바뀌는 것 없음.
지표
시각을 받은 날마다 식후 칸이 채워짐. 일상안정의 식후 비율 비교는 답이 2주 쌓인 뒤부터 들어감.
남는 일
판정 로직 개발(참조 구현 있음). 5분 · 300보는 임시값, 출시 뒤 조정.

답 B

안 됨. 사용자 확인이 있어야 함

판정 방법
사용자가 식후 걷기 목표를 완료로 누른 날만 「걸었음」. 확인 알림은 보내지 않음.
확인이 없으면 걸음이 없어도 「안 걸었음」을 만들 수 없어 「모름」.
예시
식후 걷기 목표를 완료로 누름 → 걸었음. 72 → 81.
누르지 않음 → 모름. 72 그대로.
화면
더 바뀌는 것 없음.
이미 있는 목표 완료 표시를 씀.
지표
식후 걷기 목표가 나오고 사용자가 완료를 누른 날만 채워짐. 점수가 깎이는 일은 거의 없지만 올라가는 날도 적음.
남는 일
식후 걷기 목표와 식사 시각을 묶는 규칙.

답 C

시각이 확실할 때만 걸음으로 판정함

판정 방법
추정 시각이 확신 높음(걸음 단서)이거나 건강 앱 기록일 때만 A처럼 판정함.
범위 가운데나 평소 시각으로 잡은 날은 「모름」.
예시
오후 12:25에 걷다 멈춘 단서가 있으면 오후 12:25~12:55를 보고 판정함.
단서 없이 범위 가운데로 잡은 날 → 모름. 72 그대로.

더 바뀌는 것 없음.
지표

남는 일

확정한 것

  • 질문 1개 추가 · 식이 최대 3문항, 전체 최대 5~6문항. 수면이나 회전 식이 질문을 빼서 수를 맞추면 그 축의 관찰이 늦어져서, 하나를 더함.
  • 진행 번호도 따로 셈 · 식사 1/5 → 시각 2/5 → 다음 질문 3/5
  • 1시간 범위 + 선택지 상한 시각 · 선택지는 1시간 간격으로 두고, 아침 9시 · 점심 오후 2시 · 저녁 오후 9시를 넘으면 그 시각에 답한 것과 같은 선택지를 보여 줌. 2시간 간격은 정확도가 절반으로 떨어지고 식후 걸음을 2시간 반이나 보게 돼서 쓰지 않음.
  • 아침 기준 시각은 7시 · 8시 정각 · 출시 뒤 「8시 이후」를 고른 비율이 30%를 넘으면 경계를 다시 봄.
  • 시각은 「오후 1:10」처럼 오전 · 오후를 붙여 표기 · 오전·오후는 위에 작게, 시각은 크게. 아침 선택지는 「7시 이전」처럼 시만 씀.
  • 선택지 시각은 10분 단위로 내림 · 반올림하면 자정을 넘기거나 아직 안 온 몇 분이 선택지에 들어감.
  • 건너뛰기 없음 · 다른 식이 질문과 같음.
  • 세 번째 선택지는 「못 먹거나 거름」, 이 답에는 시각을 묻지 않음 · 제품 전체 문구와 데이터 계약에도 반영했음.
  • 「못 먹거나 거름」만 5~7자 규칙의 예외(8자). 시각 선택지 큰 글자는 모두 5~7자 안 · 다른 선택지는 지금 규칙 그대로임.
  • 점심에는 「드신 뒤 답해주세요」 안내를 붙이지 않음 · 먹기 전에 답할 수 있는 건 오후 12:00~12:30뿐이라 드묾. 출시 뒤 점심 답 중 이 시간 답이 10%를 넘으면 그때 붙임.
  • 식후 걷기 확인 알림은 보내지 않음

함께 정한 것

  • 선택지 순서 · 점심 · 저녁 1시간 칸은 최근부터(1시간 이내 → 그보다 전), 고정 선택지는 이른 시각부터(7시 이전 → 9시 이후).
  • 시각 단계에서 앱을 나갔음 오면 · 식사 답은 두고, 시각 선택지는 다시 들어온 시각 기준으로 새로 만듦.
  • 건강 앱 식사 기록이 있으면 · 시각 단계를 묻지 않고 그 시각을 씀(확신 높음).
  • 식후에 걸었는지는 걸음 기록으로 판정 · 식후 관찰 시간 안에 5분 넘게 이어 걸었거나(분당 20보 이상) 합계 300보 이상이거나 운동 기록이 시작됐으면 「걸었음」. 아니면 「안 걸었음」. 걸음 기록이 없거나 식사 시각이 모름이면 「모름」. 계산식 전달 문서가 판정을 서비스 몫으로 두기 때문임.
