1.1 목적

마이리포트 v2는 검진·진료 이력 열람에 AI 웰니스 코칭을 더한다. 코칭이 설득력을 가지려면 "지금 내 상태가 어떤지"를 사용자가 직관적으로 확인할 수 있는 근거 지표가 필요하며, 이 3종 지표가 그 역할을 한다. 세 지표는 사용자를 평가하는 점수가 아니라, 생활 패턴을 이해하고 조절 가능한 지점을 보여주는 해석 지표다.

1.2 왜 3개이며 왜 합치지 않는가

세 지표는 같은 데이터(걸음·활동·수면·심박)를 다른 시간축과 다른 질문으로 본 결과다. 하나로 합치면 "오늘 여유가 없어서"인지 "행동을 안 붙여서"인지 "최근 흐름이 흔들려서"인지 구분할 수 없다. 생활여유는 낮지만 자기돌봄은 괜찮을 수 있고(빠듯했지만 가능한 순간마다 움직임을 붙임), 생활여유는 괜찮지만 일상안정이 낮을 수도 있다(오늘은 버틸 만하지만 최근 흐름이 한쪽으로 쏠림).

1.3 공통 설계 원칙

P1 · 질문은 해석 보조

질문 응답은 점수를 직접 올리거나 내리지 않는다. 이유 설명·코칭 문구 선택·신뢰도 보강에만 쓴다. 미응답을 이유로 낮은 상태를 주지 않는다.

P2 · 디바이스 데이터가 기본 축

watch가 있으면 더 자세히, 없으면 낮은 해상도로 해석한다. watch 미보유 사용자를 불리하게 만들지 않는다.

P3 · 기록은 점수 보너스가 아님

식사 기록은 「기준점 확인됨」까지다. 기록했다는 사실로 상태를 올리지 않는다.

P4 · 숫자는 내부 계산용

0~100 내부 규칙값은 구간 판정에만 쓰고, 화면에는 상태 라벨과 흐름만 보여준다. 0~100을 건강 평가·성과 점수처럼 해석하지 않는다.

P5 · 종합 점수 없음

세 지표를 합산·평균하지 않는다. 홈 요약 문장도 대표 지표 1개 또는 주의 구간 지표만 언급한다.

P6 · 결측 ≠ 0

미착용·미수집·권한 미허용은 null이며 낮은 활동과 구분한다. 산출 불가는 「관찰 중」이라는 별도 상태다.

P7 · 플랫폼 차이는 비교 가능성부터

Apple·Samsung의 수집 방식이 다르면 같은 눈금으로 비교하지 않는다. 공통 정규화 필드 + coverage/comparable 플래그를 둔다.

P8 · rule-based · 후속 보정

학습 환경이 없으므로 미리 정한 규칙과 안전장치로 동작한다. 계수·경계는 고정 규칙값이며 실사용 데이터는 이상 반응 확인·보정에만 쓴다.

2디바이스 수집 데이터 · 정규화 필드

Apple Health · Samsung Health에서 무엇을 가져오고, 지표 산출 전에 어떤 공통 필드로 바꾸는지

원본 필드명이 산식에 바로 들어가지 않는다. 플랫폼별 원본을 아래 정규화 필드로 변환한 뒤 구성 요소(M/G/H/D · anchor · dev/vol)를 계산한다. 시간 정보가 살아 있는 interval 단위 원본이 기본 축이며, 일 합계값은 희소 경로와 일상안정 신호에만 쓴다.

I1

생활여유STATE · 오늘의 상태 · Life Margin

수면과 활동 배치를 바탕으로, 오늘 생활의 부담이 한쪽으로 몰려 있는지와 리듬에 여유가 있는지를 해석

정의 · 핵심 관점

부담(오래 안 움직임 · 활동이 늦은 시간에 몰림 · 회복할 틈 없이 이어짐) ↔ 여유(짧게라도 분산된 움직임 · 무리한 흐름을 낮추는 시간 · 충분한 수면). 활동 총량이 아니라 하루의 배치가 핵심이다. 걸음이 많아도 저녁에 몰려 있고 중간에 쉬는 흐름이 없으면 「충분해요」로 단정하지 않는다.

구성 요소 산출 절차 임계값 잠정 · §8 P1-1

각 구성 요소는 0~1 범위로 정규화한다. 입력은 §2의 정규화 필드이며, 기준일 하루(04:00~익일 04:00)를 대상으로 한다.

기호입력산출 절차예시
M
움직임 분산		step_interval · partition① 6개 partition 중 「활동 있음」 구획 수 = p
② 5분 이상 active_bout 수 = b (상한 8)
③ M = 0.6·(p ÷ 6) + 0.4·(b ÷ 8)		4구획 활동 · bout 5개 → 0.6·0.67 + 0.4·0.63 = 0.65
G
비활동 압력		sedentary_gap · sleep_session① 깨어 있는 시간의 sedentary_gap 중 가장 긴 것 = L(분)
② 60분 이상 gap 개수 = n
③ G = 0.7·clip((L − 60) ÷ 180, 0, 1) + 0.3·clip(n ÷ 4, 0, 1)		최장 150분 · 긴 gap 3개 → 0.7·0.5 + 0.3·0.75 = 0.58
H
늦은·몰린 활동		step_interval · partition① 21시 이후 걸음 ÷ 하루 걸음 = late
② 걸음이 가장 많은 한 partition의 비중 = conc
③ H = 0.5·clip(late ÷ 0.4, 0, 1) + 0.5·clip((conc − 0.35) ÷ 0.4, 0, 1)		21시 이후 30% · 최대 구획 55% → 0.5·0.75 + 0.5·0.5 = 0.63
D
수면 부족		sleep_session(어젯밤) · baseline① 총 수면 분 = s
② 개인 기준 = baseline 수면 중앙값과 420분 중 작은 값 = ref
③ D = clip((ref − s) ÷ 120, 0, 1)		기준 430 → ref 420, 실제 330 → 0.75
R
희소 경로 익숙함		daily_steps · baseline① z = (오늘 걸음 − 기준 중앙값) ÷ 기준 IQR
② R = clip(z, −1.875, 1.875) (8·R이 ±15에 걸리도록)		중앙값 6,000 · IQR 2,000 · 오늘 7,500 → z 0.75 → 8R = 6

Q(질문 응답)는 산식에 들어가지 않으며, "오늘 몸이 무거웠다"류 응답은 이유 문장 선택과 코칭 문구에만 쓴다. 절차의 분모·임계값(6구획 · 60분 · 21시 · 420분 등)은 잠정이며 실데이터 분포로 조정한다.

산출 방식

위에서 얻은 M/G/H/D를 타임라인 풍부도(coverage)에 따라 두 경로 중 하나로 결합한다.

// ① 풍부한 타임라인 경로 — 시간대별 활동 interval + 수면이 있을 때 I1 = clip( 50 + (35/85) × (35·M − 30·G − 20·H) − 20·D , 0, 100 ) // ② 희소 기록 경로 — 걸음 일 합계만 있을 때 (35~65에 갇힘, ①과 눈금 비교·차감 금지) I1_low = 50 + clip( 8·R , −15, 15 ) // R = 오늘 걸음 합계가 내 평소 범위(기준 21일) 안인가에 대한 익숙함 지표 // 응답만 있는 날은 산출하지 않는다 → 관찰 중

계수(35/85 · 35 · 30 · 20 · 8 · ±15)는 엔진 v5.7 고정 규칙값이며 데이터로 학습한 값이 아니다. 채택 여부는 §8 P1-1.

이 지표가 말하지 않는 것

피로도 · 수면 점수 · 스트레스 점수 · 회복 점수 · readiness 점수가 아니다. 치료 효과나 건강 상태 판단도 아니다. 「부족해요」는 몸이 나쁘다는 뜻이 아니라 오늘 하루의 흐름에 회복할 틈이 적었다는 관찰이다.

결측 처리

  • 타임라인이 불완전하면 ① 대신 ② 희소 경로로 전환한다. 0점으로 채우지 않는다.
  • 걸음 기록도 없으면 관찰 중. 사유: "오늘 활동 기록이 아직 없어요".
  • 수면 기록이 없으면 D = 0이 아니라 D를 제외하고 계산하되 결과에 coverage 플래그를 남긴다(해석 문장에서 "수면은 기록이 없어 빼고 봤어요").
I2

자기돌봄ACTION · 오늘의 행동 · Self-Care Moments

식사·긴 비활동 등 「행동 가능한 기준점」 주변에서 실제 움직임이 있었는지를 연결률로 본다

정의 · 핵심 관점

많이 움직였는지가 아니라 알맞은 때에 움직였는지가 기준이다. 조절 가능한 순간(기준점, anchor)과 그 근처에서 실제로 일어난 짧은 움직임의 연결을 본다. 이름은 사용자의 주체성을 긍정적으로 표현하며, 의지력·순응도·실천 점수 같은 평가·압박형 표현을 쓰지 않는다.

I2 = ( 연결된 행동 수 ÷ 유효 기회 수 ) × 100 // 예: 기회 3회 중 2회에 행동이 붙음 → 66.7 → 좋음 // 유효 기회 수 < 최소 기회 수(잠정 2)이면 산출하지 않는다 → 관찰 중 // 같은 window에 여러 활동이 있어도 1회로 센다(중복 인정 없음, 잠정)

I2는 걸음 수 총량이 아니라 「언제 걸었는가」가 중요하므로 시간 정보가 살아 있는 step_interval(§2)을 쓰고, 일 합계값은 쓰지 않는다. 산식보다 기준점 종류 · 인정 window · 행동 인정 기준 · 최소 기회 수 · 중복 처리 Rule을 먼저 고정해야 한다(§8 P0-1·P0-2).

이 지표가 말하지 않는 것

의지력 · 코칭 순응도 · 목표 달성률 · 활동량 점수가 아니다. 하루 걸음이 많아도 기준점과 연결되지 않으면 올라가지 않고, 활동량이 크지 않아도 적절한 순간에 행동이 붙으면 의미 있는 연결로 본다.

결측 처리

  • 기준점 신호(식사 기록 또는 긴 비활동 판정)와 시간대별 활동 데이터가 둘 다 있어야 산출한다. 걸음 총량만으로는 불가하며 저해상도 대체 경로가 없다.
  • 기록만 있고 실제 움직임 데이터가 없으면 「기준점 확인됨」까지이며 상태를 올리지 않는다.
  • 기회 목록이 불완전하면 비율을 억지로 계산하지 않고 null(관찰 중). 사유: "오늘은 챙길 순간이 아직 확인되지 않았어요".
I3

일상안정TREND · 최근의 흐름 · Life Steadying

수면·활동·심박 등 생활 신호의 최근 7일 흐름을 개인의 평소 기준(직전 21일)과 직접 비교하는 독립 지표. 값이 높을수록 안정적이며 I2와 무관하게 계산한다

정의 · 핵심 관점

하루하루의 리듬이 평소처럼 일정하게 흐르고 있는지 본다. 정해진 목표에 맞췄는지가 아니라 개인 기준 범위 안에서 최근 며칠이 얼마나 벗어나지 않고, 얼마나 덜 흔들렸는지를 본다. 어제와 오늘이 크게 다르지 않을수록 안정적이다.

구성 요소

구성 요소쉬운 설명역할무엇으로 계산하나
개인 기준 범위그 사람에게 평소 자연스러운 생활 신호의 범위비교 기준신호별 직전 21일의 중앙값과 산포(IQR). 최소 15일 관측
최근 벗어남 ⓑ최근 7일이 평소 중심에서 얼마나 떨어졌는지핵심|최근 7일 중앙값 − 기준 중앙값| ÷ 기준 IQR. 최소 5일 관측

구성 요소 산출 절차 잠정 제안 · §8 P0-3

단계입력산출 절차규칙(잠정)
① 신호 일별값sleep_session · movement_minutes · daily_steps · resting_hr기준일까지 28일 각 날의 신호값 4종을 만든다.
· 수면: 총 수면 분 · 활동 시간: movement_minutes · 걸음: daily_steps · 심박: resting_hr		missing/nonwear 날은 null로 두고 채우지 않는다
② 구간 나누기day기준일 포함 최근 7일 = recent, 그 직전 21일 = basebase 관측일 ≥ 15 · recent 관측일 ≥ 5인 신호만 계속 진행
③ 비교 가능성comparablebase와 recent의 수집 경로가 같은 신호만 사용중간에 워치→폰으로 바뀐 신호는 제외
④ 기준 범위base신호별 median_base · IQR_base. IQR이 최소 산포보다 작으면 최소 산포로 대체최소 산포: 수면 20분 · 활동 시간 10분 · 걸음 800보 · 심박 3bpm
⑤ 벗어남 devrecent · ④|median_recent − median_base| ÷ IQR_base, 0~2로 자른다방향(높아짐/낮아짐)은 점수에 넣지 않고 해석 문장에만 쓴다
⑥ 흔들림 volrecent · ④IQR_recent ÷ IQR_base − 1, 0~2로 자른다(평소보다 더 흔들린 만큼만)평소보다 덜 흔들린 것은 0으로 본다
⑦ 신호별 안정도 · 합산⑤·⑥s = 1 − 0.5·dev − 0.5·vol → 가중 평균 × 100가중치: 수면 .35 · 활동 시간 .30 · 걸음 .20 · 심박 .15. 제외된 신호는 분모에서 뺀다

예시 — 수면: base 중앙값 420분 · IQR 45분, recent 중앙값 390분 · IQR 70분 → dev 0.67 · vol 0.56 → s 0.39. 활동 시간: dev 0.2 · vol 0 → s 0.90. 걸음: dev 0.5 · vol 0.3 → s 0.60. 심박은 comparable=false로 제외. I3 = 100 × (0.35·0.39 + 0.30·0.90 + 0.20·0.60) ÷ 0.85 = 62 → 보통(비슷해요). 해석: "잠드는 시간이 평소보다 흔들렸어요".

산출 방식

// 신호 k마다 (기준 21일 vs 최근 7일), 기준일마다 재계산 dev_k = clip( |median_recent − median_base| ÷ IQR_base , 0, 2 ) // 벗어남 vol_k = clip( IQR_recent ÷ IQR_base − 1 , 0, 2 ) // 평소보다 더 흔들린 만큼만 s_k = clip( 1 − 0.5·dev_k − 0.5·vol_k , 0, 1 ) // 신호별 안정도 // 관측된 신호의 가중 평균 (잠정 가중치: 수면 .35 · 활동시간 .30 · 걸음 .20 · 안정시 심박 .15) I3 = 100 × Σ( w_k · s_k ) ÷ Σ( w_k ) , k ∈ coverage 충족 신호 // 기준 15일 또는 최근 5일 미만 · 관측 신호 0개 → null (관찰 중) // 기준 IQR이 0에 가까우면 신호별 최소 산포(예: 수면 20분·걸음 800보)로 대체해 나눗셈 불안정을 막는다
  • 일 단위 산정. 기준일마다 「그날까지의 최근 7일 vs 직전 21일」로 값을 내므로 주간 그래프에 요일별 점을 찍을 수 있다. 당일 기록이 없어도 이력이 있으면 계산된다.
  • 비교 가능성. 기준 구간과 최근 구간의 수집 경로(플랫폼·기기)가 다르면 해당 신호는 comparable=false로 두고 제외한다(P7).
  • 균일하게 나쁜 경우. 매일 5시간씩 자는 사람은 흔들림이 없어 「안정적이에요」가 나올 수 있다. 그 상태가 나쁘다는 사실은 이 지표가 말하지 않으며 절대 임계를 보는 코칭 규칙이 맡는다. 해석 문장에서 "평소 범위 안에서"를 반드시 붙인다.

이 지표가 말하지 않는 것

오늘의 컨디션 · 당일 활동량 · 치료 효과 · 건강 상태 진단이 아니다. 하루만 좋아졌다고 안정으로 판단하지 않으며, 체중·심박 추세를 의료적 상태 판정에 쓰지 않는다.

결측 처리

  • 기준 구간 15일 · 최근 구간 5일 최소 관측을 만족하는 신호만 쓴다. 하나도 없으면 관찰 중. 사유: "평소 범위를 잡으려면 며칠 더 기록이 필요해요".
  • 신규 사용자는 가입 후 기준선 형성 기간(§8 P1-4) 동안 관찰 중으로만 표시한다.

5.2 구간 배지

표기

홈은 3구간 게이지 + 라벨, 지표별 분석 카드는 우측 상단 배지에 기준일 라벨만 표시한다. 숫자 · 퍼센트 · 소수점 · 등급은 어디에도 노출하지 않는다.

색상

좋음 = 지표 고유색(생활여유 #12A150 · 자기돌봄 #D98A12 · 일상안정 #7C5CFC), 보통 = 중립 회색, 주의 = amber. 그래프 선/점은 상태와 무관하게 지표 고유색을 유지한다.

표시 없음같은 구간 · 전일 값 없음 · 어느 한쪽이 관찰 중

같은 구간 안의 내부 점수 증감은 변화로 보지 않는다. "화 62 → 수 67"이 아니라 "보통 구간에서 움직이다가 좋음 구간으로 옮겨갔다"는 흐름만 말한다.

5.4 주간 그래프 규칙

세 구간 띠 위에서 값이 있는 날만 점·선 · 기준일은 속 빈 원 · 금~일은 미래라 비움
요소규칙
배경 띠주의 · 보통 · 좋음 3개 가로 구간. 연한 상태색과 우측 짧은 이름. 띠 비율은 구간 경계(66/33)를 따른다
기간월~일 7칸. 이전 주로 이동하면 그 주의 요일, 읽기 전용
선/점실제 값이 있는 날만 점을 찍고 이웃한 관측일만 선으로 잇는다
기준일속 빈 원 + 굵은 테두리, 해당 요일 Bold
결측일 · 미래점 없음 · 선 끊김. 0이나 이전 값으로 메우지 않는다. 미래 요일은 비운다
표시하지 않는 것Y축 눈금·숫자, 점 위 값, 평균선, 증감 표시. 점을 눌러도 값이 뜨지 않는다
일상안정다른 두 지표와 같은 형식. 각 날의 값은 「그날 기준 최근 7일 vs 직전 21일」

5.5 결측 · 산출 불가 · 미연동

상태조건화면
관찰 중지표별 필수 입력 미충족 · 기준선 미형성 · 기회 미관측빈 게이지 / 카드에 지표명만 + "아직 관찰 중이에요" + 지표별 사유 한 줄. 구간 배지 없음. 결측을 낮은 구간으로 표시하지 않는다
주 중 일부 결측기준일은 산정되지만 주 중 일부 날이 결측정상 카드. 그래프에서 해당 날만 점 없이 선을 끊는다
미연동건강 데이터 연동 없음게이지·카드 대신 연동 안내. 관찰 중과 반드시 구분한다

홈 요약 문장은 세 라벨이 이미 상태를 말하므로 평상시에는 두지 않고, 주의 구간 지표가 있을 때 "{지표명}에서 살펴볼 점이 있어요", 관찰 중 지표가 있을 때 "{지표명}은 아직 관찰 중이에요"만 붙인다(홈화면 화면정의서 §6.4).
