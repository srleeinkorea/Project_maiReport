01목적과 범위

검진 항목 값 하나를 같은 성별·연령대 인구 분포에 대입해 "또래 100명 중 몇 번째"를 계산합니다. 검진기관 판정(정상A·B·질환의심·유질환자)과는 독립된 축이며, 판정을 대체하거나 새 등급을 만들지 않습니다.

  • 계산 위치: 서버. 검진 데이터가 저장·갱신될 때 1회 계산해 결과를 함께 저장합니다. 클라이언트는 저장된 값을 표시만 합니다.
  • 대상 항목: 아래 03장 기준표에 있는 항목만. 기준표에 없는 항목(요단백·시력·흉부촬영 등)은 계산하지 않습니다.
  • 정확한 등수는 출력하지 않습니다. 퍼센타일(정수)만 출력합니다.

02입력

{
  "sex": "M" | "F",              // 회원 프로필. 없으면 계산 불가 → 06장
  "age": 45,                     // 검진일 기준 만 나이 (생년월일과 exam_date로 서버가 계산)
  "items": [
    { "code": "BP_SYS", "value": 148, "unit": "mmHg" },
    { "code": "FBG",    "value": 128, "unit": "mg/dL" }
  ]
}

항목 코드는 기존 검진 정규화 코드를 그대로 씁니다. 단위가 기준표와 다르면(예: 혈당 mmol/L) 계산 전에 기준표 단위로 환산합니다. 환산표가 없는 단위는 계산하지 않습니다.

03기준 분포표

항목 × 성별 × 연령대별 분포 모수를 담은 설정 데이터입니다. 코드에 하드코딩하지 않고 버전이 있는 설정 파일 또는 테이블로 관리합니다. 값을 바꾸면 기존 계산 결과는 재계산 대상이 됩니다(09장).

연령대 구간

band_index012345
만 나이19–2930–3940–4950–5960–6970+

초기 버전은 10세 구간입니다. 공단 참조표준(2세 단위)으로 교체할 때는 구간 배열만 바꾸면 되도록 bands를 데이터로 둡니다.

  "bands": [[19,29],[30,39],[40,49],[50,59],[60,69],[70,200]],
  "items": {

      "unit": "mmHg",
      "dist": "normal",            // "normal" | "lognormal"
      "better": "low",             // "low" | "high" | "none"
      "low_flag": 90,              // 선택. 이 값 미만이면 순위 대신 경고 (06장)
      "M": { "mu": [118,120,123,126,130,134], "sd": [11,12,13,14,15,16] },
      "F": { "mu": [106,108,113,120,127,133], "sd": [10,11,13,15,16,17] }
    },
    "TG": {
      "unit": "mg/dL", "dist": "lognormal", "better": "low",
      "M": { "mu": [100,135,145,140,130,120], "sd": [1.70,1.75,1.75,1.70,1.65,1.60] },

  • dist = normal: mu는 산술평균, sd는 표준편차.
  • dist = lognormal: mu는 기하평균(중앙값), sd는 기하표준편차(무차원, 1보다 큼). 값이 오른쪽으로 치우친 항목(중성지방, 간효소, 공복혈당)에 씁니다.
  • better: low 낮을수록 좋음 / high 높을수록 좋음(HDL, 헤모글로빈) / none 방향 없음(키, 체중).

04계산

4.1 연령대 선택

band = index of first b in bands where b[0] <= age <= b[1]
if none → 계산 안 함 (18세 이하)

4.2 표준화 점수 z

normal     :  z = (x − mu[band]) / sd[band]
lognormal  :  z = (ln(x) − ln(mu[band])) / ln(sd[band])       // x > 0 필수

4.3 분포 위치 P (또래 중 나보다 값이 낮은 사람의 비율, 0–100)

P = Φ(z) × 100
Φ = 표준정규 누적분포함수. 언어 표준 라이브러리나 erf 기반 근사(Abramowitz–Stegun 7.1.26, 오차 1.5e-7)를 쓴다.
z를 [−4, 4]로 클램프한 뒤 계산한다 (극단값이 0이나 100으로 붙는 것을 막는다).

4.4 또래 상위 % (rank_pct)

better = low   :  rank_pct = P              // 값이 낮을수록 rank_pct가 작다 = 상위
better = high  :  rank_pct = 100 − P
better = none  :  rank_pct = null, size_pct = 100 − P   // "큰 순 상위 %"로만 표기

4.5 반올림과 범위

display_pct = clamp(round(rank_pct), 1, 99)
// 0%와 100%는 표시하지 않는다. "상위 0 %"는 오해를 부른다.
// 저장은 소수 1자리(rank_pct_raw)로, 표시는 정수로.

4.6 구간 라벨 (bucket)

rank_pctbucket 코드화면 문구비고
1 – 25GOOD또래보다 좋음
26 – 60MID또래 수준중앙값 ±를 넓게 잡는다. 측정 오차 안의 차이를 "나쁨"이라 말하지 않기 위해서다
61 – 85WATCH또래보다 나쁨
86 – 99LOW또래 하위 15 %

경계값은 설정으로 둡니다. better = none 항목에는 bucket을 붙이지 않습니다.

4.7 종합 (summary)

eligible = items where better != none AND flag == null
avg_pct  = mean(rank_pct of eligible)           // 가중치 없음
worse_n  = count(eligible where rank_pct > 50)
grade    = bucket(avg_pct)                       // 4.6과 같은 경계

종합은 구간 등급(grade)으로만 표기합니다. avg_pct 숫자를 사용자에게 직접 보이지 않습니다. 항목 수가 3개 미만이면 종합을 만들지 않습니다.

4.8 의사코드

def percentile(item_code, sex, age, x, ref):
    spec = ref.items[item_code]
    band = band_index(age, ref.bands)
    if band is None or x is None or x <= 0: return None
    if spec.low_flag is not None and x < spec.low_flag:
        return {"flag": "LOW_RANGE"}
    mu, sd = spec[sex].mu[band], spec[sex].sd[band]
    if spec.dist == "lognormal":
        z = (ln(x) - ln(mu)) / ln(sd)
    else:
        z = (x - mu) / sd
    z = clamp(z, -4, 4)
    P = Phi(z) * 100
    if spec.better == "none":
        return {"size_pct": P_to_display(100 - P), "rank_pct": None}
    rank = P if spec.better == "low" else 100 - P
    return {"rank_pct_raw": round(rank, 1),
            "rank_pct": P_to_display(rank),
            "bucket": bucket(rank),
            "median": mu, "z": round(z, 2), "ref_version": ref.version}

def P_to_display(p): return int(min(99, max(1, round(p))))

06예외 처리

상황처리
성별 또는 생년월일 없음전체 계산 생략. 검진 상세에 순위 줄을 표시하지 않는다. "프로필을 채우면 또래 비교를 볼 수 있어요" 안내 1줄
만 18세 이하계산 생략. 소아·청소년은 별도 성장도표가 필요하다
값 없음 · 0 · 음수해당 항목 생략
기준표에 없는 항목 코드해당 항목 생략. 오류 아님
low_flag 미만 (BMI < 18.5, 수축기 < 90, 이완기 < 60)flag: LOW_RANGE. 순위·bucket 없음. 종합에서 제외. 낮은 값이 "상위 1 %"로 보이는 것을 막는다
단위 불일치환산표가 있으면 환산 후 계산, 없으면 생략하고 로그
극단값 (z 절대값 > 4)클램프 후 계산. 별도로 outlier: true를 남겨 검수값 오류 가능성을 추적한다
기준표 버전 변경기존 결과는 ref_version이 다르면 조회 시 재계산한다. 재계산은 멱등이다
사용자 등록 리포트(OCR 검수값)공단 연계값과 같은 방식으로 계산. 출처를 결과에 남긴다

07AI 요약 연동

AIH-001·002의 파이프라인에 그대로 얹습니다. 결론과 먼저 볼 항목은 규칙이, 문장은 AI가 맡습니다.

규칙 엔진 (코드)

rows     = items where rank_pct != null and flag == null
low      = rows where bucket == LOW    sorted by rank_pct desc
watch    = rows where bucket == WATCH  sorted by rank_pct desc
priority = (low + watch)[:3]

headline_key =
  "attention" if low   → "또래보다 눈에 띄게 높은 항목이 있어요"  보조: 먼저 볼 항목 N · 또래 하위권 M
  "watch"     if watch → "대부분 또래 수준이고, 지켜볼 항목이 있어요"  보조: 지켜볼 항목 N
  "ok"        else     → "주요 항목이 또래 평균 이상으로 확인됐어요"  보조: 정리한 항목 N

AI에 넘기는 것

{
  "cohort_label": "남성 40대",             // 10세 단위까지만
  "priority": ["수축기 혈압", "공복 혈당", "이완기 혈압"],
  "items": [ {"name": "수축기 혈압", "bucket_label": "또래 하위권"}, ... ]
}
// 값, 퍼센타일 숫자, z, 검진일, 기관명은 넘기지 않는다

출력 검수 (SAFE-001 확장)

  • 숫자 문자가 하나라도 있으면 차단.
  • 금지어 사전: 고혈압·당뇨·위험·심각·매우·급격·약·치료·때문에·운동 부족·식습관·문제없·건강합니다·걱정 없. 기존 SAFE-001 사전에 추가합니다.
  • 길이: headline_key가 ok면 150자, 그 외 300자.
  • 차단 시 재시도 없음. "이번 결과는 AI 요약으로 정리하기 어려워요" 문구.

09데이터 출처와 교체

초기 기준표는 근사값입니다. 키·체중·BMI 20~40대 평균만 국가기술표준원 인체치수조사(2021 실측) 공표치이고, 나머지 평균은 국민건강영양조사 공표 통계를 참고한 근사값, 표준편차는 문헌 통상치입니다. 서비스 출시 전에 아래 순서로 교체합니다.
순위출처내용비고
1국민건강보험공단 한국인 참조표준 (혈압 · 혈당)성별 × 2세 단위 평균·불확도·분포공공데이터포털 15098383, 15103159. 공단 시스템 로그인 후 XLSX 다운로드
2통계청 KOSIS · 건강검진통계연보성별 × 5세 단위 평균 신장·체중, 검진 항목별 판정 분포DT_35007_N130 (신장), N132 (체중). KOSIS 로그인 필요
3국민건강영양조사 원시자료개인 단위. 항목별 평균·SD·백분위를 직접 계산 가능knhanes.kdca.go.kr. 연구 목적 신청. 표준편차는 여기서 얻는다
4자체 회원 검진 데이터회원 누적 후 실측 분포성별·연령대별 표본 1,000명 이상일 때만 전환. 그 전에는 편향이 크다

교체 방법: 기준표 JSON의 mu·sd만 바꾸고 version을 올립니다. 정규·로그정규 선택은 원시자료의 왜도로 확인합니다(왜도 > 1이면 로그정규). 2세 단위로 갈 때는 bands와 배열 길이를 함께 바꿉니다.

10결정 필요

  1. 경험적 백분위 vs 모수 분포. 원시자료를 확보하면 정규 근사 대신 실제 백분위표(1~99)를 저장하는 편이 정확합니다. 저장 크기는 항목 × 성별 × 연령대 × 99개로 작습니다. 원시자료 확보 시점에 전환할지 결정.
  2. 혈압 U자형 처리. 현재는 저혈압을 low_flag로 제외만 합니다. 정상 범위 중앙(예: 115/75)에서의 거리로 순위를 매기는 방식도 가능하지만 설명이 어렵습니다. 초기 버전은 현행 유지 제안.
  3. 종합 등급 노출 여부. 항목별 순위만 보여주고 종합은 숨기는 안도 있습니다. 종합은 가중치 논쟁이 따르므로 사용자 테스트 후 결정.
