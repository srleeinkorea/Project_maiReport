## 계산 방식 요약

- 기준: 같은 성별 × 5세 연령 구간의 전국 검진 수검자 분포(값 구간별 인원수).
- 분포 위치 P = [ Σ(상한 ≤ x인 구간 인원) + 해당 구간 인원 × (x − 하한)/(상한 − 하한) ] ÷ 총 인원 × 100
- 또래 상위 % = P (낮을수록 좋은 항목) / 100 − P (HDL·혈색소·eGFR처럼 높을수록 좋은 항목)
- 표기: "또래 상위 N %" 또는 "100명 중 N번째". 1~99로 제한, 정확한 등수는 쓰지 않음.
- 구간 라벨: 1~25 좋음 / 26~60 또래 수준 / 61~85 나쁨 / 86~99 하위 15 %
- 키·체중은 방향 없음 → "큰 순 상위 %"로만 표기, 종합 제외. 기준은 국가기술표준원 제8차 인체치수조사(2020 실측)의 성별 × 5세 구간 백분위표(p1~p99)를 선형 보간. 표준편차도 같은 표에 있음(`04_기준데이터/18, 19번`). 국민건강영양조사는 표준편차를 공표하지 않아 쓰지 않음. 70세 이상은 자료 없음.
- BMI 18.5 미만, 수축기 90 미만, 이완기 60 미만은 순위 대신 "확인 필요".

## 두 산출물의 관계

- **엑셀(02)** 이 기준입니다. KOSIS 실측 분포로 경험적 백분위를 계산하며, 개발 구현의 검증 기준값으로 씁니다.
- **계산기(03)** 는 먼저 만든 프로토타입으로 정규분포 근사(평균·표준편차)를 씁니다. 두 결과가 수 % 차이 날 수 있으며, 실제 서비스는 엑셀 방식(경험적 백분위)을 따릅니다. 규격서 10장 "결정 필요 1번"은 이 패키지로 **경험적 백분위 채택**으로 결정 가능합니다.
