이 문서로 하는 일

식이 질문·목표가 기획(데이터계약)대로 나오는지 앱 화면(검증 사이트)에서 확인하고 결과를 기록해요. 기준은 SharePoint의 식이 개발전달 데이터계약 엑셀이고, 케이스마다 「예상」과 「근거」(엑셀 칸 링크)가 붙어 있어요.

  1. 케이스의 조건대로 앱에서 실행해요.
  2. 실제로 나온 결과를 고르거나 메모에 적으면 판정이 정해져요(직접 바꿀 수도 있어요).
  3. 통과가 아닌 케이스는 맨 아래 「개발 전달 모음」에 쌓이니 그대로 복사해서 전달해요.

개발 전달 모음

실패 · 재확인 · 추후 확인으로 판정된 케이스가 모여요. 그대로 복사해 개발에 전달하세요.

아직 기획과 다른 케이스가 없어요.
  • 질환별 연결 축 (질환연결축 시트): 고혈압 = 국물 → 채소 · 당뇨병 = 채소 → 단 음료·간식 → 식사 속도·양 · 이상지질혈증 = 기름진 음식 → 식사 속도·양 · 만성 신장질환 = 없음(금지만). 질문은 질문 번호 순서로 고르고, 목표는 그날 질문 축을 따라가요. 만성 신장질환은 연결 축이 없어요.
  • 질문 번호 순서 (질문 시트): 채소 → 단 음료·간식 → 국물 → 야식 → 식사 속도·양 → 단백질 → 기름진 음식. 야식은 오전 4~10시에만 물어요.
  • 금지 성격 (질환금지성격 시트): 당뇨병 = 공복·감량 · 만성 신장질환 = 증량·감량·수분. 회복 문구 12개 중 10개는 증량 성격이라 신장질환에서 빠지고, 증량이 아닌 2개(입맛 없는 날 적어 두기 · 식사 시간 정해 두기)는 남아요.
  • 색 표시: 왼쪽 빨간 띠와 빨간 조건 칸은 F, 노란 띠와 노란 조건 칸은 E예요. TBD와 P는 색 표시가 없어요.
  • 노란 표시가 붙은 케이스는 기획 결정이 남은 항목이라, 예상과 달라도 자동 판정이 TBD예요.
  • 고른 결과는 이 브라우저에만 저장돼요. 다른 사람과 공유되지 않아요.
