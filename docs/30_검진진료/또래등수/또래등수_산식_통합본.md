# 또래 등수 산식 · 통합본 (개발/디자인 전달)

대상: 신체계측 4항목 — 키 · 체중 · BMI · 허리둘레. 화면 문구 "내 또래 100명 중 N등".
계산 엔진은 PCT-002(국민건강영양조사 경계값표)를, 표시 규칙은 AI 요약 화면정의서를 따른다.
v1.0 · 2026-09-14

---

## 0. 준비물

| 준비물 | 내용 |
|---|---|
| 경계값표 | `20_국민건강영양조사_2022-2024_백분위_키체중BMI허리.csv` — 항목 × 성별 × 5세 구간 = 104행, 행마다 p1~p99 경계값 99개. 서버 메모리에 상주 |
| 회원 정보 | 성별(남/여), 생년월일 |
| 검진 값 | 키 cm, 체중 kg, 허리둘레 cm, BMI (검진일 포함) |

BMI는 결과지 값을 쓰고, 없으면 `체중 ÷ (키/100)²` 소수 1자리. 결과지 값과 0.2 이상 차이 나면 결과지 값을 쓰고 로그만 남긴다.

## 1. 계산 (항목마다 반복)

**STEP 1 · 나이** — 검진일 기준 만 나이. 오늘 기준이 아니다(같은 검진은 몇 년 뒤 봐도 등수가 같아야 함).
```
age = 검진일.year − 생년월일.year
if (검진일.month, 검진일.day) < (생년월일.month, 생년월일.day): age −= 1
```

**STEP 2 · 나이 구간** — 5세 단위. 20세 미만은 계산하지 않는다(자녀 프로필은 별도 성장도표). 80세 이상은 한 구간.
```
if age < 20:  rank = null
if age >= 80: band_age = "80세이상"
else:         lo = (age // 5) × 5;  band_age = f"{lo}-{lo+4}세"     # 45 → "45-49세"
```

**STEP 3 · 내 행 찾기** — 항목·성별·구간이 모두 같은 행 하나. 없으면 `rank = null`.
```
bounds = [p1, p2, …, p99]   # 오름차순
```

**STEP 4 · 몇 번째 경계까지 넘었나 (k)** — 내 값 x보다 **작거나 같은** 경계값 개수.
```
k = bisect_right(bounds, x)          # 0 ~ 99
```

**STEP 5 · 경계 사이 보간 → 위치 P**
```
if k == 0:     P = 1
elif k >= 99:  P = 99
else:
    lo, hi = bounds[k−1], bounds[k]  # k번째, k+1번째 경계
    frac = 0 if hi == lo else (x − lo) / (hi − lo)
    P = k + frac
```
P의 뜻: "나보다 값이 작은 사람이 100명 중 P명".

**STEP 6 · 등수와 구간**
```
rank = clamp(round(P), 1, 99)        # 화면의 "N등". 방향 뒤집기 없음
band = ceil(rank / 20)               # 1~5, 사람 그림 위치
```
1등 = 값이 가장 작음, 99등 = 가장 큼. 네 항목 모두 같은 방향. 등수는 위치이지 좋고 나쁨이 아니다.

**STEP 7 · 건강 기준 (등수와 별개)**
```
health = warn  if BMI < 18.5 or BMI ≥ 25
health = warn  if 허리둘레 ≥ 85 (여) / ≥ 90 (남)
그 외 ok. 키·체중은 항상 ok
```
근거: 국민건강보험공단 판정기준(비만). 저체중도 warn.

**STEP 8 · 저장** — 검진 1건마다 항목별 결과를 저장하고 화면은 저장값만 읽는다. 표 버전이 바뀌면 재계산.
```json
{ "exam_id": "…", "table_version": "knhanes-2022-2024.v1",
  "body": [ { "key": "bmi", "value": 25.7, "unit": "kg/m²", "P": 76.3, "rank": 76, "band": 4, "health": "warn", "cohort": "여자|40-44세" } ] }
```

## 2. 화면 매핑

| 출력 | 화면 요소 | 규칙 |
|---|---|---|
| value · unit | 측정값 | 소수 1자리, 카드에서 가장 큰 숫자 |
| rank | "내 또래 100명 중 **N등**" | 항목 색으로 강조 |
| band | 사람 그림 5개 중 진하게 칠할 위치 · "나" 말풍선 · 구간 라벨 강조 | 라벨: 1~20등 · 21~40등 · 41~60등 · 61~80등 · 81~100등 |
| band | 상태 배지 문구 | 아래 사전 |
| health | 배지 톤 | warn → 주의 톤. 그 외 band 2~4 안정 톤, band 1·5 중립 톤 |

배지 문구 사전

| band | 키 | 체중 | BMI | 허리둘레 |
|---|---|---|---|---|
| 1 | 작은 편이에요 | 가벼운 편이에요 | 낮은 편이에요 | 가는 편이에요 |
| 2 | 조금 작은 편이에요 | 조금 가벼운 편이에요 | 조금 낮은 편이에요 | 조금 가는 편이에요 |
| 3 | 평균적인 편이에요 | 평균적인 편이에요 | 평균적인 편이에요 | 평균적인 편이에요 |
| 4 | 조금 큰 편이에요 | 조금 무거운 편이에요 | 조금 높은 편이에요 | 조금 굵은 편이에요 |
| 5 | 큰 편이에요 | 무거운 편이에요 | 높은 편이에요 | 굵은 편이에요 |

화면에 쓰지 않는 것: "상위/하위 N%", "또래보다 좋음/나쁨", 종합 점수, 방향 뒤집기. 신체계측 외 검사(혈압·혈당·지질 등)는 등수화하지 않고 공단 판정기준 막대로 보여 준다.

## 3. 예외

| 상황 | 처리 |
|---|---|
| 성별 없음 · 20세 미만 · 행 없음 | rank = null |
| rank = null | 등수 "—", 사람 그림 전부 연한 톤, "나" 없음, 안내 "또래 비교 데이터를 준비 중이에요" |
| 항목 값 없음 | 그 카드 제거, 순서 당김 |
| 값이 p1 미만 / p99 이상 | P = 1 / 99 (STEP 5) |
| hi == lo | frac = 0 |
| 단위 다름 | 먼저 환산, 환산표 없으면 계산 안 함 |

## 4. 검증 벡터 (허용 오차 ±0.1 · 경계값표 기준)

| 성별 | 나이 | 항목 | x | k | P | rank | band | health | 배지 |
|---|---|---|---|---|---|---|---|---|---|
| 남 | 45 | BMI | 24.5 | 40 | 40.0 | 40 | 2 | ok | 조금 낮은 편이에요 |
| 남 | 45 | 허리둘레 | 82 | 21 | 21.0 | 21 | 2 | ok | 조금 가는 편이에요 |
| 남 | 45 | 키 | 172 | 42 | 42.5 | 43 | 3 | ok | 평균적인 편이에요 |
| 남 | 45 | 체중 | 72.5 | 36 | 36.3 | 36 | 2 | ok | 조금 가벼운 편이에요 |
| 여 | 42 | BMI | 17.9 | — | (계산) | (계산) | — | **warn** (저체중) | band 문구 + 주의 톤 |
| 남 | 17 | BMI | 24.5 | — | — | null | — | — | "—" + 준비 중 안내 |

k·P는 PCT-002 검증 벡터와 같다. 여 42 BMI 17.9는 등수도 계산하되 health = warn으로 배지 톤만 바꾼다(PCT-002의 "확인 필요 대체"와 다른 점).

## 5. 자주 틀리는 곳
- 나이를 오늘 기준으로 잡으면 등수가 해마다 바뀐다 → 검진일 기준.
- k는 "작거나 같음". 경계값과 같은 값은 그 경계 번호가 k.
- rank를 뒤집지 않는다. 키 1등은 가장 작은 키다.
- 0등·100등은 쓰지 않는다(1~99).
- BMI는 결과지 값 우선, 없으면 체중 ÷ (키/100)².

## 6. 경계값표 만드는 절차 (데이터 담당, 연 1회)
1. 질병관리청 국민건강영양조사 누리집 → 원시자료 → 3개년(2022~2024) 기본DB. 사용자등록 후 무료.
2. 변수: sex, age, HE_ht, HE_wt, HE_BMI, HE_wc, wt_itvex(검진 가중치). 연도별 이용지침서에서 확인.
3. 만 19세 이상, 값 있음, 가중치 > 0. 3개년 합칠 때 각 연도 가중치 ÷ 3.
4. 성별 × 5세 구간(20-24 … 75-79, 80세 이상). 표본 30명 미만 집단은 만들지 않음.
5. 가중 백분위: 값 정렬 → 누적 가중치가 W×q/100을 처음 넘는 지점에서 선형보간 → p1~p99.
6. 검증: p1 ≤ … ≤ p99, p50 ≈ 가중평균, 건강검진통계 구간표로 계산한 P와 ±2 이내.
7. 파일명에 조사 연도·생성일·버전. 화면 고지 "국민건강영양조사 2022~2024(질병관리청)". 원시자료는 재배포하지 않는다.
